Le parcours d'apprentissage vous mène de l'installation d'AWFlow à la création d'agents, une courte leçon à la fois. Chaque leçon se termine par quelque chose qui fonctionne, et vous explique comment le vérifier. Votre progression est enregistrée **dans ce navigateur**, sans compte : ouvrez n'importe quelle leçon pour voir l'anneau de progression dans le rail de gauche.

<YouTube id="ogZ03_AC5o8" />

## Niveau 1 · Vos premières automatisations

**Disponible maintenant.** Environ 30 minutes. Vous terminez avec un workflow d'IA qui s'exécute depuis un raccourci clavier, et vous savez comment demander le suivant à Aria.

## À propos de votre progression

- La progression est stockée dans le stockage local de votre navigateur, sur cet appareil uniquement. Rien n'est envoyé ailleurs.
- Dans une fenêtre privée, ou si votre navigateur bloque le stockage du site, les leçons fonctionnent toujours, mais la progression est oubliée quand vous quittez la page.
- Pour repartir de zéro, effacez les données de ce site dans les paramètres de votre navigateur.
