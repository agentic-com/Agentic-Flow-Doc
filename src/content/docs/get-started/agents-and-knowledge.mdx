Level 3 goes from a single AI step to **agents**: models that choose which tools to use, remember earlier conversations, and answer from documents you give them.

<Aside type="note" title="Lessons coming next">
The level 3 lessons, with steps, checks and progress tracking like [level 1](/get-started/install/), are not written yet. Until they are, each topic below links to the guide that covers it today.
</Aside>

| 2 | Get answers in a set format | Prompts that return clean, structured output. | [Prompting and outputs](/concepts/ai/prompting-and-outputs/) |

| 5 | Keep a human in the loop | Ask for approval before an agent acts. | [Action approval](/concepts/ai/action-approval/) |
