Welcome to the Agentic Workflow Studio learning center! Here you'll find comprehensive resources to help you master creating AI-powered workflows within your browser.

## Learning Paths

Choose your learning journey based on your experience level and goals:

### For Beginners
Start with our foundational courses that teach you the basics of browser-based workflow creation:
- **Browser Extension Basics**: Learn how to install and set up Agentic Workflow Studio
- **Your First Workflow**: Create simple workflows using browser context manipulation
- **Understanding Nodes**: Master the core building blocks of browser workflows

### For Intermediate Users
Build on your foundation with more advanced browser automation techniques:
- **Advanced Browser Manipulation**: Complex text extraction and content processing
- **Multi-Node Workflows**: Combining multiple browser extension nodes effectively
- **AI Integration**: Incorporating AI processing into your browser workflows

### For Advanced Users
Explore sophisticated AI-powered automation and complex workflow patterns:
- **Advanced AI Workflows**: LangChain integration within browser context
- **Custom Workflow Patterns**: Building reusable automation templates
- **Performance Optimization**: Efficient browser resource usage
