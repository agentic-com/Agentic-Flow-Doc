:::note[In 20 seconds]
While a step works on one item, `{{ $input }}` and a reference to a **directly connected** step both point at the matching item. A reference to a step further back returns that step's **whole output**, not the matching item. To keep a title next to its URL, carry the field forward on the item, join the lists again with Merge on a shared field, or process one item at a time in a lambda workflow.
:::

## See it happen

## Which item does a reference return?

| You write… | While the step works on item 2, you get… |
| --- | --- |
| `{{ $input.url }}` | `url` of item 2, the item this run received. |
| `{{ $('Get All Text from Link').url }}` in a step **directly connected** to it | `url` of the item from that step used in this run. |
| `{{ $('Split Out').url }}` in a step **further down** | Empty: that step's whole output is a list, and a list has no `url` field. |
| `{{ $('Split Out').1.url }}` | `url` of the second item of that list (counting starts at 0), whatever item is being processed. |

In a step's settings, the input panel shows the same split: steps under **Direct inputs** give you the matching item, steps under **Relatives** give you their whole output.

The third option works because a lambda workflow runs once per item: inside it, every earlier step holds a single item, so `{{ $('Lambda Input').url }}` reads the right value anywhere.

Add a stable field such as `id` or `url` before a workflow splits into branches. It gives Merge something reliable to match on later.

## You'll notice this when…

<details>
<summary>Every row shows the same title</summary>

The title comes from a step that isn't directly connected, or from a step that output a single item, so every run reads the same value. Carry the title forward on each item and read it with `$input`.

</details>

<details>
<summary>A reference to an earlier step comes out empty</summary>

That step is not directly connected, so the reference reads its whole output. If the output is a list, use an index (`.0.title`) or carry the field forward instead. Also check the name: `$('…')` must match the node label exactly, including capitals and spaces.

</details>

<details>
<summary>After a Merge, fields are called left-title and right-title</summary>

Both inputs had a `title` field with different values, so [Merge](/nodes/builtin/flow/merge/) kept both and renamed them. Rename one side before the Merge, or use the prefixed names.

</details>
