Download the input data as a file

## What it does

Converts workflow data into a downloadable file in various formats (JSON, CSV, etc.).

## When to use it

Use this node to export workflow results as files for download or storage.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **FieldPath** | Text |  | Yes | The path to the field to pick from the input object (without the node's name or id) that contains the url to download. |
| **File type** | Choice | json | No | The type to use for the file to download in case the type can't be determined from the input data. 17 options. |
| **File name** | Text | `file` | No | The name of the file to download. If not provided, a random file name will be generated based on the input data. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Return input fields** | Toggle | Off | No | Whether to return the input fields in the output. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Connect data into Download as file, configure the settings above, and use the output in the next workflow step.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
