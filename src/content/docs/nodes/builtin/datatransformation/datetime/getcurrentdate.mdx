Get the date and time at the moment the node runs.

## What it does

Get Current Date writes the current date and time into a field named by **Output field name**. It reads the clock of the computer running the workflow, down to the millisecond. It ignores the incoming data unless you turn on **Include input fields**, which keeps the incoming fields next to the date.

## When to use it

- Stamp an item with the time it was processed before saving it.
- Start a date calculation from "now", such as "now plus 7 days".
- Build a dated file name or message.

## Example workflow

Log each run to a sheet with a timestamp:

1. [Schedule](/nodes/builtin/trigger/schedule/) trigger, every hour.
2. Get Current Date, **Output field name** `checkedAt`.
3. [Format Date](/nodes/builtin/datatransformation/datetime/formatdate/), **Date to format** `{{ $input.checkedAt }}`, **Format** `YYYY-MM-DD`, **Output field name** `day`, **Include input fields** on.
4. [Google Sheets](/nodes/builtin/integration/google-sheets/), append a row with `{{ $input.day }}` and `{{ $input.checkedAt }}`.

## Common issues

- **The incoming data is gone after this node.** By default only the date is output. Turn on **Include input fields** under **Options**.
- **The time looks a few hours off.** The date is stored in UTC (the `Z` at the end). [Format Date](/nodes/builtin/datatransformation/datetime/formatdate/) shows it in your local time zone.
- **The date field is missing.** With **Include input fields** on, an incoming field with the same name as **Output field name** replaces the date. Use a different name.
