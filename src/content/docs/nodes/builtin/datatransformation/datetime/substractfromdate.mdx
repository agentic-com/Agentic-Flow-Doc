Subtract a number of days from a date

## What it does

Subtracts a specified duration (days, hours, minutes, etc.) from a date value.

## When to use it

Use this node to calculate past dates, determine deadlines, or find historical timestamps.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Date to subtract from** | Date and time |  | Yes | The date to subtract days from. |
| **Time unit to subtract** | Choice |  | Yes | The time unit to subtract from the date. Options: year, quarter, month, week, day, hour, minute, second. |
| **Duration** | Number |  | Yes | The duration to subtract from the date. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}
