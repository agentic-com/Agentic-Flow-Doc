Add a number of days to a date

## What it does

Adds a specified duration (days, hours, minutes, etc.) to a date value.

## When to use it

Use this node to calculate future dates, schedule events, or set expiration times.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Date to add to** | Date and time |  | Yes | The date to add days to. |
| **Time unit to add** | Choice |  | Yes | The time unit to add to the date. Options: year, quarter, month, week, day, hour, minute, second. |
| **Duration** | Number |  | Yes | The duration to add to the date. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
