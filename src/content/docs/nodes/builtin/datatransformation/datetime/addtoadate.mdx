Move a date forward by a number of years, months, days, hours or other units.

## What it does

Add To A Date takes **Date to add to**, adds **Duration** of the chosen **Time unit to add**, and writes the new date into a field named by **Output field name**.

- Units: year, quarter (3 months), month, week (7 days), day, hour, minute, second.
- The calculation uses your computer's local time zone, so adding 1 day keeps the same clock time even across a daylight-saving change.
- A negative **Duration** moves the date back, but [Subtract From A Date](/nodes/builtin/datatransformation/datetime/substractfromdate/) reads more clearly.
- Adding a month to the 31st rolls over when the next month is shorter: January 31 plus 1 month gives March 2 or 3.

## When to use it

- Work out a due date, for example 14 days after an order date.
- Set an expiry time, such as "now plus 1 hour".
- Build the end of a date range to send to an API.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Date to add to** | Date and time |  | Yes | The date to add days to. |
| **Time unit to add** | Choice |  | Yes | The time unit to add to the date. Options: year, quarter, month, week, day, hour, minute, second. |
| **Duration** | Number |  | Yes | The duration to add to the date. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

**Date to add to** accepts a date you pick, or an expression such as `{{ $input.createdAt }}`. ISO dates (`2026-03-01`, `2026-03-01T09:30:00Z`) are the safest format.

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

The item holds one field, named by **Output field name**, with the new date. Turn on **Include input fields** to keep the incoming fields next to it, for example `{ dueDate, orderId, customer }`.

## Example workflow

Remind yourself of a follow-up one week from today:

1. [Get Current Date](/nodes/builtin/datatransformation/datetime/getcurrentdate/), **Output field name** `now`.
2. Add To A Date, **Date to add to** `{{ $input.now }}`, **Time unit to add** `week`, **Duration** `1`, **Output field name** `followUp`.
3. [Format Date](/nodes/builtin/datatransformation/datetime/formatdate/), **Date to format** `{{ $input.followUp }}`, **Format** `DD/MM/YYYY`.
4. [Browser Notification](/nodes/extension/browsernotification/) showing the formatted date.

## Troubleshooting

- **The output is "Invalid Date" or empty.** The incoming value is not a date the browser understands. Use an ISO date such as `2026-03-01`, or reshape it first.
- **The result is off by a few hours.** The date was read in a different time zone than you expected. Include the time zone in the input (`Z` or `+02:00`).
- **The new date is missing after the node.** With **Include input fields** on, an incoming field with the same name as **Output field name** replaces the result. Pick a name the input does not already use.
