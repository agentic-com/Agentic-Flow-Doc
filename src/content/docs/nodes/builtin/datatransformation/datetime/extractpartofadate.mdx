Pull one number out of a date, such as its year, day of the month or hour.

## What it does

Extract Part Of A Date reads **Date to extract part from** and returns one number, chosen with **Part of date to extract**, in the field named by **Output field name**. Values are read in your computer's local time zone.

| Part | What you get |
| --- | --- |
| year | The full year, for example `2026`. |
| month | The month counted **from 0**: January is `0`, December is `11`. |
| week | The day of the month divided by 7, a decimal (the 15th gives about `2.14`). It is not a week-of-year number. |
| day | The day of the month, `1` to `31`. |
| hour | `0` to `23`. |
| minute, second | `0` to `59`. |

## When to use it

- Branch on the hour, for example only notify between 9 and 18 with [IF](/nodes/builtin/flow/if/).
- Group or label items by year.
- Check whether today is the 1st of the month.

To turn a date into readable text, use [Format Date](/nodes/builtin/datatransformation/datetime/formatdate/) instead.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Date to extract part from** | Date and time |  | Yes | The date to extract part from. |
| **Part of date to extract** | Choice |  | Yes | The part of the date to extract. Options: year, month, week, day, hour, minute, second. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

**Date to extract part from** accepts a picked date or an expression such as `{{ $input.publishedAt }}`. ISO dates (`2026-03-01T09:30:00Z`) work best.

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

The item holds one number under **Output field name**, for example `{ hour: 14 }`. Turn on **Include input fields** to keep the incoming fields too.

## Example workflow

Only send a notification during working hours:

1. [Get Current Date](/nodes/builtin/datatransformation/datetime/getcurrentdate/), **Output field name** `now`.
2. Extract Part Of A Date, **Date to extract part from** `{{ $input.now }}`, **Part of date to extract** `hour`, **Output field name** `hour`.
3. [IF](/nodes/builtin/flow/if/): `{{ $input.hour }}` is greater than or equal to `9` and less than `18`.
4. On the true branch, a [Browser Notification](/nodes/extension/browsernotification/).

## Troubleshooting

- **The month is one lower than expected.** Months start at 0. Add 1 with [Math](/nodes/builtin/datatransformation/math/), or use [Format Date](/nodes/builtin/datatransformation/datetime/formatdate/) if you need it as text.
- **"week" returns a decimal.** It is the day of the month divided by 7, not the week of the year.
- **The output is empty or `NaN`.** The incoming value is not a date the browser can read. Use an ISO date such as `2026-03-01`.
