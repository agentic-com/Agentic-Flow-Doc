Extract a part of a date

## What it does

Extracts a specific component (year, month, day, hour, etc.) from a date value.

## When to use it

Use this node to isolate date components for filtering, grouping, or display purposes.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Date to extract part from** | Date and time |  | Yes | The date to extract part from. |
| **Part of date to extract** | Choice |  | Yes | The part of the date to extract. Options: year, month, week, day, hour, minute, second. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Connect data into Extract Part Of A Date, configure the settings above, and use the output in the next workflow step.
