Format a date

## What it does

Converts a date value into a specified string format (e.g., "YYYY-MM-DD", "MM/DD/YYYY").

## When to use it

Use this node to format dates for display, API requirements, or standardized output.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Date to format** | Date and time |  | Yes | The date to format. |
| **Format** | Choice |  | Yes | The format to use for the date. Options: MM/DD/YYYY, YYYY/MM/DD, MMMM DD YYYY, MM-DD-YYYY, YYYY-MM-DD, DD/MM/YYYY, DD-MM-YYYY, Unix Timestamp, Unix MS Timestamp. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

One output port.
