Get the time between two dates

## What it does

Calculates the duration between two dates in specified units (days, hours, minutes, etc.).

## When to use it

Use this node to measure time elapsed, calculate age, or determine time remaining until a deadline.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Start date** | Date and time |  | Yes | The start date. |
| **End date** | Date and time |  | Yes | The end date. |
| **Units** | Multiple choice |  | Yes | The units to subtract from the date. Options: year, month, week, day, hour, minute, second, millisecond. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}
