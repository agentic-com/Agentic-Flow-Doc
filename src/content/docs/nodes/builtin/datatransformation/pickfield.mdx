Pick a specific field from the input data

## What it does

Extracts a single specified field from input data, discarding all other fields.

## When to use it

Use this node to simplify data by keeping only the field you need for downstream processing.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **FieldPath** | Text |  | Yes | The path to the field to pick from the input object (without the node's name or id). |
| **Output field name** | Text |  | No | The name of the output field to be used in case the target data is an array of non objects (like strings, numbers, etc.). |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Connect data into Pick Field, configure the settings above, and use the output in the next workflow step.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
