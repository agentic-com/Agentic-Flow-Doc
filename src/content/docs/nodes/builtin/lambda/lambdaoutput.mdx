Define the outputs for the lambda workflow.

## What it does

Defines the output values returned by a lambda workflow to its caller.

## When to use it

Use this node as the exit point of a lambda workflow to specify what data it returns.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Outputs** | Field list |  | Yes | The outputs for the lambda workflow. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Connect data into Lambda Output, configure the settings above, and use the output in the next workflow step.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
