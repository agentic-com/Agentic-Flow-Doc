Load a web page as text to feed into the Indexer.

## What it does

Fetches the given URL and converts its HTML response into clean plain text, then outputs that
text under a configurable field (default `text`). Connect that output to the
[Indexer](/nodes/builtin/ai/aiagents/indexernode/) node's `Input` port to index a web page.

## When to use it

Use it to index the content of a public web page into a knowledge base for RAG or Q&A, without
manually copying the page text.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **URL** | Text |  | Yes | The URL to load text from. |
| **Output field name** | Text | `text` | No | The name of the output field that will hold the loaded text. |
| **Timeout** | Number | 10000 | No | The timeout for the request in milliseconds. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Headers** | Key-value pairs |  | No | The headers to send with the request. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

An item with the extracted page text under the chosen output field (default `text`).

## Notes

- Runs in the web app or the extension. Pages that block cross-origin requests may not be
  reachable from the web app — in that case use the
  [Current Page Document Loader](/nodes/builtin/ai/loaders/currentpagedocumentloader/) inside
  the extension instead.
- Uses the same fetch + HTML-to-text conversion as
  [Get All Text from Link](/nodes/builtin/core/getalltextfromlink/).

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Troubleshooting

- A `HTTP error! status: …` means the server returned a non-2xx response.
- An `Invalid URL` error means the URL is malformed.
- A `Request timeout` means the page took longer than the configured timeout.
