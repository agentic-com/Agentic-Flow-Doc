Load the current tab as text to feed into the Indexer.

## What it does

Reads the visible text of the currently-open browser tab and outputs it under a configurable
field (default `text`). Connect that output to the
[Indexer](/nodes/builtin/ai/aiagents/indexernode/) node's `Input` port to index whatever page
you are on.

## When to use it

Use it to index the page a user is currently viewing — a document, an article, an internal
tool — without needing a public URL.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Output field name** | Text | `text` | No | The name of the output field that will hold the loaded text. |
| **DOM Selector** | Page element |  | No | The selector of the DOM element to interact with. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Visible text only** | Toggle | Off | No | Only return text from visible elements. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

An item with the current page's text under the chosen output field (default `text`).

## Notes

- **Extension only.** This loader talks to the active tab through the awflow browser extension,
  so it does not run in the web app. Install the extension to use it.
- Uses the same page-text extraction as [Get All Text](/nodes/extension/getalltext/).

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Troubleshooting

- `No content found` — the page (or the selected element) yielded no text. Run the node after
  the page has loaded, and check the DOM Selector if you set one.
