An AI agent that can call tools (search, calculate, browse, call APIs) step by step until it can answer.

## What it does

Tools Agent sends **Prompt** to the chat model on **Model**, together with the tools connected to **Tools**. The model decides which tool to call and with what; the agent runs it, sends the result back, and repeats until the model gives a final answer or **Max iterations** is reached.

Some tools only read or compute. Others take real actions on your behalf, and those can ask for your approval before they run. Each tool step has **Ask before a call** (*Every call*, *Only calls that change things*, *Skip trusted sites*, *Ask me anywhere, even when I'm away*); calls that delete or send as you always ask. When nobody is there to answer (a scheduled run), the run waits in **Runs** instead of failing. See [Steps as AI tools](/concepts/ai/steps-as-tools/) and [Action approval](/concepts/ai/action-approval/).

Tools you can connect include the dedicated tools ([HTTP Request Tool](/nodes/builtin/ai/aidependencies/tools/http-request/), [MCP Client Tool](/nodes/builtin/ai/aidependencies/tools/mcp-client/), [Workflow Tool](/nodes/builtin/ai/aidependencies/tools/workflow-tool/), Calculator, Web Search…), the [Browser](/nodes/builtin/ai/aidependencies/tools/browser/) block, and app and page steps used as tools (Slack, Gmail, Google Sheets, Notion…). Add them from the agent's **Building blocks** at the top of **Setup**. What tools return from outside (pages, API answers) reaches the model fenced as data.

While it runs:

- Each tool call appears in the run log as it happens (*Agent calls tool …*, then *Tool … finished in 840 ms*, or a warning when it failed or timed out).
- **Stop** interrupts the agent mid-reply: the model call and any running tool are cancelled, and the log says *Agent stopped before it finished*.
- When the model asks for a tool in a malformed way, the error is sent back to the model so it can correct the call, instead of failing the node.

### Fallback model

Connect a second chat model to **Fallback**. When the main model fails before writing anything with an error worth retrying elsewhere (rate limit 429, payment or key problems 401/402/403, a 5xx, a network error), the same call goes to the fallback. The run log names the switch, and the output gets `usedFallback: true`.

### Structured answers (version 2)

With an output parser and a model that can use tools, new Tools Agent steps get the answer back as a tool call with typed fields, checked against the parser's schema. A wrong answer is asked again once; then the step fails and lists the missing fields. Models that can't use tools still read the answer from the text. Steps saved before 0.9 keep reading the text.

### Memory

With a chat memory on **Memory**, the agent has a conversation: it loads the earlier messages as chat history, saves the prompt as a `user` message, and saves the reply as an `assistant` message (a structured reply from an output parser is saved as JSON text). With a [Chat Trigger](/nodes/builtin/trigger/chat/), the agent's answer streams into the chat as the reply; a Chat Trigger saved before 0.9 needs the **same** memory connected to the trigger and to this agent.

## When to use it

- A chatbot that can look things up on the web, do maths or query an API before it answers.
- A task in several steps, such as "find the price on this page, convert it to euros, and fill it into the form".
- An assistant that searches your knowledge base and also uses tools.

For a single prompt with no tools, use [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/). To answer only from your documents, [RAG Agent](/nodes/builtin/ai/aiagents/ragnode/) is simpler.

Behind a Chat Trigger, set **Prompt** to `{{ $input.chatInput }}`. Use **System message** to tell the agent its role and when to use which tool.

When the agent reaches **Max iterations**, it stops calling tools and is asked for a final answer with what it has; the run log says *Agent reached its max iterations and answered with what it had*.

When a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) is connected to **Knowledge**, **Knowledge search** decides how the agent uses it:

- **Search before answering** (default): the knowledge base is searched with the prompt and the passages are given to the agent up front. Best for small and on-device models.
- **Let the agent search the knowledge base on its own**: the agent gets a knowledge search tool and decides when and what to search, for example several searches with better questions. Best for capable models.
- **Both**: passages up front, and the tool to search again.

The search tool returns passages numbered `[S1]`, `[S2]`… (the numbering continues across calls), fenced as reference data. It only reads, so it does not need your approval. Its calls appear in `steps` like any other tool, and the sources it found are added to `sources`.

The other knowledge options work as on the RAG Agent: see [Knowledge base options](/nodes/builtin/ai/aiagents/ragnode/#knowledge-base-options). A **Device only** knowledge base is never sent to a cloud model.

- `response`: the agent's final answer.
- `steps`: present when tools are connected. Each entry has `name`, `args`, `status` (`ok`, `error`, `timeout`, `aborted` or `skipped`), `durationMs`, `result` (shortened) and `truncated`.

- `usage`: tokens used over every model call of the run: `inputTokens`, `outputTokens`, `cachedTokens` (served from the provider's prompt cache) and `totalTokens`. Present when the provider reports usage.

## Dependencies and credentials

- **Model**: a chat model that supports tool calling. Cloud models do, and so do the on-device [Transformers Chat](/nodes/builtin/ai/aidependencies/llm/transformerschat/) and [Web LLM](/nodes/builtin/ai/aidependencies/llm/wbellm/) models (prompt-based tool calling). The model node holds the API key.
- **Tools**: any number of tool nodes, such as [Calculator](/nodes/builtin/ai/aidependencies/tools/calculator/), [Web Search](/nodes/builtin/ai/aidependencies/tools/web-search/), [Wikipedia Query](/nodes/builtin/ai/aidependencies/tools/wikipedia-query/) or [Workflow as Tool](/nodes/builtin/ai/aidependencies/tools/workflow-tool/).
- **Memory**: a [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/), to remember the conversation. It can keep tool results so later turns can use them.
- **Knowledge**: a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) node.
- **Output Parser**: shapes the final answer.

## Example workflow

1. [Chat Trigger](/nodes/builtin/trigger/chat/) opens a chat window.
2. Tools Agent with **Prompt** `{{ $input.chatInput }}` and **System message** `You are a research assistant. Search the web for recent facts and use the calculator for any maths.`
3. Connect an [Chat OpenAI](/nodes/builtin/ai/aidependencies/llm/openai/) model to **Model**, [Web Search](/nodes/builtin/ai/aidependencies/tools/web-search/) and [Calculator](/nodes/builtin/ai/aidependencies/tools/calculator/) to **Tools**, and one [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) to both **Memory** and the Chat Trigger.

Ask "What is the population of Lyon divided by 12?" and watch the run log: the agent searches, then calculates, then answers.

## Common issues

- **"This agent requires that the bind_tools() method be implemented on the input model".** The connected chat model cannot call tools. Use a cloud model, or Transformers Chat or Web LLM on-device, and check that it is connected to **Model**.
- **The run pauses and nothing happens.** A tool is waiting for your approval. Open **Runs** and approve or reject the action.
- **"Agent reached its max iterations and answered with what it had".** The agent needed more tool calls. Raise **Max iterations**, or make the prompt and **System message** more precise so it needs fewer steps.
- **The agent never uses a tool.** Say in **System message** when each tool should be used. Small models often skip tools; try a more capable model.
- **"Model not found".** The connected model node is not set up: open it and choose a model and its credential.
