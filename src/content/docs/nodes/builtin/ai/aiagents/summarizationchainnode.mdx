## What it does

Summarization sends **Text** to the chat model connected to **Model**, asking for a concise summary that keeps the key points. The reply comes back in `summary`.

**Max words** and **Style** are added to the model's instructions. They guide the model; they do not cut the text afterwards, so a summary can run a little over **Max words**.

The whole text is sent in one request, so it must fit the model's context window.

## When to use it

- Summarise an article or a long page before you read it.
- Shorten a transcript, an email thread or a report before you save or send it.
- Make compact context for another AI step.

To summarise on-device without a model node, use [Summarize](/nodes/builtin/ai/localai/summarize/). For any other kind of rewrite, use [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/).

## Example workflow

1. [Get All Text](/nodes/extension/getalltext/) reads the current page, with **Output field name** `text` and **Visible text only** on.
2. Summarization with **Text** `{{ $input.text }}`, **Max words** `120` and **Style** `bullet points`, with an [Chat OpenAI](/nodes/builtin/ai/aidependencies/llm/openai/) model on **Model**.
3. [Display Markdown](/nodes/extension/displaymarkdown/) with **Content** `{{ $input.summary }}`.

## Common issues

- **The summary is longer than Max words.** The limit is an instruction, not a hard cut. Lower it, or add `Never exceed the word limit.` in **System message**.
- **The model fails on a very long page.** The text is larger than the model's context window. Use a model with a larger window, or shorten the text first (for example with a **DOM Selector** in Get All Text).
- **"Dependency model is required".** Connect a chat model to the **Model** slot.
- **"Model not found".** The connected model node is not set up: open it and choose a model and its credential.
