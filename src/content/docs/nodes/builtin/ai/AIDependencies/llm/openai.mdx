# Chat OpenAI

Leverage OpenAI to use LLM locally directly on your device

## What it does

Provides access to OpenAI's language models (GPT-4, GPT-3.5, etc.) for AI agent nodes.

## When to use it

Connect this to AI agents when you want to use OpenAI's models for text generation, analysis, or conversation.

## Inputs and settings

| Setting | Notes |
| --- | --- |
| Model | Source-backed field from the node schema. |

## Outputs

Returns a chat model dependency that can be connected to AI agent nodes.

## Dependencies and credentials

- No explicit credential or node dependency is declared in the node description.

## Example workflow

Connect Chat OpenAI to an AI agent or dependency input that accepts this dependency type, then run the agent with data from previous nodes.
