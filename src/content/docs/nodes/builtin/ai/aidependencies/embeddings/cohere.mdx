Leverage Cohere to create embeddings.

## What it does

Converts text into vector embeddings using a Cohere embeddings model. Cohere exposes an OpenAI-compatible API, so this node runs the OpenAI embeddings client against Cohere's base URL.

## When to use it

Connect this to indexer or RAG nodes when you need to create embeddings for semantic search and retrieval using Cohere.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Text |  | Yes | The Cohere embeddings model to use, e.g. embed-english-v3.0. |
| **Authentication** | Credential |  | Yes | Use your Cohere API key as a Bearer token. |
{/* AUTO:settings:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
- **Authentication** (credential): required. Pick a saved connection or create one from this field.
{/* AUTO:deps:end */}

- Requires an Authentication credential (Cohere API key), sent as a Bearer token.
- The node throws an error if Model is empty.

## Example workflow

Connect Cohere Embeddings to an AI agent or dependency input that accepts this dependency type, set the Model to a Cohere embeddings model such as `embed-english-v3.0`, attach your Cohere API key credential, then run the agent with data from previous nodes.

## Troubleshooting

- Check that the Model field is set — the node throws an error if it is empty.
- Verify the Cohere API key credential is valid.
- If it calls an external service, verify credentials, permissions, and rate limits.
