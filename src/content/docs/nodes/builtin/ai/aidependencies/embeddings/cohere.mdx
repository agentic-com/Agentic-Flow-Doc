Turn text into vectors with Cohere's embedding models, so a knowledge base can find passages by meaning.

## What it does

Cohere Embeddings plugs into the **Embeddings** slot of a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) node. It does not run on its own and has no output. When the knowledge base is filled or searched, the text is sent to Cohere with your key and comes back as vectors (lists of numbers that capture meaning).

A knowledge base remembers the embedding model it was built with and always uses it. So this node decides the model when a **new, empty** knowledge base is first filled. After that, connect the same node to search it.

Your passages and questions are sent to Cohere. For text that must stay on your device, use [Local Embeddings](/nodes/builtin/ai/aidependencies/embeddings/localembeddings/).

## When to use it

- Documents in many languages: Cohere has multilingual embedding models.
- You already use Cohere and want its embeddings in AWFlow.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Text |  | Yes | The Cohere embeddings model to use, e.g. embed-english-v3.0. |
| **Authentication** | Credential |  | Yes | Use your Cohere API key as a Bearer token. |
{/* AUTO:settings:end */}

Type the **Model** id as Cohere names it, for example `embed-english-v3.0`, or `embed-multilingual-v3.0` for other languages. Don't change it on a knowledge base that already has content.

## Outputs

{/* AUTO:outputs:start */}
This node has no output port. It plugs into a slot on another node instead of passing items along.

| Slot | Accepted by |
| --- | --- |
| Embeddings | [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) |
{/* AUTO:outputs:end */}

The vectors go to the knowledge base, not to the next node.

## Dependencies and credentials

{/* AUTO:deps:start */}
- **Authentication** (credential): required. Pick a saved connection or create one from this field.
{/* AUTO:deps:end */}

In **Authentication**, save your Cohere API key. Create it on the API keys page of the Cohere dashboard. See [Create a credential](/usage/using-the-app/credentials/create/).

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on the page.
2. [Get All Text](/nodes/extension/getalltext/) with **Output field name** `pageText`.
3. [Indexer](/nodes/builtin/ai/aiagents/indexernode/) with **Input** `{{ $input.pageText }}`, a [Recursive Character Text Splitter](/nodes/builtin/ai/aidependencies/textsplitter/recursivecharactertextsplitter/) in its **Text Splitter** slot, and a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) pointing to a new knowledge base in its **Knowledge** slot.
4. Cohere Embeddings in the Local Knowledge's **Embeddings** slot, **Model** `embed-multilingual-v3.0`.

## Troubleshooting

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **"… was built with … embeddings. Connect that embeddings node to use it."** The knowledge base was built with this Cohere model. Connect Cohere Embeddings with the same **Model** to its Local Knowledge.
- **A "Model mismatch" warning in the run log.** The knowledge base was built with another model, so this node was ignored. Disconnect it, or re-embed the knowledge base from its settings.
- **A 401 error.** The key is wrong or revoked. Create a new key and update the credential.
