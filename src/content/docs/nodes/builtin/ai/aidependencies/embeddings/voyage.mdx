## What it does

Voyage Embeddings plugs into the **Embeddings** slot of a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) node. It does not run on its own and has no output. When the knowledge base is filled or searched, the text is sent to Voyage AI with your key and comes back as vectors (lists of numbers that capture meaning).

A knowledge base remembers the embedding model it was built with and always uses it. So this node decides the model when a **new, empty** knowledge base is first filled. After that, connect the same node to search it.

Your passages and questions are sent to Voyage AI. For text that must stay on your device, use [Local Embeddings](/nodes/builtin/ai/aidependencies/embeddings/localembeddings/).

## When to use it

- You want Voyage's retrieval-focused models, for example for long technical or legal documents.
- You already have a Voyage AI account.

Type the **Model** id as Voyage AI names it, for example `voyage-large-2`. Don't change it on a knowledge base that already has content.

## Outputs

{/* AUTO:outputs:start */}
This node has no output port. It plugs into a slot on another node instead of passing items along.

- **Embeddings** slot of [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/)
{/* AUTO:outputs:end */}

The vectors go to the knowledge base, not to the next node.

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on the page.
2. [Get All Text](/nodes/extension/getalltext/) with **Output field name** `pageText`.
3. [Indexer](/nodes/builtin/ai/aiagents/indexernode/) with **Input** `{{ $input.pageText }}`, a [Recursive Character Text Splitter](/nodes/builtin/ai/aidependencies/textsplitter/recursivecharactertextsplitter/) in its **Text Splitter** slot, and a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) pointing to a new knowledge base in its **Knowledge** slot.
4. Voyage Embeddings in the Local Knowledge's **Embeddings** slot, **Model** `voyage-large-2`.

## Common issues

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **"… was built with … embeddings. Connect that embeddings node to use it."** The knowledge base was built with this Voyage model. Connect Voyage Embeddings with the same **Model** to its Local Knowledge.
- **A "Model mismatch" warning in the run log.** The knowledge base was built with another model, so this node was ignored. Disconnect it, or re-embed the knowledge base from its settings.
- **A 401 error.** The key is wrong or revoked. Create a new key and update the credential.
