Turn text into vectors with Google's Gemini embedding models, so a knowledge base can find passages by meaning.

## What it does

Google Embeddings plugs into the **Embeddings** slot of a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) node. It does not run on its own and has no output. When the knowledge base is filled or searched, the text is sent to the Gemini API with your key and comes back as vectors (lists of numbers that capture meaning).

A knowledge base remembers the embedding model it was built with and always uses it. So this node decides the model when a **new, empty** knowledge base is first filled. After that, connect the same node to search it.

Your passages and questions are sent to Google. For text that must stay on your device, use [Local Embeddings](/nodes/builtin/ai/aidependencies/embeddings/localembeddings/).

## When to use it

- You already have a Google AI Studio key, for example for [Chat Google](/nodes/builtin/ai/aidependencies/llm/google/).
- You want cloud embeddings with the same Google account as your chat model.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Text |  | Yes | The Google embeddings model to use, e.g. text-embedding-004. |
| **Authentication** | Credential |  | Yes | Use your Google AI (Gemini) API key as a Bearer token. |
{/* AUTO:settings:end */}

Type the **Model** id as Google names it, for example `text-embedding-004`. Don't change it on a knowledge base that already has content.

## Outputs

{/* AUTO:outputs:start */}
This node has no output port. It plugs into a slot on another node instead of passing items along.

| Slot | Accepted by |
| --- | --- |
| Embeddings | [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) |
{/* AUTO:outputs:end */}

The vectors go to the knowledge base, not to the next node.

## Dependencies and credentials

{/* AUTO:deps:start */}
- **Authentication** (credential): required. Pick a saved connection or create one from this field.
{/* AUTO:deps:end */}

In **Authentication**, save your Google AI (Gemini) API key. Create it in Google AI Studio, at [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey). See [Create a credential](/usage/using-the-app/credentials/create/).

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on the page.
2. [Get All Text](/nodes/extension/getalltext/) with **Output field name** `pageText`.
3. [Indexer](/nodes/builtin/ai/aiagents/indexernode/) with **Input** `{{ $input.pageText }}`, a [Recursive Character Text Splitter](/nodes/builtin/ai/aidependencies/textsplitter/recursivecharactertextsplitter/) in its **Text Splitter** slot, and a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) pointing to a new knowledge base in its **Knowledge** slot.
4. Google Embeddings in the Local Knowledge's **Embeddings** slot, **Model** `text-embedding-004`.

## Troubleshooting

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **"… was built with … embeddings. Connect that embeddings node to use it."** The knowledge base was built with this Google model. Connect Google Embeddings with the same **Model** to its Local Knowledge.
- **A "Model mismatch" warning in the run log.** The knowledge base was built with another model, so this node was ignored. Disconnect it, or re-embed the knowledge base from its settings.
- **An "API key not valid" or 401 error.** Use a Google AI Studio key (a Vertex AI key does not work here), and check it was not deleted.
