Leverage OLLAM to use Embeddings locally directly on your device

## What it does

Converts text into vector embeddings using locally-run Ollama models.

## When to use it

Connect this to indexer or RAG nodes when you want local, privacy-focused embeddings without external API calls.

## Troubleshooting

- **Ollama refuses the request (403 / CORS error):** Ollama only answers browser origins it allows. Start it with the extension's origin allowed:
  - **Chrome:** `OLLAMA_ORIGINS=chrome-extension://linlkeaipfpnhddjkpcbmldionajfifa ollama serve`
  - **Firefox:** `OLLAMA_ORIGINS=moz-extension://* ollama serve` (a Firefox add-on's origin is different on every install)
- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
