Query Wikipedia for information on a given topic.

## What it does

Provides Wikipedia search and retrieval capabilities as a tool for AI agents.

## When to use it

Connect this to Tools Agent nodes to give them the ability to search Wikipedia for factual information.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Top K Results** | Number |  | No | The number of top results to return. |
| **Max Document Content Length** | Number |  | No | The maximum length of the document content. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
This node has no output port. It plugs into a slot on another node instead of passing items along.

| Slot | Accepted by |
| --- | --- |
| Tools | [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/) |
{/* AUTO:outputs:end */}

Returns a tool dependency that agent nodes can call.

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Connect Wikipedia Query to an AI agent or dependency input that accepts this dependency type, then run the agent with data from previous nodes.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
