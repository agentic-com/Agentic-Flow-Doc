Return data in a defined JSON format

## What it does

Ensures AI agent responses follow a specific JSON schema structure.

## When to use it

Connect this to AI agents when you need structured, parseable output in a defined format for downstream processing.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **JSON Output Example** | Code | `{
    "name": "John",
    "age": 30
}` | Yes | An example of the JSON output you expect. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
This node has no output port. It plugs into a slot on another node instead of passing items along.

| Slot | Accepted by |

Returns an output parser dependency used to structure model responses.

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Connect Structured Output Parser to an AI agent or dependency input that accepts this dependency type, then run the agent with data from previous nodes.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
