Give an AI node access to OpenAI's GPT models, using your own OpenAI API key.

## What it does

Chat OpenAI is a model you plug into the **Model** slot of an AI node, such as the [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/) or [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/). It does not run on its own and has no output. When the AI node runs, it sends its messages to OpenAI with your key and gets the reply back.

- **Temperature** is 0 when you leave it empty, so answers are focused and repeatable.
- Replies are capped at **Max Tokens** (4096 by default).
- A failed request is retried up to **Max Retries** times (2 by default). A request that gets no answer within 60 seconds fails.

## When to use it

- General writing, summarising, extracting and classifying with a GPT model.
- An agent that calls tools: connect it to the [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/).
- You already have an OpenAI account with credit.

If your company uses OpenAI models through Microsoft Azure, use [Chat Azure OpenAI](/nodes/builtin/ai/aidependencies/llm/azure-openai/) instead.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Text |  | Yes | The model to use. |
| **Authentication** | Credential |  | Yes | Use a Bearer Token. |
| **Options** | Group |  | No | The options to use with the model. |
| Options › **Temperature** | Number |  | No | The temperature to use for the model. |
| Options › **Max Retries** | Number | 2 | No | The maximum number of retries to use for the model. |
| Options › **Max Tokens** | Number | 4096 | No | The most tokens the model may generate in one reply. Defaults to 4096, which keeps providers from reserving credit for the whole output window. |
{/* AUTO:settings:end */}

Type the **Model** id exactly as OpenAI names it, for example `gpt-4o-mini` or `gpt-4o`. Your account must have access to that model.

## Dependencies and credentials

{/* AUTO:deps:start */}
- **Authentication** (credential): required. Pick a saved connection or create one from this field.
{/* AUTO:deps:end */}

In **Authentication**, use a Bearer Token credential that holds your OpenAI API key. Create the key on the API keys page of the OpenAI platform ([platform.openai.com/api-keys](https://platform.openai.com/api-keys)). See [Create a credential](/app/connections/create/).

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on the page.
2. [Get All Text](/nodes/extension/getalltext/) with **Output field name** `pageText`.
3. [Summarization](/nodes/builtin/ai/aiagents/summarizationchainnode/) with **Text** `{{ $input.pageText }}` and **Max words** `80`, with Chat OpenAI in its **Model** slot (**Model** `gpt-4o-mini`).
4. [Browser Notification](/nodes/extension/browsernotification/) with **Message** `{{ $input.summary }}`.

## Troubleshooting

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **An "Incorrect API key" or 401 error.** The key is wrong or revoked. Create a new key and update the credential.
- **A 429 or "quota" error.** Your OpenAI account is out of credit or over its rate limit. Add credit or wait, then run again.
- **The answer stops mid-sentence.** It hit **Max Tokens**. Raise it under **Options**.
