Let the Q&A Agent answer on your device by quoting the right passage from your knowledge base, instead of asking a chat model.

## What it does

Local Q&A Model is a model you plug into the **Model** slot of the [Q&A Agent](/nodes/builtin/ai/aiagents/qanode/). With it connected, the agent answers in your browser, free and private, and only with text that is really in your documents. When the agent runs:

1. It finds the most relevant passages in its connected [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) (**Knowledge documents (k)** on the agent, 4 by default).
2. The model looks for the answer in each passage (each cut to **Max knowledge context length**, 4000 characters by default).
3. The best-scoring answer wins, with the document it came from.

Because it can only quote, the Q&A Agent **must have a Knowledge connected** when you use this model.

## When to use it

- Look up facts in your own documents without sending them or the question to a server.
- You want short answers quoted word for word, not generated text.

For open questions that need a written, combined answer, connect a chat model such as [Web LLM](/nodes/builtin/ai/aidependencies/llm/wbellm/) instead.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Model picker |  | No | An on-device extractive Q&A model (e.g. DistilBERT SQuAD). Install one from Local AI, or download it from the picker. |
{/* AUTO:settings:end */}

The **Model** picker lists on-device question-answering models (for example DistilBERT SQuAD). Install one from the [Local Models](/app/local-models/) page, or download it from the picker. When you publish or share the workflow, **Model** is cleared, so whoever installs it picks their own.

## Outputs

{/* AUTO:outputs:start */}
This node has no output port. It plugs into a slot on another node instead of passing items along.

| Slot | Accepted by |
| --- | --- |
| Model | [Q&A Agent](/nodes/builtin/ai/aiagents/qanode/) |
{/* AUTO:outputs:end */}

The Q&A Agent produces the output: `answer` (the quoted text), `score` (how sure the model is; higher is better) and `source` (the document it came from).

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.

## Example workflow

1. Fill a knowledge base with your product manuals on the [knowledge bases page](/app/knowledge-bases/overview/).
2. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on selected text (the question).
3. [Q&A Agent](/nodes/builtin/ai/aiagents/qanode/) with **Prompt** `{{ $input.selectionText }}`, with Local Q&A Model in its **Model** slot and [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) (your manuals) in its **Knowledge** slot.
4. [Browser Notification](/nodes/extension/browsernotification/) with **Message** `{{ $input.answer }} ({{ $input.source }})`.

## Troubleshooting

- **"The Local Q&A Model answers by quoting a passage, so it needs a context: connect a Knowledge to the Q&A Agent."** Connect a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) to the agent.
- **"Choose an on-device Q&A model in the Local Q&A Model node."** **Model** is empty. Pick a model.
- **"Model "…" isn't available. Install it from Local AI."** Install it from [Local Models](/app/local-models/), or download it from the picker.
- **The answer is empty.** None of the passages found contained an answer (the run log shows a warning). Raise **Knowledge documents (k)**, rephrase the question, or check that the knowledge base holds the information.
