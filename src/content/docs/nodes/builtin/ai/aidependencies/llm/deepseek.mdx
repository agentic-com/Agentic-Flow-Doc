## What it does

Chat DeepSeek is a model you plug into the **Model** slot of an AI node, such as the [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/) or [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/). It does not run on its own and has no output. When the AI node runs, it sends its messages to DeepSeek with your key and gets the reply back.

- **Temperature** is 0 when you leave it empty, so answers are focused and repeatable.
- Replies are capped at **Max Tokens** (4096 by default).
- A failed request is retried up to **Max Retries** times (2 by default). A request that gets no answer within 60 seconds fails.

## When to use it

- Everyday text jobs at a low price per token: use `deepseek-chat`.
- Problems that need step-by-step thinking, such as maths or logic: use `deepseek-reasoner`.
- You want an alternative to OpenAI or Anthropic with your own DeepSeek account.

In **Authentication**, use a Bearer Token credential that holds your DeepSeek API key. Create the key on the API keys page of the DeepSeek platform. See [Create a credential](/app/connections/create/).

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on selected text.
2. [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/) with **Prompt** `Check this calculation step by step and give the correct result: {{ $input.selectionText }}`.
3. Chat DeepSeek in its **Model** slot, **Model** `deepseek-reasoner`, **Max Tokens** `8000`.
4. [Clipboard Write](/nodes/extension/clipboardwrite/) with **Text** `{{ $input.response }}`.

## Common issues

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **A 401 error.** The key is wrong or revoked. Create a new key and update the credential.
- **A 402 or "insufficient balance" error.** Top up your DeepSeek account.
- **The request times out.** A reasoning model can think for a long time. Try `deepseek-chat`, or a shorter prompt.
