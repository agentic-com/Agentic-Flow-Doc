Leverage Anthropic to use LLM locally directly on your device

## What it does

Provides access to Anthropic's Claude models for AI agent nodes.

## When to use it

Connect this to AI agents when you want to use Claude models for their strong reasoning and analysis capabilities.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Text |  | Yes | The model to use. |
| **Authentication** | Credential |  | Yes | Use a JWT Token. |
| **Options** | Group |  | No | The options to use with the model. |
| Options › **Temperature** | Number |  | No | The temperature to use for the model. |
| Options › **Max Retries** | Number | 2 | No | The maximum number of retries to use for the model. |
| Options › **Max Tokens** | Number | 4096 | No | The most tokens the model may generate in one reply. Defaults to 4096, which keeps providers from reserving credit for the whole output window. |
{/* AUTO:settings:end */}

## Example workflow

Connect Chat Anthropic to an AI agent or dependency input that accepts this dependency type, then run the agent with data from previous nodes.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
