## What it does

Chat Azure OpenAI is a model you plug into the **Model** slot of an AI node, such as the [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/) or [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/). It does not run on its own and has no output. When the AI node runs, it sends its messages to your Azure OpenAI resource and gets the reply back.

- **Temperature** is 0 when you leave it empty, so answers are focused and repeatable.
- Replies are capped at **Max Tokens** (4096 by default).
- A failed request is retried up to **Max Retries** times (2 by default). A request that gets no answer within 60 seconds fails.

## When to use it

- Your company gives you access to GPT models through Azure rather than through OpenAI directly.
- Your data must stay in your organisation's Azure region and contract.

With a personal OpenAI account, use [Chat OpenAI](/nodes/builtin/ai/aidependencies/llm/openai/) instead.

You find the values in the Azure portal, on your Azure OpenAI resource:

- **Resource Name**: the name of the resource, the first part of its endpoint. For `https://my-azure-openai.openai.azure.com`, it is `my-azure-openai`.
- **Deployment Name**: the name you gave the model deployment in the resource (not always the same as the model name).
- **Model**: the model behind that deployment, for example `gpt-4o`.
- **API Version**: leave `2024-10-21` unless your administrator tells you otherwise.

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on selected text.
2. [Information Extractor](/nodes/builtin/ai/aiagents/informationextractornode/) with **Text** `{{ $input.selectionText }}` and **What to extract** `the person's name, company and email address`.
3. Chat Azure OpenAI in its **Model** slot: **Resource Name** `my-azure-openai`, **Deployment Name** `gpt-4o`, **Model** `gpt-4o`.
4. The contact details come out in the `extracted` field, ready for a spreadsheet or CRM node.

## Common issues

- **"Resource Name parameter is required and cannot be empty"** or **"Deployment Name parameter is required and cannot be empty".** Fill in both fields from the Azure portal.
- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **A "DeploymentNotFound" or 404 error.** **Deployment Name** does not match a deployment in that resource, or the deployment is still being created. Copy the exact name from the portal.
- **A 401 error.** The key belongs to another resource, or was regenerated. Copy a current key from **Keys and Endpoint**.
