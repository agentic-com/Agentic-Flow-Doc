## What it does

Chat xAI (Grok) is a model you plug into the **Model** slot of an AI node, such as the [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/) or [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/). It does not run on its own and has no output. When the AI node runs, it sends its messages to xAI with your key and gets Grok's reply back.

- **Temperature** is 0 when you leave it empty, so answers are focused and repeatable.
- Replies are capped at **Max Tokens** (4096 by default).
- A failed request is retried up to **Max Retries** times (2 by default). A request that gets no answer within 60 seconds fails.

## When to use it

- You want to use Grok models in a workflow.
- You already have xAI credit and want to use it for writing, summarising or agents.

## Outputs

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on selected text.
2. [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/) with **Prompt** `Write a short, friendly reply to this message: {{ $input.selectionText }}`.
3. Chat xAI (Grok) in its **Model** slot, **Model** `grok-2-latest`.
4. [Clipboard Write](/nodes/extension/clipboardwrite/) with **Text** `{{ $input.response }}`.

## Common issues

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **A 401 or 403 error.** The key is wrong, revoked, or your team has no credit. Check the xAI console and update the credential.
- **A "model not found" error.** The model id is old or misspelled. Copy a current one from xAI's model list.
- **The answer stops mid-sentence.** It hit **Max Tokens**. Raise it under **Options**.
