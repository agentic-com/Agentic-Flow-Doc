Give an AI node access to Mistral AI's open and frontier models, using your own Mistral API key.

## What it does

Chat Mistral is a model you plug into the **Model** slot of an AI node, such as the [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/) or [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/). It does not run on its own and has no output. When the AI node runs, it sends its messages to Mistral with your key and gets the reply back.

- **Temperature** is 0 when you leave it empty, so answers are focused and repeatable.
- Replies are capped at **Max Tokens** (4096 by default).
- A failed request is retried up to **Max Retries** times (2 by default). A request that gets no answer within 60 seconds fails.

## When to use it

- You prefer a European AI provider.
- Writing and translating text in a workflow with your Mistral account.
- A small, cheap model for simple jobs and a large one for harder ones, from the same provider.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Text |  | Yes | The Mistral model to use, e.g. mistral-large-latest. |
| **Authentication** | Credential |  | Yes | Use your Mistral API key as a Bearer token. |
| **Options** | Group |  | No | The options to use with the model. |
| Options › **Temperature** | Number |  | No | The temperature to use for the model. |
| Options › **Max Retries** | Number | 2 | No | The maximum number of retries to use for the model. |
| Options › **Max Tokens** | Number | 4096 | No | The most tokens the model may generate in one reply. Defaults to 4096, which keeps providers from reserving credit for the whole output window. |
{/* AUTO:settings:end */}

Type the **Model** id as Mistral names it, for example `mistral-large-latest` or `mistral-small-latest`. The `-latest` ids always point to the newest version.

## Dependencies and credentials

{/* AUTO:deps:start */}
- **Authentication** (credential): required. Pick a saved connection or create one from this field.
{/* AUTO:deps:end */}

In **Authentication**, use a Bearer Token credential that holds your Mistral API key. Create the key on the API Keys page of the Mistral console (La Plateforme). See [Create a credential](/usage/using-the-app/credentials/create/).

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on selected text.
2. [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/) with **Prompt** `Translate into French, keep the tone: {{ $input.selectionText }}`.
3. Chat Mistral in its **Model** slot, **Model** `mistral-small-latest`.
4. [Clipboard Write](/nodes/extension/clipboardwrite/) with **Text** `{{ $input.response }}`.

## Troubleshooting

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **A 401 error.** The key is wrong or revoked. Create a new key and update the credential.
- **A 429 error.** You hit your plan's rate limit. Send fewer items at once, or upgrade the plan.
- **An "invalid model" error.** The model id is misspelled. Copy it from Mistral's model list.
