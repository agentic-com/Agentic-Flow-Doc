Give an AI node access to hundreds of models from many providers (Anthropic, OpenAI, Google, Meta, Mistral and more) with one OpenRouter API key.

## What it does

Chat OpenRouter is a model you plug into the **Model** slot of an AI node, such as the [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/) or [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/). It does not run on its own and has no output. When the AI node runs, it sends its messages to OpenRouter, which passes them to the model you chose and returns the reply. You pay OpenRouter, from one balance, whatever the model.

- **Temperature** is 0 when you leave it empty, so answers are focused and repeatable.
- Replies are capped at **Max Tokens** (4096 by default). This also stops OpenRouter from reserving credit for a model's whole output window, which can fail on a small balance.
- A failed request is retried up to **Max Retries** times (2 by default). A request that gets no answer within 60 seconds fails.

## When to use it

- You want to try or compare models from several providers without an account at each.
- You want one bill and one key for all your AI nodes.
- You want free or very cheap models that OpenRouter lists.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Text |  | Yes | The OpenRouter model slug, e.g. anthropic/claude-3.5-sonnet. |
| **Authentication** | Credential |  | Yes | Use your OpenRouter API key as a Bearer token. |
| **Options** | Group |  | No | The options to use with the model. |
| Options › **Temperature** | Number |  | No | The temperature to use for the model. |
| Options › **Max Retries** | Number | 2 | No | The maximum number of retries to use for the model. |
| Options › **Max Tokens** | Number | 4096 | No | The most tokens the model may generate in one reply. Defaults to 4096, which keeps providers from reserving credit for the whole output window. |
{/* AUTO:settings:end */}

**Model** is OpenRouter's model slug, in the form `provider/model`, for example `anthropic/claude-3.5-sonnet`. Copy it from the model's page on OpenRouter.

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger on selected text.
2. [Sentiment Analysis](/nodes/builtin/ai/aiagents/sentimentanalysisnode/) with **Text** `{{ $input.selectionText }}`.
3. Chat OpenRouter in its **Model** slot, **Model** `anthropic/claude-3.5-sonnet`.
4. [Browser Notification](/nodes/extension/browsernotification/) with **Message** `{{ $input.sentiment }}`.

## Troubleshooting

- **"Model parameter is required and cannot be empty".** Fill in **Model**.
- **A 402 error.** Your OpenRouter balance is too low for the request. Add credit, or lower **Max Tokens**.
- **A "not a valid model ID" error.** The slug is wrong. Copy it exactly from OpenRouter, including the `provider/` part.
- **A 401 error.** The key is wrong or deleted. Create a new key and update the credential.
