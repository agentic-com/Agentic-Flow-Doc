# Chrome AI

Leverage Chrome AI to use LLM directly on your device

## What it does

Provides access to Chrome's built-in AI models running locally in the browser.

## When to use it

Connect this to AI agents for fast, privacy-focused AI that runs entirely in Chrome without external API calls.
