Leverage Chrome AI to use LLM directly on your device

## What it does

Provides access to Chrome's built-in AI models running locally in the browser.

## When to use it

Connect this to AI agents for fast, privacy-focused AI that runs entirely in Chrome without external API calls.

**Chrome only.** This node uses the AI built into Google Chrome. It doesn't work in Firefox: there, use an on-device model (WebLLM or Transformers.js, see [Local models](/usage/using-the-app/local-models/)) or a cloud AI provider instead.

## Troubleshooting

- **Stopping a run.** **Stop** interrupts the node while Gemini Nano is still answering; the reply is cancelled.
- **In Firefox it fails with "only works in Chrome".** That's expected: Firefox doesn't include Chrome's built-in AI. Switch to an on-device or cloud model.
- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
- No dedicated source test was found next to this node; verify behavior manually when changing this page.
