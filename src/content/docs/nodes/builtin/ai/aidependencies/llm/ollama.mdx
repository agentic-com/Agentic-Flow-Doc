Leverage OLLAM to use LLM locally directly on your device

## What it does

Provides access to locally-run Ollama models for AI agent nodes without external API calls.

## When to use it

Connect this to AI agents when you want to use local, privacy-focused LLMs running on your machine via Ollama.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Model picker |  | Yes | The model to use. |
| **Options** | Group |  | No | The options to use with the model. |
| Options › **Temperature** | Number |  | No | The temperature to use for the model. |
| Options › **Max Retries** | Number | 2 | No | The maximum number of retries to use for the model. |
| Options › **Max Tokens** | Number | 4096 | No | The most tokens the model may generate in one reply. Defaults to 4096, which keeps providers from reserving credit for the whole output window. |

## Troubleshooting

- **Ollama refuses the request (403 / CORS error):** Ollama only answers browser origins it allows. Start it with the extension's origin allowed:
  - **Chrome:** `OLLAMA_ORIGINS=chrome-extension://linlkeaipfpnhddjkpcbmldionajfifa ollama serve`
  - **Firefox:** `OLLAMA_ORIGINS=moz-extension://* ollama serve` (a Firefox add-on's origin is different on every install)
- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
