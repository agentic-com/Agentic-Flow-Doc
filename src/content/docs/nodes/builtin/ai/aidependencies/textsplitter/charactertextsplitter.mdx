Breaks down text into smaller parts.

## What it does

Splits text into fixed-size chunks based on character count.

## When to use it

Connect this to indexer nodes when you need simple, predictable text chunking for document processing.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Chunk Size** | Number | 1000 | No | The size of each chunk. |
| **Separator** | Text |  | No | The separator to use. |
| **Chunk Overlap** | Number | 200 | No | The overlap between chunks. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
This node has no output port. It plugs into a slot on another node instead of passing items along.
