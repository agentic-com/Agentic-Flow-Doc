Breaks down text into smaller parts.

## What it does

Splits text intelligently by trying multiple separators (paragraphs, sentences, words) to maintain context.

## When to use it

Connect this to indexer nodes for better text chunking that preserves semantic meaning and document structure.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Chunk Size** | Number | 1000 | No | The size of each chunk. |
| **Chunk Overlap** | Number | 200 | No | The overlap between chunks. |
| **Separators** | Tags |  | No | The separators to use. |
| **Language** | Choice |  | No | The language of the text. 16 options. |
{/* AUTO:settings:end */}

## Outputs
