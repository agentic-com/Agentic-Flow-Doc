# Recursive Character Text Splitter

Breaks down text into smaller parts.

## What it does

Splits text intelligently by trying multiple separators (paragraphs, sentences, words) to maintain context.

## When to use it

Connect this to indexer nodes for better text chunking that preserves semantic meaning and document structure.
