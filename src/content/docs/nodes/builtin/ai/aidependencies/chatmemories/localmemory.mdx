:::caution[Deprecated: replaced by Chat Memory]
Local Memory is no longer in the node palette. Use [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: Conversation** instead. Existing workflows keep running.
:::

Gave an agent a saved conversation history, picked from your conversations.

## What it does

Workflows that already use Local Memory keep working, with the same conversation and history. The node now runs as a [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: Conversation** and the conversation you had picked. When you open the workflow, the node shows that it was upgraded from Local Memory; saving the workflow turns it into a Chat Memory node.

## When to use it

Don't add it to new workflows. Use [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/).

## Example workflow

1. Open a workflow that uses Local Memory, for example a [Chat Trigger](/nodes/builtin/trigger/chat/) with a [Tools Agent](/nodes/builtin/ai/aiagents/toolsagentnode/).
2. Save it. The node becomes a Chat Memory with **Storage: Conversation** and the same conversation.
3. Chat as before: the history is still there.

## Troubleshooting

- **I can't find Local Memory in the node list.** It was replaced. Add [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) instead.
- **Where is the conversation?** On the [Memory page](/app/memory/overview/), under **Workflows**.
