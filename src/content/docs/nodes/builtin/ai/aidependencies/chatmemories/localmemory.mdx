# Local Memory (replaced)

:::caution[Replaced by Chat Memory]
Local Memory is no longer in the node palette. Use [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: Conversation** instead.
:::

## What happens to existing workflows

Workflows that already use Local Memory **keep working**, with the same conversation and the same history:

- The node runs through Chat Memory with **Storage: Conversation** and the conversation you had picked.
- When you open the workflow, the node shows that it was **upgraded from Local Memory**. Saving the workflow turns it into a Chat Memory node.
- **Summarise older messages** stays off, as before; turn it on in Chat Memory if you want it.

| Local Memory setting | Chat Memory setting |
| --- | --- |
| Memory (the picked conversation) | **Storage: Conversation**, same conversation |

The conversation is listed on the [Memory page](/usage/using-the-app/memory/overview/) under **Workflows**.
