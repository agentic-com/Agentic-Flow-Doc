# Window Buffer Memory (replaced)

:::caution[Replaced by Chat Memory]
Window Buffer Memory is no longer in the node palette. Use [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: This run only** instead.
:::

## What happens to existing workflows

Workflows that already use Window Buffer Memory **keep working**:

- The node runs through Chat Memory with **Storage: This run only** and **History sent to the model: Last N messages**, where N is twice the old window size *k* (a question and its answer are two messages). With the default *k* of 5, that is the last 10 messages.
- The conversation is now really kept for the length of the run — the old node didn't remember anything. Nothing is saved after the run.
- When you open the workflow, the node shows that it was **upgraded from Window Buffer Memory**. Saving the workflow turns it into a Chat Memory node.

| Window Buffer Memory setting | Chat Memory setting |
| --- | --- |
| Window Size (k) | **Storage: This run only**, **Last N messages** with N = 2 × k |

Because nothing is saved, it still can't give a [Chat Trigger](/nodes/builtin/trigger/chat/) a chat history. Use **Conversation** or **Key** storage for that.
