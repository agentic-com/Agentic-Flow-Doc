:::caution[Deprecated: replaced by Chat Memory]
Persistent Chat Memory is no longer in the node palette. Use [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: Key** instead. Existing workflows keep running.
:::

Gave an agent a conversation history saved under a key.

## What it does

Workflows that already use Persistent Chat Memory keep working, with the same key and history. The node now runs as a [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: Key**, your conversation key, and **Key scope: Shared**: old keys were shared by every workflow, and they stay that way. When you open the workflow, the node shows that it was upgraded; saving the workflow turns it into a Chat Memory node.

Conversations saved under a key used to be invisible in the app. They now appear on the [Memory page](/app/memory/overview/) under **Workflows**, marked **Recovered**.

## When to use it

Don't add it to new workflows. Use [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: Key**, and prefer **Key scope: This workflow** unless several workflows really need to share the conversation.

## Example workflow

1. Open a workflow that uses Persistent Chat Memory with the key `support-bot`.
2. Save it. The node becomes a Chat Memory with **Storage: Key**, **Key** `support-bot` and **Key scope: Shared**.
3. Run it as before: the agent continues the same conversation.

## Common issues

- **"Conversation Key is required".** The key is empty. Fill in **Key** on the Chat Memory.
- **Two workflows share a conversation.** They use the same key with **Shared** scope, as the old node did. Switch one to **This workflow** if they should be separate.
