:::caution[Replaced by Chat Memory]
Persistent Chat Memory is no longer in the node palette. Use [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) with **Storage: Key** instead.
:::

## What happens to existing workflows

Workflows that already use Persistent Chat Memory **keep working**, with the same key and the same history:

- The node runs through Chat Memory with **Storage: Key**, your conversation key, and **Key scope: Shared** — old keys were shared by every workflow, and they stay that way.
- When you open the workflow, the node shows that it was **upgraded from Persistent Chat Memory**. Saving the workflow turns it into a Chat Memory node.
- **Summarise older messages** stays off, as before; turn it on in Chat Memory if you want it.

| Persistent Chat Memory setting | Chat Memory setting |
| --- | --- |
| Conversation Key | **Storage: Key**, same key, **Key scope: Shared** |

Conversations saved under a key used to be invisible in the app. They now appear on the [Memory page](/usage/using-the-app/memory/overview/) under **Workflows**, marked **Recovered**.

For a new workflow, prefer **Key scope: This workflow** unless several workflows really need to share the conversation.
