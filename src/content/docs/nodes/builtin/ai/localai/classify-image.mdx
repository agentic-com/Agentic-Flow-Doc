Label an image **entirely in your browser** with an installed image-classification model (MobileNet on TensorFlow.js, ViT on transformers.js). No cloud call, no cost, no data leaving the device.

## What it does

Loads the image you provide, runs it through the selected on-device classifier, and returns the predicted labels with confidence scores — filtered by a threshold and capped to the top results.

## When to use it

Tag or route images by content: sort uploads, flag categories, or branch a workflow on what an image contains — all offline and private.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Model picker |  | No | Any installed image-classification model, across engines. |
| **Image** | Media |  | No | Image URL, data URL, or $binary from a previous node. |
| **Confidence threshold** | Number | 0.1 | No | Drop predictions below this score. |
| **Top-K results** | Number | 5 | No |  |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has these fields:

| Field | Type | Description |
| --- | --- | --- |
| `predictions` | List of entries | Labels above the threshold, best first |
| `top` | Text | The best label, or null when none passed |
| `score` | Number |  |
{/* AUTO:outputs:end */}

Returns `{ predictions, top, score }`:

- `predictions` — array of `{ label, score }`, highest first, after threshold and top-K.
- `top` — the highest-scoring label (or `null` if none pass the threshold).
- `score` — that label's score.

## Before you run

Install an image-classification model from the picker or the [Local AI](/usage/using-the-app/local-models/) page. The first run loads the model into memory; later runs are fast.

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Troubleshooting

- **Empty picker** — no image-classification model is installed; add one first.
- **No predictions** — lower the confidence threshold, or try a stronger model (ViT over MobileNet).
- **Slow first run** — the model is loading/downloading; it stays warm for the session.
