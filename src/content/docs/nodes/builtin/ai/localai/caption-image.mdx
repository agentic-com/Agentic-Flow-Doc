Describe an image in a short sentence with a model that runs in your browser, so the image never leaves your device.

## What it does

Caption Image runs the **Image** through an image-to-text model, such as *ViT-GPT2 captioning*, and returns one caption, for example "a dog sitting on a couch". The image can be a web address, a data URL, raw base64, or a file passed from an earlier node. There is no cost per run and no API key.

Captioning models are small: expect a short, plain description, not a detailed analysis.

## When to use it

- Write draft alt text for images on a page.
- Turn a screenshot or photo into words that a text step can store, search or summarize.

To get labels with scores, use [Classify Image](/nodes/builtin/ai/localai/classify-image/). To count or locate things, use [Detect Objects](/nodes/builtin/ai/localai/detect-objects/).

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Model picker |  | No | Any installed image-captioning model. |
| **Image** | Media |  | No | Image URL, data URL, or $binary from a previous node. |
{/* AUTO:settings:end */}

**Image** has four tabs. **From input** takes an expression that points to an image from an earlier node, such as `{{ $input.dataUrl }}` after [Screenshot Page](/nodes/extension/screenshotpage/) or `{{ $binary }}` for an attached file. **URL** takes a web address. **Upload** and **Base64** store a fixed image with the node, handy for trying a model.

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has the fields `text` (text).
{/* AUTO:outputs:end */}

`text` is the caption. Use it as `{{ $input.text }}` in the next node.

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

The **Model** picker lists your installed models first, then models that download on first use. Manage them on the [Local AI](/usage/using-the-app/local-models/) page.

## Example workflow

Copy alt text for any image you right-click:

1. [Context Menu](/nodes/builtin/trigger/contextmenu/) with **Menu Contexts** set to **Image**.
2. Caption Image with **Model** *ViT-GPT2 captioning* and **Image** (From input) `{{ $input.srcUrl }}`.
3. [Clipboard Write](/nodes/extension/clipboardwrite/) with **Text** `{{ $input.text }}`.

## Troubleshooting

- **"Choose a captioning model."** **Model** is empty. Pick one.
- **"No image provided. Pass an image URL, a data URL, or a $binary image from a previous node."** **Image** is empty, or its expression returned nothing. Check that the field you point to exists on the incoming item.
- **The caption is vague or off.** Small captioning models miss details. Crop to the subject with [Edit Image](/nodes/builtin/datatransformation/editimage/), or use [Classify Image](/nodes/builtin/ai/localai/classify-image/) for labels.
- **The first run is slow.** The model downloads and loads on first use; later runs are fast.
