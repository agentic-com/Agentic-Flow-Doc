Summarize, translate, or transform text locally in your browser with a sequence-to-sequence model (DistilBART for summarization, NLLB for translation, T5 for general transforms, on transformers.js). Private, offline, no cost.

## What it does

Runs the input text through the selected on-device text-generation model. What it *does* depends on the model you pick — a summarizer condenses, a translation model translates, a T5 model follows a task prefix.

## When to use it

Add offline summarization or translation to a workflow, or run a small text transform without an LLM API key or per-token cost.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Model picker |  | No | Any installed text-generation model, across engines. |
| **Text** | Text |  | No |  |
| **Source language** | Text |  | No | For translation models (e.g. eng\_Latn). |
| **Target language** | Text |  | No | For translation models (e.g. fra\_Latn). |
{/* AUTO:settings:end */}

Source/target language are passed through to translation models (such as NLLB); other models ignore them.

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has the fields `text` (text).
{/* AUTO:outputs:end */}

Returns `{ text }` — the generated / summarized / translated text.

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Troubleshooting

- **Translation ignored** — set both Source and Target language in the codes the model expects (e.g. NLLB's `xxx_Yyyy` form).
- **Truncated output** — small on-device models have short context/output limits; split long inputs upstream.
