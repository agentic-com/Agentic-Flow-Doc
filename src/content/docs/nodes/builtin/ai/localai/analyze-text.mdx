Classify text — **sentiment, toxicity, or moderation** — locally in your browser (DistilBERT-SST2, toxic-bert on transformers.js). Private, offline, no cost.

## What it does

Runs the text through the selected on-device classifier and returns the matching labels with confidence scores, filtered by a threshold and capped to the top results.

## When to use it

Moderate user-generated content, gauge feedback tone, or gate a workflow branch on toxicity — without sending the text to a third-party API.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Model** | Model picker |  | No | Any installed text-moderation model, across engines. |
| **Text** | Text |  | No | The text to analyze. |
| **Confidence threshold** | Number | 0 | No |  |
| **Top-K labels** | Number | 5 | No |  |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has these fields:

| Field | Type | Description |
| --- | --- | --- |
| `predictions` | List of entries | Labels above the threshold, best first |
| `top` | Text | The best label, or null when none passed |
| `score` | Number |  |
{/* AUTO:outputs:end */}

Returns `{ predictions, top, score }`:

- `predictions` — array of `{ label, score }`, highest first.
- `top` — the highest-scoring label (or `null`).
- `score` — that label's score.
