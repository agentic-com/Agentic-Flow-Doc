**Perfect for:** User-friendly displays • Report generation • API formatting • Localization

## What It Does

- **Change date formats** - Convert between different date string formats
- **Localize dates** - Display dates in different languages and regions
- **Custom patterns** - Create your own date format patterns
- **Timezone conversion** - Apply timezone changes during formatting

## Common Format Examples

- **User Friendly**: Convert `2024-01-15T14:30:00Z` to **"January 15, 2024 at 2:30 PM"**.
- **Short Date**: Convert it to **"1/15/24"**.
- **Formal**: Convert to **"Monday, January 15, 2024"**.
- **Standard (ISO)**: Convert "January 15, 2024" back to machine-readable **"2024-01-15"**.

## Format Presets

| Preset | Example Output | Best For |
|--------|----------------|----------|
| `"human"` | "January 15, 2024 at 2:30 PM" | User interfaces |
| `"short"` | "1/15/24" | Compact displays |
| `"medium"` | "Jan 15, 2024" | Reports |
| `"long"` | "January 15, 2024" | Formal documents |
| `"ISO"` | "2024-01-15T14:30:45Z" | APIs and databases |
| `"date_only"` | "2024-01-15" | Date without time |
| `"time_only"` | "2:30 PM" | Time without date |

## Custom Format Patterns

**Create your own formats using these tokens:**

| Token | Description | Example |
|-------|-------------|---------|
| `YYYY` | 4-digit year | 2024 |
| `MM` | 2-digit month | 01 |
| `DD` | 2-digit day | 15 |
| `MMMM` | Full month name | January |
| `MMM` | Short month name | Jan |
| `dddd` | Full day name | Monday |
| `HH` | 24-hour format | 14 |
| `hh` | 12-hour format | 02 |
| `mm` | Minutes | 30 |
| `A` | AM/PM | PM |

**Example custom pattern:**
```json
{
  "output_format": "dddd, MMMM D, YYYY [at] h:mm A"
}
```
**Result:** "Monday, January 15, 2024 at 2:30 PM"

## Quick Troubleshooting

**Format not working:** Check that your pattern tokens are correct (YYYY not yyyy)
**Wrong language:** Specify the locale parameter for non-English formats
**Timezone issues:** Set timezone parameter if dates appear in wrong time zone
