**What it does:** Extracts specific parts from dates like year, month, day, hour, or day of the week for filtering and analysis.

**Perfect for:** Date filtering • Analytics • Conditional logic • Time-based sorting

## What It Does

- **Extract date parts** - Get year, month, day, hour, minute from any date
- **Get day names** - Extract day of week (Monday, Tuesday, etc.)
- **Calculate derived values** - Get quarter, week number, day of year
- **Multiple extractions** - Get several date parts at once

## Common Extractions

**Basic date parts**
```json
["year", "month", "day"]
```

**Time components**
```json
["hour", "minute", "second"]
```

**Text-based parts**
```json
["month_name", "day_name"]
```

**Calculated values**
```json
["quarter", "week_of_year", "day_of_year"]
```

## Real Example

**Input Date:**
January 15, 2024 at 2:30 PM (which falls on a Monday).

**The Extraction:**
You ask the node to pull out:
- Year
- Month
- Day
- Day Name
- Hour

**Result:**
```json
{
  "year": 2024,
  "month": 1,
  "day": 15,
  "day_name": "Monday",
  "hour": 14
}
```

## Practical Use Cases

**Filter by weekday:**
- Extract `day_name` to filter only weekday data
- Skip weekend entries in business reports

**Seasonal analysis:**
- Extract `quarter` to group data by business quarters
- Extract `month_name` for monthly comparisons

**Time-based sorting:**
- Extract `hour` to analyze peak usage times
- Extract `week_of_year` for weekly trends

## Available Date Parts

| Part | Description | Example |
|------|-------------|---------|
| `year` | Four-digit year | 2024 |
| `month` | Month number (1-12) | 1 |
| `month_name` | Full month name | "January" |
| `day` | Day of month | 15 |
| `day_name` | Full day name | "Monday" |
| `hour` | Hour (0-23) | 14 |
| `minute` | Minute (0-59) | 30 |
| `quarter` | Quarter (1-4) | 1 |
| `week_of_year` | Week number | 3 |
| `is_weekend` | True/false | false |

## Common Use Cases

**Business analytics** - Extract quarters and months for financial reporting
**User behavior analysis** - Extract hours and days to find usage patterns
**Content filtering** - Extract day names to show only weekday content
**Seasonal campaigns** - Extract months to trigger seasonal marketing

## Quick Troubleshooting

**Wrong timezone results:** Specify timezone if your dates are in different time zones
**Missing parts:** Check that the date format is recognized (use ISO format when possible)
**Locale issues:** Specify locale for month/day names in different languages
