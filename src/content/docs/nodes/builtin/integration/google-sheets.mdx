# Google Sheets

Integrate with Google Sheets to perform operations on spreadsheets and data.

## What it does

Google Sheets belongs to the **Integration** palette group. Its canonical node id is `googleSheets` and its source documentation link is `/nodes/builtin/integration/google-sheets/`.

## When to use it

Use Google Sheets when the workflow needs to call this external service with configured credentials.
