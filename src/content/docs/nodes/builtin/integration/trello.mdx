## What it does

The Trello node works on three kinds of things (**Resource**):

- **Card**: create a card in a list, change its title or description, move it to another list, or attach a link to it.
- **Board**: list your boards, to find a **Board ID**.
- **List**: list the lists (columns) of a board, to find a **List ID**.

When you fill **Source URL** on **Card → Create**, the node does two things: it adds a `Source:` line with the link to the end of the description, and it attaches the link to the card, so it shows in the card's attachments with a preview.

## When to use it

- Capture a page as a card in a "To read" or "Ideas" list.
- Add a card to a team board when a form is filled or a page changes.
- Move a card to "Done" when a workflow finishes the task.
- Attach a generated report or a related page to an existing card.

For personal to-dos, use [Todoist](/nodes/builtin/integration/todoist/). For software issues, use [Linear](/nodes/builtin/integration/linear/) or [GitHub](/nodes/builtin/integration/github/).

- **List ID** and **Target list ID** are the id of a list (a column), not of a board. Run **Board → List**, then **List → List** with your **Board ID**, and copy the `id` of the list.
- **Board ID** can also be the short code in a board's address: `https://trello.com/b/AbC123xY/my-board` gives `AbC123xY`.
- **Card ID** comes from the `id` of a **Card → Create** result, for example `{{ $('Trello').id }}`, or from the short code in a card's address (`https://trello.com/c/<code>/…`).
- **Position** puts the new card at the `Top` or `Bottom` of the list.

- **Card → Create**, **Update** and **Move** return the card, including its `id`, `name`, `desc`, `idList` and `url` (the link to open it in Trello).
- **Card → Attach URL** returns the new attachment, with its `id`, `name` and `url`.
- **Board → List** returns one item per board with `id`, `name` and `url`; **List → List** returns one item per list with `id` and `name`.

## Dependencies and credentials

{/* AUTO:deps:start */}
- **Credential** (connection, Basic Auth): required. See [Connect Trello](/app/connections/trello/).
{/* AUTO:deps:end */}

Trello uses an API key and a token, saved together as a Basic Auth credential:

1. Open [trello.com/app-key](https://trello.com/app-key) while signed in to Trello. If Trello asks you to create a Power-Up first, create one in its admin page; its **API key** tab gives you the key.
2. Copy the **API key**.
3. Next to the key, follow the **Token** link, allow access, and copy the token.
4. Create a Basic Auth credential with the API key as **Username** and the token as **Password**. See [Create a credential](/app/connections/create/).

The token can act on all your boards, so keep it private.

## Example workflow

1. A [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger adds "Add to Trello" to the right-click menu.
2. [Get Page Metadata](/nodes/extension/getpagemetadata/) reads the page's `title` and `url`.
3. Trello, **Card → Create**, **List ID** of your "Ideas" list, **Card title** `{{ $input.title }}`, **Source URL** `{{ $input.url }}`, **Position** `Top`.
4. [Browser Notification](/nodes/extension/browsernotification/) shows `Card added`, with the card's `{{ $input.url }}`.

## Common issues

- **"Trello needs a Basic Auth credential with the API key in Username and the token in Password."** The credential is missing a value or is not Basic Auth. Fill both fields.
- **"Trello API Error: 401 … the API key or token is invalid or expired".** The key and token do not belong together, are swapped, or the token was revoked. Generate a new token next to your key and update the credential.
- **"Trello API Error: 400 … invalid id".** A **List ID**, **Card ID** or **Board ID** is wrong. A board id was probably used where a list id is needed; use **List → List** to get list ids.
- **The run is blocked in the web app.** Trello runs through the browser extension. Install the extension and allow Trello for this workflow when asked, or run the workflow from the extension. See [Running extension-only integrations in the web app](/app/troubleshooting/extension-only-integrations-in-the-web-app/).
