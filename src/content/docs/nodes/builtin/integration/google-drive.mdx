Integrate with Google Drive to manage files and folders.

## What it does

Manages files and folders in Google Drive, including upload, download, search, and organization operations.

## When to use it

Use this node to automate file storage, backup workflows, or integrate document management into your processes.

## Dependencies and credentials

{/* AUTO:deps:start */}
- **Credential** (credential, OAuth2): required. Pick a saved connection or create one from this field.
{/* AUTO:deps:end */}

- Credential type: OAuth2 — create your own Google OAuth client first: [Create your OAuth client](/usage/using-the-app/credentials/oauth-client/#google).

## Example workflow

Connect prepared data into Google Drive, select the credential, choose the operation, then map previous node values into the operation fields.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
