# Notion

Integrate with Notion to perform operations on databases, pages, and blocks.

## What it does

Manages Notion databases, pages, and blocks through the Notion API.

## When to use it

Use this node to automate documentation, sync data to Notion, or build workflows around your Notion workspace.

## Attaching files and images to a page

**Block → Create** can append a **File** or **Image** block whose content comes
from a file attached to the incoming item (its `$binary` payload — as produced by
**HTTP Request**, **Local File Read**, **Convert to File**, and similar nodes).

1. Set **Block** to the ID of the page (or block) to append to.
2. Set **Block Type** to `File (from binary)` or `Image (from binary)`.
3. Set **Binary Field** to the `$binary` key holding the file (defaults to `data`).
4. Optionally set a **Caption**.

Under the hood the node uses Notion's file-upload API: it creates a file upload,
sends the file's bytes, then appends a block that references the completed upload.
The file's name and MIME type are taken from the binary attachment. If the incoming
item has no file under the chosen Binary Field, the node fails with a clear error so
you can fix the upstream step. These uploads run through the same delegated-fetch
path as the rest of the node, so File / Image blocks work both in the extension and
in the web app (with the extension installed and Notion's host consented).

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
- This node has source tests; use them as the reference for edge-case behavior during maintenance.

## Running in the web app

Notion's API cannot be called directly from a normal web page, so this node is
**extension-only** by default. If you use the **web app** but also have the awflow
**browser extension installed**, the web app can still run Notion by delegating its
calls to the extension — provided Notion's host is consented for the workflow. See
[Running Extension-Only Integrations in the Web App](/usage/troubleshooting/extension-only-integrations-in-the-web-app/).
