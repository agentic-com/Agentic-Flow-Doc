Integrate with Gmail to perform operations on messages and drafts.

## What it does

Sends, reads, and manages Gmail messages and drafts through the Gmail API.

## When to use it

Use this node to automate email workflows, send notifications, or process incoming messages.

## Attachments

The **Send** message operation can attach files carried by the incoming item's `$binary`
data (for example a file produced by a Google Drive, HTTP Request, or file-download node).
List the logical `$binary` keys to attach in the **Attachments** field — commonly `data`.
Each selected key is read from the item, and the email is built as a `multipart/mixed`
message with your body followed by one part per attachment. If a selected key has no
binary on the incoming item, the node fails with a clear error.
