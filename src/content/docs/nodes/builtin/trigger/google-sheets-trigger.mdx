Start the workflow when rows are added at the bottom of a Google Sheet.

:::note[A polling trigger]
It checks for new items on a timer while the workflow is **On**, in the browser extension. Read [Polling triggers](/concepts/flow/polling-triggers/) for the first check, test events and what happens when a check fails.
:::

## What it does

Every **Check every** minutes, the trigger reads the sheet and starts one run with the rows added since the last check. It watches the bottom of the sheet: edits to existing rows don't count. When rows are deleted, it starts again from the new bottom, with a warning, and never replays old rows.

A check that finds nothing new starts no run. Press **Run** to fetch a test event: the latest items, without moving the trigger's position.

## When to use it

- A form that writes to a sheet: act on each new answer.
- A shared sheet of leads: add each new lead to your CRM.

## Example workflow

1. New row on a *Signups* sheet.
2. [Gmail](/nodes/builtin/integration/gmail/) sends a welcome email to `{{ $input.email }}`.

## Common issues

- **"Choose a spreadsheet first."**: paste the spreadsheet's link in **Spreadsheet**.
- **An edited row didn't start a run**: only added rows count.
