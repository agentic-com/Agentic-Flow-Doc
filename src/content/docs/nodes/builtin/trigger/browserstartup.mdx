Run the flow when the browser starts.

## What it does

Triggers workflow execution automatically when the browser application starts.

## When to use it

Use this trigger to run initialization workflows or background tasks that should start with the browser.

## Inputs and settings

{/* AUTO:settings:start */}
This node has no settings.
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has the fields `triggerType` (choice), `triggeredAt` (text), `reason` (text), `startedAt` (any).
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Create a workflow with Browser Startup as the first node, then connect it to the action nodes that should run after the trigger fires.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
