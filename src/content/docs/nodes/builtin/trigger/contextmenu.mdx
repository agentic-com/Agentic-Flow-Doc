Run the flow from the browser context menu.

## What it does

Triggers workflow execution from the browser's right-click context menu on pages, links, or selected content.

## When to use it

Use this trigger to create custom context menu actions for quick access to workflows while browsing.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Menu Contexts** | Multiple choice | Page | No | Options: Page, Selection, Link, Editable Field, Image, Video, Audio. |
| **Document URL Patterns** | List |  | No | Optional browser match patterns for the page URL. |
| **Target URL Patterns** | List |  | No | Optional browser match patterns for link, image, video, or audio targets. |
{/* AUTO:settings:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Create a workflow with Context Menu as the first node, then connect it to the action nodes that should run after the trigger fires.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
