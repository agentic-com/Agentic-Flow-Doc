## What it does

An activated workflow with a Context Menu trigger shows up in the right-click menu under **Agentic Workflow**, then **Personal Workflows** (or **Downloaded Workflows** for ones you installed from the marketplace). The menu entry is the workflow's name.

The entry only appears where it fits: on the kinds of content picked in **Menu Contexts**, and, when you set them, only on matching pages (**Document URL Patterns**) or matching links and media (**Target URL Patterns**). Clicking it runs the workflow from this trigger, with the clicked text, link or image and the page details as output.

A workflow can have several Context Menu triggers with different settings, for example one for selected text and one for links. Only the triggers that match what you clicked run.

## When to use it

- Act on selected text: translate it, summarize it, save it, or send it to a chat.
- Act on a link: save it to a list or open it somewhere else.
- Act on an image: download it or send its address to a service.
- Run a workflow on the current page without opening AWFlow.

## Inputs and settings

{/* AUTO:settings:start */}
<AwfParamTable rows={[{"name":"Menu Contexts","type":"Multiple choice","default":"Page","description":"Options: Page, Selection, Link, Editable Field, Image, Video, Audio."},{"name":"Document URL Patterns","type":"List","description":"Optional browser match patterns for the page URL."},{"name":"Target URL Patterns","type":"List","description":"Optional browser match patterns for link, image, video, or audio targets."}]} />
{/* AUTO:settings:end */}

- **Menu Contexts** decides where you right-click. **Page** means a right-click on the page itself, **Selection** a right-click on selected text, **Editable Field** inside a text box, and so on.
- **Document URL Patterns** limits the entry to pages whose address matches, for example `https://*.wikipedia.org/*`. Leave it empty to show it everywhere.
- **Target URL Patterns** checks the address of the clicked link, image, video or audio instead, for example `https://*.youtube.com/*` to only offer the entry on YouTube links.

Patterns use the form `scheme://host/path` with `*` as a wildcard; see [Page Load](/nodes/builtin/trigger/pageload/#inputs-and-settings) for examples.

Which fields are filled depends on what you clicked:

- `selectionText`: the selected text (Selection).
- `linkUrl`: the address of the clicked link (Link).
- `srcUrl` and `mediaType`: the address and type (`image`, `video`, `audio`) of the clicked media.
- `editable`: true when you clicked inside a text field.
- `pageUrl`, `tabTitle`, `tabId`: the page and tab you were on.

Use them downstream, for example `{{ $input.selectionText }}`.

## Example workflow

Summarize selected text on any page:

1. Add **Context Menu** with **Menu Contexts** set to **Selection**.
2. Add [Summarize](/nodes/builtin/ai/localai/summarize/) with **Text** `{{ $input.selectionText }}` and **Length** **Short**.
3. Add [Browser Notification](/nodes/extension/browsernotification/) with **Title** `Summary` and **Message** `{{ $input.summary }}`.
4. Activate the workflow, select a paragraph on a page, right-click, and choose the workflow's name.

## Common issues

- **The workflow is not in the right-click menu.** Activate the workflow, then right-click and choose **Get / Refresh Workflows** so the menu picks up your changes. Also check that you right-clicked on the right kind of content: with only **Page** selected, the entry does not show on selected text or links.
- **The entry shows, but clicking it does nothing.** What you clicked did not match this trigger's contexts or patterns (the menu can show the entry more broadly than each trigger allows when a workflow has several Context Menu triggers). Check **Menu Contexts** and both pattern lists.
- **`selectionText` is empty.** **Selection** is not in **Menu Contexts**, or you right-clicked outside the selected text.
- **It does not work in the web app.** This node runs in the browser extension; install it and activate the workflow there.
