# Context Menu

Run the flow from the browser context menu.

## What it does

Context Menu belongs to the **Trigger** palette group. Its canonical node id is `contextMenu` and its source documentation link is `/nodes/builtin/trigger/contextmenu/`.

## When to use it

Use Context Menu when a workflow should start from this event instead of only from another node.
