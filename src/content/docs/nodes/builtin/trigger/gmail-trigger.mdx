Start the workflow when a new email arrives in Gmail: in the inbox, under a label, or matching a search.

:::note[A polling trigger]
It checks for new items on a timer while the workflow is **On**, in the browser extension. Read [Polling triggers](/concepts/flow/polling-triggers/) for the first check, test events and what happens when a check fails.
:::

## What it does

Every **Check every** minutes, the trigger looks at the newest 25 emails of the **Label** (the inbox when empty) that match the **Search**, and starts one run with the ones it hasn't seen yet.

A check that finds nothing new starts no run. Press **Run** to fetch a test event: the latest items, without moving the trigger's position.

## When to use it

- Save invoices from billing emails to Google Drive.
- Turn emails with a label into tasks.
- Get a notification when a specific sender writes.

## Example workflow

1. New email with **Search** `has:attachment subject:invoice`.
2. [Gmail](/nodes/builtin/integration/gmail/) gets the attachment.
3. [Google Drive](/nodes/builtin/integration/google-drive/) uploads it to an *Invoices* folder.

## Common issues

- **It misses some emails**: a check reads the newest 25 matching emails. With a busy inbox, check more often or narrow the **Search**.
- **Not working** on the connection: reconnect Gmail on the [Connections](/app/connections/) page.
