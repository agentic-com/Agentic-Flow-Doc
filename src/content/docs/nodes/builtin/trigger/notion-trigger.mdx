Start the workflow when a page is added to, or edited in, a Notion database.

:::note[A polling trigger]
It checks for new items on a timer while the workflow is **On**, in the browser extension. Read [Polling triggers](/concepts/flow/polling-triggers/) for the first check, test events and what happens when a check fails.
:::

## What it does

Every **Check every** minutes, the trigger reads the database's latest pages and starts one run with the new ones. With **Start a run when a page is** set to **Added or edited**, each edit counts again (two edits in the same minute are told apart).

A check that finds nothing new starts no run. Press **Run** to fetch a test event: the latest items, without moving the trigger's position.

## When to use it

- A content calendar: act when a new idea is added.
- A task database: notify someone when a page changes.

## Example workflow

1. New or updated page on a *Requests* database, **Added**.
2. [Slack](/nodes/builtin/integration/slack/) posts the page title and link.

## Common issues

- **"Choose a database first."**: paste the database's link in **Database**.
- **Nothing runs**: the database isn't shared with the integration your connection uses.
