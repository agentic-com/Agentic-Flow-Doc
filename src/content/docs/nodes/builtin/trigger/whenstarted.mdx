Start a workflow by hand, whenever you choose to run it.

## What it does

When Started waits for nothing. The workflow runs when you click **Test Workflow** in the designer, run it from the workflow list, or press the trigger's own run button. The trigger has no settings and passes `{ "started": true }` to the next node.

A workflow whose only trigger is When Started also appears in the browser's right-click menu (under **Personal Workflows**), so you can run it on the page you are looking at.

If a workflow has several triggers, clicking **Test Workflow** asks you which one to start from. Only the branch after the chosen trigger runs.

## When to use it

- Try out a new workflow while you build it.
- Run a workflow on demand: clean up tabs, export data, send a one-off message.
- Keep a manual entry point next to an automatic trigger, so you can test the same steps without waiting for the event.

To run on a timer, use [Schedule](/nodes/builtin/trigger/schedule/). To run from a keyboard shortcut, use [Hotkey](/nodes/builtin/trigger/hotkey/).

## Example workflow

Save the text of the current page:

1. Add **When Started**.
2. Add [Get All Text](/nodes/extension/getalltext/) with **Output field name** `text` to read the page you have open.
3. Add [Data Store](/nodes/builtin/core/datastore/) with **Operation** set to **Set**, **Key** `last-page-text` and **Value** `{{ $input.text }}`.
4. Open the page you want, then click **Test Workflow**.

## Troubleshooting

- **The workflow does not run on its own.** That is expected: When Started only runs when you start it. Add an automatic trigger such as [Schedule](/nodes/builtin/trigger/schedule/) or [Page Load](/nodes/builtin/trigger/pageload/) and activate the workflow.
- **A "Choose a trigger to run" dialog opens.** The workflow has more than one trigger. Pick When Started to run the branch that follows it.
- **The workflow is missing from the right-click menu.** It also has an automatic trigger (such as Schedule or Page Load), or it is not activated. Right-click and choose **Get / Refresh Workflows** after changing it.
