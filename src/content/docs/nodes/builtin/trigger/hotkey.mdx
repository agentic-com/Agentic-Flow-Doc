Run a workflow from a keyboard shortcut, wherever you are in the browser.

## What it does

The AWFlow extension offers four shortcut slots, **Hotkey slot 1** to **Hotkey slot 4**. In the node you pick a slot; in your browser's shortcut settings you choose which keys press that slot. When you press the keys, every activated workflow whose Hotkey trigger uses that slot runs from this trigger.

Browsers do not let an extension create a new shortcut for each workflow, which is why there are fixed slots. Slot 1 comes with a suggested shortcut, **Ctrl+Shift+1** (**Command+Shift+1** on Mac). Slots 2 to 4 have no keys until you set them.

## When to use it

- Workflows you run many times a day, such as saving the current page or copying a formatted link.
- Actions on the page you are reading, without opening a menu.
- A fast manual start next to an automatic trigger.

To start from a right-click instead, use [Context Menu](/nodes/builtin/trigger/contextmenu/).

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Hotkey Slot** | Choice | Hotkey slot 1 | No | Which keyboard-shortcut slot fires this trigger. Assign the actual key combo at chrome://extensions/shortcuts. Options: Hotkey slot 1, Hotkey slot 2, Hotkey slot 3, Hotkey slot 4. |
{/* AUTO:settings:end */}

To choose the keys for a slot:

- **Chrome and other Chromium browsers:** open `chrome://extensions/shortcuts`.
- **Firefox:** open `about:addons`, click the gear menu, then **Manage Extension Shortcuts**.

Find **Agentic Workflow**, then the line **Run workflow bound to Hotkey slot 2** (or the slot you picked), and type your key combination.

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has the fields `triggerType` (always "hotkey"), `triggeredAt` (text), `command` (text).
{/* AUTO:outputs:end */}

`command` names the slot that fired, from `run-workflow-1` to `run-workflow-4`. The output does not include the page you were on; add a node such as [Get Selected Text](/nodes/extension/getselectedtext/) to read from it.

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Copy the selected text with one shortcut:

1. Add **Hotkey** with **Hotkey Slot** set to **Hotkey slot 2**.
2. Add [Get Selected Text](/nodes/extension/getselectedtext/) with **Output field name** `selection`.
3. Add [Clipboard Write](/nodes/extension/clipboardwrite/) with **Text** `{{ $input.selection }}`.
4. Activate the workflow, then set the keys for **Run workflow bound to Hotkey slot 2**, for example **Alt+Shift+C**.

## Troubleshooting

- **Pressing the keys does nothing.** The slot has no keys yet (only slot 1 has a suggested shortcut), or the workflow is not activated. Set the keys in the browser's shortcut page, and check the slot chosen in the node is the one you set.
- **Slot 1's suggested shortcut does nothing.** Another extension or the browser already uses **Ctrl+Shift+1**, so it was not assigned. Pick other keys for slot 1 in the shortcut page.
- **Two workflows run at once.** Both use the same slot. Give each workflow its own slot.
- **It does not work in the web app.** This node runs in the browser extension; install it and activate the workflow there.
