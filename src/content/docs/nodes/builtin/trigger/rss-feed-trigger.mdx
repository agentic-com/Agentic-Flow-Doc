Start the workflow when a blog, a news site or any RSS/Atom feed publishes a new item. No connection needed.

:::note[A polling trigger]
It checks for new items on a timer while the workflow is **On**, in the browser extension. Read [Polling triggers](/concepts/flow/polling-triggers/) for the first check, test events and what happens when a check fails.
:::

## What it does

Every **Check every** minutes, the trigger reads the **Feed URL** and starts one run with the items it hasn't seen yet. An item is recognised by its id (`guid`), or its link when the feed has no id.

A check that finds nothing new starts no run. Press **Run** to fetch a test event: the latest items, without moving the trigger's position.

## When to use it

- Post new articles from a blog to Slack or Discord.
- Save new podcast episodes to a reading list.
- Summarise each new post of a news feed with AI.

## Example workflow

1. New feed item on a blog feed, **Check every** 30 minutes.
2. [Summarization Chain](/nodes/builtin/ai/aiagents/summarizationchainnode/) summarises `{{ $input.content }}`.
3. [Discord](/nodes/builtin/integration/discord/) posts the title, link and summary.

## Common issues

- **Nothing ever runs**: with **Skip what's already there**, only items published after you turned the workflow On start runs. Press **Run** to fetch a test event and check the feed works.
- **The feed can't be read**: open the address in a tab; it must show XML, not a web page.
