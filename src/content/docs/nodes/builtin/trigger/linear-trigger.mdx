Start the workflow when an issue is created in Linear, in every team or in one.

:::note[A polling trigger]
It checks for new items on a timer while the workflow is **On**, in the browser extension. Read [Polling triggers](/concepts/flow/polling-triggers/) for the first check, test events and what happens when a check fails.
:::

## What it does

Every **Check every** minutes, the trigger reads the latest issues and starts one run with the new ones. Fill **Team key** (for example `ENG`) to watch one team; leave it empty for every team.

A check that finds nothing new starts no run. Press **Run** to fetch a test event: the latest items, without moving the trigger's position.

## When to use it

- Announce new issues in a chat channel.
- Copy new issues to another tool.
- Ask AI to suggest a priority for each new issue.

1. New Linear issue, **Team key** `SUP`.
2. [Discord](/nodes/builtin/integration/discord/) posts the issue title and link.

## Common issues

- **Nothing runs for one team**: check the **Team key** matches the prefix of its issues.
