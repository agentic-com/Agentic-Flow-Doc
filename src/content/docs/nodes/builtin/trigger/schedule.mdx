Run the flow at a specific time.

## What it does

Triggers workflow execution at specified times or intervals using cron-like scheduling rules.

## When to use it

Use this trigger to run workflows automatically at regular intervals or specific times, such as daily reports or periodic data syncs.

## Timing and reliability

- **Daylight saving time:** Daily, weekly and monthly schedules (and hourly schedules pinned to a specific minute) re-arm after each run, recomputing the next occurrence from the calendar. This keeps them on the correct **local** wall-clock time across daylight-saving transitions instead of drifting by an hour.
- **Second-level schedules are best-effort:** browser alarms are floored at about one minute, so second intervals have a minimum of 10 seconds and are effectively rounded up to roughly a minute. Use them for approximate polling, not precise sub-minute timing.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
