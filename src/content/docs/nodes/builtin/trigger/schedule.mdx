Run the workflow automatically at set times: every few minutes, daily at 9:00, every Monday, on the 1st of the month.

## What it does

Schedule starts the workflow on the rules you set, once the workflow is published. Each rule picks a **Trigger Interval** and then asks only for what that interval needs:

| Trigger Interval | You set |
| --- | --- |
| `seconds` | **Seconds Between Triggers** (at least 10) |
| `minutes` | **Minutes Between Triggers** |
| `hours` | **Hours Between Triggers** and, optionally, **Trigger at Minute** |
| `days` | **Days Between Triggers**, **Trigger at Hour**, **Trigger at Minute** |
| `weeks` | **Weeks Between Triggers**, the weekdays (field **Units**), **Trigger at Hour**, **Trigger at Minute** |
| `months` | **Months Between Triggers**, **Trigger at Day of Month**, **Trigger at Hour**, **Trigger at Minute** |

Add several rules to combine schedules, for example weekdays at 9:00 plus Saturdays at noon.

Daily, weekly and monthly schedules (and hourly ones pinned to a minute) stay on the same local clock time when daylight saving time changes.

## When to use it

- Daily reports, digests and reminders.
- Regular checks: a price, a page, an inbox.
- Routines that run an agent at set times, with [Run agent](/nodes/builtin/ai/aiagents/runagentnode/).

## Example workflow

1. Schedule with one rule: `days`, **Days Between Triggers** 1, **Trigger at Hour** 8 AM, **Trigger at Minute** 0.
2. [RSS Feed Read](/nodes/builtin/core/rss-feed-read/) fetches a feed.
3. [Limit](/nodes/builtin/datatransformation/limit/) keeps the 5 newest posts.
4. [Telegram](/nodes/builtin/integration/telegram/) sends them to you.

## Common issues

- **The workflow never runs on its own.** Publish the workflow: schedules only run for published workflows. To test, run it from the canvas.
- **A seconds schedule runs about once a minute.** The browser runs scheduled alarms at most about once a minute, so second-level schedules are approximate. The minimum is 10 seconds.
- **A monthly schedule skipped a month.** That month has no such day (for example the 31st). Pick a day that every month has, such as the 1st or the 28th.
