Built-in nodes cover triggers, sub-workflows, flow control, data transformation, core utilities, AI and app integrations. Nodes that act on the open web page are under [In Page Action](/nodes/extension/).

## Groups

- [Trigger](/nodes/builtin/trigger/whenstarted/) starts a workflow.
- [Lambda](/nodes/builtin/lambda/lambdainput/) defines the inputs and outputs of reusable sub-workflows.
- [Flow](/nodes/builtin/flow/if/) branches, waits, loops, merges, pauses for approval and stops.
- [Data Transformation](/nodes/builtin/datatransformation/editfields/) reshapes item data.
- [Core](/nodes/builtin/core/http-request/) runs code, reads web addresses, calls APIs and feeds, and stores data.
- [AI](/nodes/builtin/ai/) provides agents, chat models and their add-ons, and on-device AI.
- [Integrations](/nodes/builtin/integration/google-sheets/) connect your data to other apps.

## Choosing a built-in node

Start with the smallest node that does the step. If the step always works the same way, a flow, transformation or core node is faster and more predictable than AI. If the step needs the open web page, use an [In Page Action](/nodes/extension/) node.
