# Built-in Nodes

Built-in nodes cover workflow triggers, lambda workflow contracts, flow control, data transformation, core utilities, AI components, and service integrations. Browser page actions live under [In Page Action](/nodes/extension/getselectedtext/).

## Groups

- [Trigger](/nodes/builtin/trigger/whenstarted/) starts workflow execution.
- [Lambda](/nodes/builtin/lambda/lambdainput/) defines reusable workflow inputs and outputs.
- [Flow](/nodes/builtin/flow/if/) controls branching, waiting, looping, merging, pausing for approval, and stopping.
- [Data Transformation](/nodes/builtin/datatransformation/editfields/) reshapes item data.
- [Core](/nodes/builtin/core/http-request/) handles code, URL extraction, HTTP calls, and feeds.
- [AI](/nodes/builtin/ai/) provides agent nodes and AI dependencies.
- [Integrations](/nodes/builtin/integration/google-sheets/) connect workflow data to external services.

## Choosing A Built-in Node

Start with the smallest node that can solve the step. If the task is deterministic, prefer flow, transformation, or core nodes before adding AI. If the task needs browser page state, use an [In Page Action](/nodes/extension/) node instead of a built-in node.
