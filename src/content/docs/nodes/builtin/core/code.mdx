# Code

Run custom python code

## What it does

Executes custom Python code to transform data or perform complex logic within your workflow.

## When to use it

Use this node for custom data transformations, calculations, or logic that isn't available in other nodes.

## Inputs and settings

| Setting | Notes |
| --- | --- |
| Code to Execute | Source-backed field from the node schema. |

## Reading input and returning output

The data flowing into the node is available to your code as a variable named **`input`** — a normal Python value (dict, list, or scalar), mirroring what `{{ $input }}` holds elsewhere.

Set a variable named **`result`** to whatever the node should output.

```python
# input = {"tags": ["news", "ai"], "title": "Hello"}
result = {
    "title": input["title"].upper(),
    "tag_count": len(input["tags"]),
    "joined": ", ".join(input["tags"]),
}
```

If nothing is connected into the node, `input` is not defined — guard with `globals().get("input")` if your code can run either way.

## Outputs

Returns the `result` variable, visible in the workflow execution data and passed to the next node.

## Dependencies and credentials

- No explicit credential or node dependency is declared in the node description.

## Example workflow

Connect data into Code, configure the settings above, and use the output in the next workflow step.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
