Makes a HTTP request and returns the response data

## What it does

Makes HTTP requests to external APIs and returns the response data.

## When to use it

Use this node to call REST APIs, fetch data from web services, or integrate with external systems via HTTP.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Method** | Choice | GET | No | The request method to use. Options: GET, POST, PUT, DELETE, PATCH, OPTIONS, HEAD. |
| **URL** | URL |  | Yes | Security: Ensure the URL is from a trusted source. Avoid including sensitive data in URL parameters. |
| **Authentication** | Credential |  | No | The authentication to use to make the request. |
| **Headers** | Key-value pairs |  | No | The headers to send with the request. |
| **Query Params** | Key-value pairs |  | No | The query params to send with the request. |
| **Body** | Group |  | No | The body to send with the request. |
| Body › **Body Content Type** | Choice | application/json | No | Content-Type to use to send body parameters. Options: application/json, application/x-www-form-urlencoded, multipart/form-data. |
| Body › **Body** | Key-value pairs |  | No | The body to send with the request. |
| **Options** | Group |  | No | The options to send with the request. |
| Options › **Redirects** | Group |  | No | The options to send with the request. |
| Options › Redirects › **Follow redirects** | Toggle | On | No | Follow redirects. |
| Options › Redirects › **Max redirects** | Number | 10 | No | The maximum number of redirects to follow. |
| Options › **Response** | Group |  | No | The options for the response. |
| Options › Response › **Include response header and status** | Toggle | Off | No | Whether to return the full response (headers and response status code) data instead of only the body. |
| Options › Response › **Response format** | Choice | autodetect | No | The format in which the data gets returned from the URL. Options: autodetect, json, text, file. |
| Options › **Timeout (ms)** | Number | 10000 | No | Time in ms to wait for the server to send response headers (and start the response body) before aborting the request. |

## Example workflow

Connect data into Http Request, configure the settings above, and use the output in the next workflow step.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
