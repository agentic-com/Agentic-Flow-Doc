Download a web page by its address and list the links on it, optionally only those to certain sites.

## What it does

Get Links from Link downloads the page at **URL**, reads every link (`href` of each `<a>` tag) and returns the addresses as a list in the field named by **Output field name**.

- Relative links are turned into full addresses.
- Links to a spot on the same page (`#section`), `mailto:`, `tel:` and `javascript:` links are skipped.
- Duplicates are removed; the order of the page is kept.
- **Filter domains** keeps only links to the listed sites; **Exclude domains** drops links to them. A domain also matches its subdomains: `example.com` covers `blog.example.com`.

Scripts on the page do not run, so links a site adds with JavaScript are not found.

## When to use it

- Collect article links from a blog or news index to read each one.
- List the external sites a page links to, with your own domain in **Exclude domains**.
- Find all links to a specific site, such as every GitHub link on a page.

To read the links of the page open in your tab, use [Get All Link](/nodes/extension/getalllinks/).

## Example workflow

Read the first five articles linked from a blog's index:

1. [When Started](/nodes/builtin/trigger/whenstarted/) trigger.
2. Get Links from Link, **URL** `https://blog.example.com`, **Output field name** `links`, **Filter domains** `blog.example.com`.
3. [Split Out](/nodes/builtin/datatransformation/splitout/), **Field To Split Out** `links`, **Output field name** `link`.
4. [Limit](/nodes/builtin/datatransformation/limit/), **Max Items** `5`.
5. [Get All Text from Link](/nodes/builtin/core/getalltextfromlink/), **URL** `{{ $input.link }}`.

## Common issues

- **The list is empty or short.** The site builds its links with JavaScript, or your domain filters remove them. Check **Filter domains** and **Exclude domains**, or open the page and use [Get All Link](/nodes/extension/getalllinks/).
- **Links to a subdomain are missing.** A filter on `blog.example.com` does not match `www.example.com`. Use the parent domain, `example.com`.
- **"Invalid URL: …".** The address is malformed, or the request could not be sent. If the address is correct and the node runs in the web app, the site likely refuses requests from other websites; run the workflow from the extension.
- **"HTTP error! status: 403"** or **"Request timeout".** The site refused or answered too slowly. Some sites block automated requests; raise **Timeout** for slow ones.
