Get the Links content of a page from a given URL

## What it does

Extracts all hyperlinks from a web page at the specified URL with optional domain filtering.

## When to use it

Use this node for web crawling, sitemap generation, or discovering related pages.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **URL** | Text |  | Yes | The URL to get the Links from. |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **Timeout** | Number | 10000 | No | The timeout for the request. |
| **Filter domains** | Tags |  | No | The domains to filter. |
| **Exclude domains** | Tags |  | No | The domains to exclude. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Headers** | Key-value pairs |  | No | The headers to send with the request. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.

## Example workflow

Connect data into Get Links from Link, configure the settings above, and use the output in the next workflow step.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
