Download a web page by its address and list the addresses of the images on it.

## What it does

Get Images from Link downloads the page at **URL**, finds its images and returns their addresses as a list in the field named by **Output field name**.

- It reads the `src` of every image tag and any `background-image` written in the page's inline styles.
- Relative addresses are turned into full `https://` addresses.
- Images embedded directly in the page as data (`data:` addresses) are skipped.
- Duplicates are removed.

Scripts on the page do not run, and images that load only as you scroll (lazy loading) often have no real `src` in the HTML, so they can be missing.

## When to use it

- Collect product or gallery images from a page to download or catalogue.
- Find the main image of an article to attach to a message.
- Pass image addresses to an AI model that describes or classifies images.

To list the images of the page open in your tab, including those added by scripts, use [Get All Images](/nodes/extension/getallimages/).

**URL** must be a full address starting with `https://` or `http://`, typed or as an expression. **Timeout** is in milliseconds.

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

One item with a list of addresses under **Output field name**, for example `{ images: ["https://example.com/a.jpg", "https://example.com/b.png"] }`. To handle each image separately, follow with [Split Out](/nodes/builtin/datatransformation/splitout/) on that field.

## Example workflow

Describe every image on a page:

1. [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger, **Menu Contexts** `Link`.
2. Get Images from Link, **URL** `{{ $input.linkUrl }}`, **Output field name** `images`.
3. [Split Out](/nodes/builtin/datatransformation/splitout/), **Field To Split Out** `images`, **Output field name** `image`.
4. [Caption Image](/nodes/builtin/ai/localai/caption-image/), **Image** `{{ $input.image }}`.

## Troubleshooting

- **The list is empty.** The page adds its images with JavaScript, or uses lazy loading. Open the page and use [Get All Images](/nodes/extension/getallimages/).
- **"Invalid URL: …".** The address is malformed, or the request could not be sent. If the address is correct and the node runs in the web app, the site likely refuses requests from other websites; run the workflow from the extension.
- **"HTTP error! status: 403"** (or another number). The server refused the request. Some sites block automated requests.
- **"Request timeout".** Raise **Timeout**.
