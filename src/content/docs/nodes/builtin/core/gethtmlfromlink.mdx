## What it does

Get HTML from Link downloads the page at **URL** and returns its HTML exactly as the server sent it, as text, in the field named by **Output field name**.

Scripts on the page do not run, so anything a site adds afterwards with JavaScript is not in the result. Use it on pages whose content is in the HTML itself, such as articles, listings and simple shops.

## When to use it

- Pull specific values (a price, a title, a table) out of a page with [HTML Extract](/nodes/builtin/datatransformation/html-extract/).
- Save a copy of a page's source.
- Check a page for a meta tag or a script without opening it.

For just the readable text, use [Get All Text from Link](/nodes/builtin/core/getalltextfromlink/). To read the HTML of the page open in your tab, use [Get All HTML](/nodes/extension/getallhtml/).

- **URL** must be a full address starting with `https://` or `http://`, typed or as an expression such as `{{ $input.url }}`.
- **Timeout** is in milliseconds (10000 = 10 seconds).
- **Headers** add extra request headers, such as `Accept-Language: en`.

## Example workflow

Check a product's price every morning:

1. [Schedule](/nodes/builtin/trigger/schedule/) trigger, every day at 8:00.
2. Get HTML from Link, **URL** `https://shop.example.com/product/123`, **Output field name** `html`.
3. [HTML Extract](/nodes/builtin/datatransformation/html-extract/), **HTML** `{{ $input.html }}`, **Mode** Single value, **Selector** `.price`, **Return** Text.
4. [Browser Notification](/nodes/extension/browsernotification/) with the extracted price.

## Common issues

- **"Invalid URL: …".** The address is malformed, or the request could not be sent. Check the address. If it is correct and the node runs in the web app, the site likely refuses requests from other websites; run the workflow from the extension.
- **"HTTP error! status: 404"** (or another number). The server answered with an error. Check the address; 403 often means the site blocks automated requests.
- **"Request timeout".** The site took longer than **Timeout**. Raise it.
- **The value you want is not in the HTML.** The site builds it with JavaScript. Open the page and use [Get All HTML](/nodes/extension/getallhtml/) or [Get Element Data](/nodes/extension/getelementdata/) instead.
