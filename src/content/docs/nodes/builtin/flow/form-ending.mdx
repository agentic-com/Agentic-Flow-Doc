Decide what the person sees after the last page of a form: a thank-you message, a web page, or nothing (the form closes).

## What it does

Form ending tells the open form what to show, then passes its input on unchanged. It does not pause the run, so steps after it still run.

- **Show a message**: a **Title** and a **Text**, for example "Thanks, it's filed" and "We'll email you."
- **Open a page**: opens the **Page** in a new tab. Only `https://` links are accepted.
- **Close the form**: the form window or sheet closes.

Without a Form ending, the form shows **Done** when the run finishes, or **Something went wrong** when it fails.

## When to use it

- At the end of a [When a form is submitted](/nodes/builtin/trigger/form-trigger/) workflow, after the steps that file the request.
- After the last [In-Page Form](/nodes/builtin/flow/in-page-form/) of a multi-page form.
- On each branch of a form workflow, with a different message per outcome ("Approved" / "We need more details").

## Example workflow

1. [When a form is submitted](/nodes/builtin/trigger/form-trigger/) asks for an email and a question.
2. [Notion](/nodes/builtin/integration/notion/) adds a page to a requests database.
3. Form ending, **Show a message**: "Thanks, it's filed".

## Common issues

- **"The page must be an https:// link."**: **Open a page** only accepts `https://` addresses.
- **The message never shows**: the run failed before reaching this step. Open **Runs** to see where.
