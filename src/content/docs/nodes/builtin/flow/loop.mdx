Execute a set of actions repeatedly based on conditions

## What it does

Executes a set of actions repeatedly based on iteration count or conditional logic.

## When to use it

Use this node to process arrays, repeat actions multiple times, or iterate until a condition is met.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Max Iterations** | Number | 100 | No | Maximum number of loop iterations. |
| **Conditions** | Conditions |  | Yes | The conditions to evaluate. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
2 output ports: **Done**, **Loop**.

Each output item has these fields:

| Field | Type | Description |
| --- | --- | --- |
| `done` | True/false | True when the loop exits through Done |
| `currentIndex` | Number |  |
| `inData` | Any | The incoming data, unchanged |
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Place Loop between data-producing nodes and downstream actions to control which data continues through the workflow.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
