Merge multiple streams into one

## What it does

Combines data from multiple workflow branches into a single stream.

## When to use it

Use this node to synchronize parallel workflow paths or combine data from different sources.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Mode** | Choice | Inner Join | Yes | The mode to use for merging the inputs. Options: Inner Join, Left Join, Right Join, Left Outer Join, Right Outer Join. |
| **Match Keys** | Key mapping |  | Yes | The keys to use for matching the inputs. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Place Merge between data-producing nodes and downstream actions to control which data continues through the workflow.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
