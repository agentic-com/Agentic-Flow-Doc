Keep only the items that match your conditions and drop the rest.

## What it does

Filter checks its **Conditions** once for every item that arrives. Items that match leave through the **Kept** port, unchanged. Items that don't match are dropped: they go nowhere, and the steps after Filter never see them.

Conditions work like the ones in [IF](/nodes/builtin/flow/if/): each compares a value (usually an expression such as `{{ $input.price }}`) with another value, using an operator for the type you pick (**String**, **Number**, **Date-Time**, **Boolean**, **Array** or **Object**). Link several conditions with **AND** or **OR**. They are read from top to bottom, one after the other, with no grouping: `A AND B OR C` means "(A and B), or C".

## When to use it

- Keep only the products under a price before sending an alert.
- Remove empty rows from a CSV before saving them.
- Keep only the links that point to a given domain.

To send the non-matching items somewhere else instead of dropping them, use [IF](/nodes/builtin/flow/if/). To keep the first few items whatever their content, use [Limit](/nodes/builtin/datatransformation/limit/).

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Conditions** | Conditions |  | Yes | The conditions to evaluate. |
{/* AUTO:settings:end */}

Write the value to test as an expression on the current item, for example `{{ $input.status }}` **Is Equal To** `active`.

## Outputs

{/* AUTO:outputs:start */}
One output port, **Kept**.

Each output item has these fields:

| Field | Type | Description |
| --- | --- | --- |
| `result` | True/false | Whether the conditions held |
| `inData` | Any | The incoming data, unchanged |
{/* AUTO:outputs:end */}

The next node receives the kept items themselves, exactly as they arrived, so you keep using the same expressions (`{{ $input.price }}`) after the Filter. If no item matches, nothing leaves the node.

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Keep only the PDF links of a page:

1. [Get All Link](/nodes/extension/getalllinks/) with **Output field name** `links` reads the links of the open page.
2. [Split Out](/nodes/builtin/datatransformation/splitout/) with **Field To Split Out** `links` makes one item per link.
3. Filter with the condition `{{ $input.links }}` (**String**) **Ends With** `.pdf`.
4. [Slack](/nodes/builtin/integration/slack/) posts `{{ $input.links }}` for every kept link.

## Troubleshooting

- **Nothing runs after the Filter.** No item matched. Open the run and check the values the condition compared: a price read from a page is often text such as `"49.90 €"`, which a **Number** comparison can't match. Clean it first with [Edit Fields](/nodes/builtin/datatransformation/editfields/) or [Regex](/nodes/builtin/datatransformation/regex/).
- **Items you expected to drop still pass.** Check the **AND** / **OR** links. Because conditions are read top to bottom without grouping, one **OR** near the end can let everything through.
- **Every item is dropped when comparing text.** Text comparisons are exact; check for extra spaces or a different capitalisation in the incoming value.
