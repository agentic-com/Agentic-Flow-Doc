Accept items matching the conditions

## What it does

Filters workflow items by passing only those that match specified conditions.

## When to use it

Use this node to remove unwanted items from your data stream based on conditional logic.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Conditions** | Conditions |  | Yes | The conditions to evaluate. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port, **Kept**.

Each output item has these fields:

| Field | Type | Description |
| --- | --- | --- |
| `result` | True/false | Whether the conditions held |
| `inData` | Any | The incoming data, unchanged |
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Place Filter between data-producing nodes and downstream actions to control which data continues through the workflow.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
