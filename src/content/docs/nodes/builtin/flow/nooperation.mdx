A placeholder step that passes data through unchanged.

## What it does

No Operation hands the data it receives straight to the next node, without changing anything. If nothing came in, it sends `{ "passed": true }` so the steps after it still run.

It exists to make a workflow easier to read and edit, not to change data. To leave a comment on it, use the notes that every node has.

## When to use it

- End an [IF](/nodes/builtin/flow/if/) or [Switch](/nodes/builtin/flow/switch/) branch on purpose, so the canvas shows the path was considered rather than forgotten.
- Keep a spot for a step you will add later, with the connections already in place.
- Keep the wiring of a section while you rework the nodes around it.

It takes a single input. To bring several branches together, use [Funnel](/nodes/builtin/flow/funnel/) or [Merge](/nodes/builtin/flow/merge/).

## Example workflow

Mark a branch as "nothing to do":

1. [Get Selected Text](/nodes/extension/getselectedtext/) with **Output field name** `text` reads the highlighted text.
2. [IF](/nodes/builtin/flow/if/) with the condition `{{ $input.text }}` (**String**) **Is Not Empty**.
3. From **True**: [Clipboard Write](/nodes/extension/clipboardwrite/) copies the text.
4. From **False**: No Operation, with a note `Nothing selected: nothing to do`.

## Common issues

- **Connecting a second branch to it isn't possible.** No Operation accepts one input. Use [Funnel](/nodes/builtin/flow/funnel/) to continue when any branch finishes, or [Merge](/nodes/builtin/flow/merge/) to join data.
- **The next node gets `{ "passed": true }`.** Nothing reached No Operation with data. Read the data you need from the earlier node with `{{ $('Node Label').field }}`.
