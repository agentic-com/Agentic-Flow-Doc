Route items to different branches based on conditions

## What it does

Routes workflow items to different output branches based on conditional logic.

## When to use it

Use this node to create conditional workflows where different actions occur based on data values or conditions.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Conditions** | Conditions |  | Yes | The conditions to evaluate. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
2 output ports: **True**, **False**.

Each output item has these fields:

| Field | Type | Description |
| --- | --- | --- |
| `result` | True/false | Whether the conditions held |
| `inData` | Any | The incoming data, unchanged |
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Place IF between data-producing nodes and downstream actions to control which data continues through the workflow.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
