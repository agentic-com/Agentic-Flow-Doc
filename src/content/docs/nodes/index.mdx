Nodes are like LEGO blocks for automation. Each node does one specific job - extract text, process data, or save files. Connect them together to create powerful workflows that run in your browser.

**What makes browser nodes special:** They work directly with web pages in real-time, letting you extract data and interact with websites in ways traditional tools can't.

## 🧠 Understanding Node Categories

### Browser Extension Nodes
**Purpose:** Direct interaction with web pages and browser functionality
**When to use:** When you need to extract data from, or interact with, web pages in real-time
**Examples:** Text extraction, form filling, page navigation, content modification

### Built-in Processing Nodes
**Purpose:** Data transformation, logic control, and intelligent processing
**When to use:** When you need to process, analyze, or make decisions about data
**Examples:** AI analysis, data formatting, conditional logic, API calls

### AI & LangChain Nodes
**Purpose:** Add intelligence, reasoning, and adaptive behavior to workflows
**When to use:** When you want workflows that can think, learn, and make smart decisions
**Examples:** Content analysis, question answering, intelligent agents, memory systems
