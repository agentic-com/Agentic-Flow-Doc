Get schemas for one form or all forms from the opened tab

## What it does

Extracts the structure and field definitions of forms on the current page.

## When to use it

Use this node to analyze form structure before filling it or to understand required fields dynamically.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **DOM Selector** | Page element |  | No | The selector of the DOM element to interact with. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each run returns a list of items with the fields `id` (text), `name` (text), `selector` (text), `action` (text), `method` (text), `enctype` (text), `target` (text), `autocomplete` (text), `noValidate` (true/false), `fieldCount` (number), `fields` (list of entries).
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Get Forms Schema after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
