Show a native browser notification You can use this node when a background or browser-triggered workflow needs to notify the user..

## What it does

Displays a native browser notification with custom title, message, and icon.

## When to use it

Use this node to alert users about workflow completion, errors, or important events from background processes.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Title** | Text |  | Yes |  |
| **Message** | Long text |  | Yes |  |
| **Options** | Group |  | No |  |
| Options › **Icon URL** | Text |  | No |  |
| Options › **Notification ID** | Text |  | No | Optional stable ID used to replace an existing notification. |
| Options › **Priority** | Choice | Normal | No | Options: Low, Normal, High. |
| Options › **Require Interaction** | Toggle | Off | No | Keep the notification on screen until it is dismissed. Chrome only: Firefox closes notifications on its own. |
| Options › **Silent** | Toggle | Off | No | Show the notification without a sound. Chrome only: Firefox ignores this option. |
{/* AUTO:settings:end */}

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Show Notification after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
