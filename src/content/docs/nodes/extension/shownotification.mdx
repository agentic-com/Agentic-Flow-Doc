# Show Notification

Show a native browser notification You can use this node when a background or browser-triggered workflow needs to notify the user..

## What it does

Show Notification belongs to the **In Page Action** palette group. Its canonical node id is `showNotificationNode` and its source documentation link is `/nodes/extension/shownotification/`.

## When to use it

Use Show Notification when the workflow needs to read from, write to, or interact with the currently open browser page.
