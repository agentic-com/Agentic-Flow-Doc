## What it does

Display Markdown renders the Markdown in **Content** and shows it in a panel in the bottom-right corner of the active tab. The panel has buttons to maximize, minimize and close it, and a copy button that copies the original Markdown.

- **Title** appears in the panel's header. When you leave it empty, a default title is shown.
- Only one panel is shown at a time: running the node again replaces it.
- The panel belongs to the page: it disappears when the page reloads or you navigate away.
- This is an end node: it has no output, so nothing runs after it on this branch.

## When to use it

- Show the result of an AI node (a summary, a translation, an answer) right next to the page it is about.
- Display a short report at the end of a workflow you run by hand.
- To show raw data as a tree instead of formatted text, use [Display Object](/nodes/extension/displayobject/). To alert someone who is not looking at the page, use [Browser Notification](/nodes/extension/browsernotification/).

## Example workflow

1. Add a [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger.
2. Add [Get All Text](/nodes/extension/getalltext/) with **Output field name** = `pageText`.
3. Add a [Summarization](/nodes/builtin/ai/aiagents/summarizationchainnode/) node with **Text** = `{{ $input.pageText }}`, and connect a chat model to it.
4. Add **Display Markdown** with **Title** = `Summary` and **Content** = `{{ $input.summary }}`.

## Common issues

- **No panel appears.** The panel is drawn on the active tab. Make sure the page you want is the active tab when the node runs; browser settings pages and the extension store cannot show it.
- **The panel is empty.** **Content** resolved to nothing. Open the previous node's output and point the expression at the field that holds the text.
- **The panel disappeared.** It is removed when the page reloads or navigates. Run the workflow again, or keep the result with [Data Store](/nodes/builtin/core/datastore/).
- **The node fails outside the extension.** This node runs in the browser extension; install it or run the workflow from the extension.
