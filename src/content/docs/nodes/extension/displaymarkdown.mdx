Display markdown content in the UI

## What it does

Renders markdown content in a modal or overlay on the current browser page.

## When to use it

Use this node to display formatted AI-generated content, documentation, or reports to users.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Title** | Text |  | No | The title of the markdown content. |
| **Content** | Markdown |  | Yes | The markdown content to display. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
This node has no output port: nothing runs after it on this branch.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Display Markdown after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
