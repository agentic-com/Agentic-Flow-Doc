Get metadata from the opened page

## What it does

Extracts page metadata including title, description, Open Graph tags, and other meta information.

## When to use it

Use this node to collect SEO data, social media previews, or page information for cataloging.

## Inputs and settings

{/* AUTO:settings:start */}
This node has no settings.
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has these fields:

| Field | Type | Description |
| --- | --- | --- |
| `url` | Text |  |
| `title` | Text |  |
| `canonicalUrl` | Text |  |
| `description` | Text |  |
| `lang` | Text |  |
| `favicon` | Text |  |
| `openGraph` | Key-value pairs | og:\* meta tags |
| `twitter` | Key-value pairs | twitter:\* meta tags |
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Get Page Metadata after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
