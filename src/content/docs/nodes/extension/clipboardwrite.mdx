Copy text to your clipboard so it is ready to paste anywhere.

## What it does

Clipboard Write puts the text in **Text** on the system clipboard, replacing what was there. It only writes: it never reads what you copied before.

The copy is made through the active tab, and the browser only allows it while that tab has focus. If the write is refused, the node fails with a clear error instead of pretending it worked. It copies text only, not images or files.

## When to use it

- Put a generated value (a summary, a reply draft, a short link, a code) on the clipboard so you can paste it straight away.
- Move a result into another app that has no integration: copy it, then paste.
- To show the result instead, use [Display Markdown](/nodes/extension/displaymarkdown/).

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has the fields `written` (always true).
{/* AUTO:outputs:end */}

`written` is `true` when the text is on the clipboard. When the copy fails, the node fails instead, so later nodes only run after a successful copy.

## Example workflow

1. Add a [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger and select an email on the page.
2. Add [Get Selected Text](/nodes/extension/getselectedtext/) with **Output field name** = `email`.
3. Add a [Basic LLM Chain](/nodes/builtin/ai/aiagents/basicllmchainnode/) with **Prompt** = `Write a short, polite reply to: {{ $input.email }}`, and connect a chat model.
4. Add **Clipboard Write** with **Text** = `{{ $input.response }}`, then paste the reply in your mail app.

## Troubleshooting

- **"Document is not focused" or "Clipboard write failed".** The browser only allows copying while the page has focus. Click into the page, keep it in front while the workflow runs, and try again.
- **The node fails on a browser page.** Browser settings pages and the extension store cannot be used; run it with a normal web page as the active tab.
- **The pasted text is not what you expected.** Check what **Text** resolves to in the node's input; an expression pointing at the wrong field gives the wrong text.
- **The node fails outside the extension.** This node runs in the browser extension; install it or run the workflow from the extension.
