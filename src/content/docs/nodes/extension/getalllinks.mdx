Get all the links from the page of the actual openend tab

## What it does

Extracts all hyperlinks (URLs) from the currently active browser tab.

## When to use it

Use this node for web crawling, link discovery, or building navigation maps of websites.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **DOM Selector** | Page element |  | No | The selector of the DOM element to interact with. |
| **Max links** | Number |  | No | The maximum number of links to return. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Get All Links after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
