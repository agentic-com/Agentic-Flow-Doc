Collect the web addresses of all the links on the active tab, or inside one part of it.

## What it does

Get All Link reads every link (`<a>` element) on the active tab and returns their URLs as a list in the field you name in **Output field name**.

- Relative links are turned into full URLs, and each URL appears only once.
- Email (`mailto:`), phone (`tel:`) and script (`javascript:`) links are left out.
- With **DOM Selector** set, only links inside the first matching element are collected.
- **Max links** keeps the first N links, in page order.

The output holds only the new field. Turn on **Include input fields** to keep the incoming item's fields next to it.

## When to use it

- Gather the article links from a listing or search page, then visit or read each one.
- Check which pages a page links to.
- For files you can download (PDF, ZIP, images…), [Get Page Assets](/nodes/extension/getpageassets/) is more precise. For a page that is not open, use [Get Links from Link](/nodes/builtin/core/getlinksfromlink/).

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Output field name** | Text |  | Yes | The name of the output field. |
| **DOM Selector** | Page element |  | No | The selector of the DOM element to interact with. |
| **Max links** | Number |  | No | The maximum number of links to return. |
| **Options** | Group |  | No | The options for the node. |
| Options › **Include input fields** | Toggle | Off | No | Whether to include the input fields in the output. |
{/* AUTO:settings:end */}

- **Output field name**: for example `links`.
- **DOM Selector**: click the crosshair button in the field and click the area to read (a results list, the main article), or type a CSS selector. Leave empty for the whole page, which also includes menus and footers.
- **Max links**: leave empty to keep them all.

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

One item with your field holding a list of URLs, for example `{ "links": ["https://example.com/post-1", "https://example.com/post-2"] }`. Use [Split Out](/nodes/builtin/datatransformation/splitout/) to turn it into one item per link.

## Example workflow

1. Open a blog's article list and run the workflow from a [Hotkey](/nodes/builtin/trigger/hotkey/) trigger.
2. Add **Get All Link** with **Output field name** = `links`, **DOM Selector** set to the list of posts and **Max links** = `10`.
3. Add [Split Out](/nodes/builtin/datatransformation/splitout/) with **Field To Split Out** = `links`.
4. Add [Get All Text from Link](/nodes/builtin/core/getalltextfromlink/) to read each post, then a [Summarization](/nodes/builtin/ai/aiagents/summarizationchainnode/) node.

## Troubleshooting

- **The list is empty.** **DOM Selector** matched nothing, or the links had not loaded yet. Check the selector with **Ping**, and wait for the list with [Wait For Element](/nodes/extension/ui/wait-for-element/).
- **The list is full of menu and footer links.** Set **DOM Selector** to the part of the page you care about.
- **Links to the same page with `#section` endings appear.** Links to a section of a page count as separate URLs. Remove them with [Filter](/nodes/builtin/flow/filter/) after Split Out.
- **The node fails outside the extension.** This node runs in the browser extension; install it or run the workflow from the extension.
