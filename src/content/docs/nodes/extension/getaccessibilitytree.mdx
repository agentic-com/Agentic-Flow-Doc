Get visible interactive and semantic elements from the opened page

## What it does

Extracts the accessibility tree showing interactive and semantic elements with their roles and labels.

## When to use it

Use this node to analyze page accessibility, identify interactive elements, or build AI agents that understand page structure.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **DOM Selector** | Page element |  | No | The selector of the DOM element to interact with. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each run returns a list of items with these fields:

| Field | Type | Description |
| --- | --- | --- |
| `selector` | Text |  |
| `tagName` | Text |  |
| `role` | Text |  |
| `name` | Text | The accessible name |
| `text` | Text |  |
| `disabled` | True/false |  |
| `checked` | True/false |  |
| `selected` | True/false |  |
| `expanded` | True/false |  |
| `boundingBox` | Object |  |
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Get Accessibility Tree after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
