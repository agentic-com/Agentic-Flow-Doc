Get the selected text from the page of the actual openend tab

## What it does

Captures the HTML markup of text that the user has currently selected on the page.

## When to use it

Use this node to extract formatted content with its structure, such as copying rich text or styled elements.

{/* AUTO:deps:start */}

{/* AUTO:deps:end */}

## Example workflow

Run Get HTML of Selected Text after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
