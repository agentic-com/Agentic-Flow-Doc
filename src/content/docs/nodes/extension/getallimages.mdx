Collect the addresses of every image on the active tab, or inside one part of it.

## What it does

Get All Images looks through the active tab and returns a list of image URLs in the field you name in **Output field name**. It finds:

- every `<img>` image, and
- background images set by the page's styles (banners, hero images, tiles).

Relative addresses are turned into full URLs, and each URL appears only once. With **DOM Selector** set, only images inside the first matching element are collected. **Max images** keeps the first N images found, in page order.

The output holds only the new field. Turn on **Include input fields** to keep the incoming item's fields next to it.

## When to use it

- Collect product or gallery pictures to download, caption or classify.
- Check which images a page uses, for example during a content review.
- For a wider inventory (downloadable files, video, audio, scripts) with file names, use [Get Page Assets](/nodes/extension/getpageassets/). For a page that is not open, use [Get Images from Link](/nodes/builtin/core/getimagesfromlink/).

- **Max images**: leave empty to keep them all.

## Example workflow

1. Open a product page and run the workflow from a [Hotkey](/nodes/builtin/trigger/hotkey/) trigger.
2. Add **Get All Images** with **Output field name** = `images`, **DOM Selector** set to the product gallery and **Max images** = `5`.
3. Add [Split Out](/nodes/builtin/datatransformation/splitout/) with **Field To Split Out** = `images`, so each URL becomes its own item.
4. Add [Caption Image](/nodes/builtin/ai/localai/caption-image/) with **Image** = `{{ $input.images }}` to describe each picture on your device.

## Common issues

- **The list is empty.** **DOM Selector** matched nothing, or the area has no images yet. Many pages load images only when you scroll to them: scroll first, or wait with [Wait For Element](/nodes/extension/ui/wait-for-element/).
- **Icons, logos or tracking pixels are in the list.** The node returns every image it finds. Narrow it with **DOM Selector**, or drop unwanted URLs with [Filter](/nodes/builtin/flow/filter/) after Split Out.
- **The node fails on a browser page.** Browser settings pages and the extension store are protected and cannot be read. Run it on a normal web page.
- **The node fails outside the extension.** This node runs in the browser extension; install it or run the workflow from the extension.
