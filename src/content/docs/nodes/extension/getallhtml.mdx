## What it does

Get All HTML copies the HTML markup of the active tab, as it is right now in the browser, and stores it as text in the field you name in **Output field name**.

- With **DOM Selector** empty, you get the whole document, from the `<html>` tag down.
- With a selector, you get the first matching element, including its own tag.
- Because it reads the live page, content added by scripts after the page loaded is included.
- The output holds only the new field. Turn on **Include input fields** to keep the incoming item's fields next to it.

It reads the main page only, not embedded frames.

## When to use it

- Pass a block of markup to [HTML Extract](/nodes/builtin/datatransformation/html-extract/) to pull out several values with selectors.
- Keep a copy of part of a page, for example with [Save as File](/nodes/builtin/datatransformation/saveasfile/).
- If you only need the readable text, [Get All Text](/nodes/extension/getalltext/) is smaller and easier to feed to an AI node. To fetch HTML from a URL without opening it, use [Get HTML from Link](/nodes/builtin/core/gethtmlfromlink/).

## Example workflow

1. Open a product page and run the workflow from a [Hotkey](/nodes/builtin/trigger/hotkey/) trigger.
2. Add **Get All HTML** with **Output field name** = `html` and **DOM Selector** set to the product box.
3. Add [HTML Extract](/nodes/builtin/datatransformation/html-extract/) with **HTML** = `{{ $input.html }}`, **Mode** = **Single value** and **Selector** = `.price`.
4. Remember the price with [Data Store](/nodes/builtin/core/datastore/), **Operation** = **Set**.

## Common issues

- **"No content found".** **DOM Selector** matched nothing on the page. Use **Ping** to check it, or wait for the element with [Wait For Element](/nodes/extension/ui/wait-for-element/) first.
- **The HTML is very large.** A whole page can be hundreds of kilobytes. Pick a smaller element in **DOM Selector**.
- **Content inside an embedded frame is missing.** Frames are not read. Open the frame's address in its own tab with [Tab Control](/nodes/extension/tabcontrol/).
- **The node fails outside the extension.** This node runs in the browser extension; install it or run the workflow from the extension.
