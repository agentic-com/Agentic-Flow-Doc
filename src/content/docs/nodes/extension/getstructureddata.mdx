Extract structured data from a table or list in the opened tab

## What it does

Extracts data from HTML tables or lists and converts it into structured JSON format.

## When to use it

Use this node to scrape tabular data from web pages for analysis, storage, or processing.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **DOM Selector** | Page element |  | Yes | The selector of the DOM element to interact with. |
| **Options** | Group |  | No | Structured extraction options. |
| Options › **Mode** | Choice | Auto | No | Choose what to extract. Options: Auto, Table, List. |
| Options › **List Format** | Choice | Text | No | How list items are represented. Options: Text, Key/Value. |
| Options › **Table first row is header** | Toggle | On | No | Use first table row as headers when no thead is present. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each run returns a list of items with these fields:

| Field | Type | Description |
| --- | --- | --- |
| `sourceType` | Choice |  |
| `selector` | Text |  |
| `items` | List of entries | One item per row or list entry |
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Get Structured Data after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
