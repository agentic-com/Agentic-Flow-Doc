Display an object in the UI

## What it does

Displays a JSON object or data structure in a formatted modal or overlay on the page.

## When to use it

Use this node to show workflow results, debug data, or present structured information to users.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Title** | Text |  | No | The title of the displayed object. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
This node has no output port: nothing runs after it on this branch.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Display Object after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
