Show the data that reaches this node as an expandable tree in a panel on the active tab.

## What it does

Display Object takes the incoming item, exactly as it arrives, and shows it in a panel in the bottom-right corner of the active tab. The data is shown as a JSON tree you can expand and collapse. The panel has buttons to maximize, minimize and close it.

- There is nothing to map: the node always shows its input. Only **Title** is set by you; when it is empty, a default title is shown.
- Only one panel is shown at a time: running the node again replaces it.
- The panel belongs to the page: it disappears when the page reloads or you navigate away.
- This is an end node: it has no output, so nothing runs after it on this branch.

## When to use it

- Look at what a page node or an AI node returned while you build a workflow, right on the page.
- Show a small structured result (a record you extracted, a list of links) to the person running the workflow.
- For formatted text, use [Display Markdown](/nodes/extension/displaymarkdown/). To inspect runs without touching the page, open the node's output in the editor instead.

## Example workflow

1. Run the workflow from a [Hotkey](/nodes/builtin/trigger/hotkey/) trigger on any article.
2. Add [Get Page Metadata](/nodes/extension/getpagemetadata/).
3. Add **Display Object** with **Title** = `Page info` to see the title, description, language and sharing tags of the page in one panel.

## Common issues

- **Only the last item is shown.** The node runs once per incoming item, and each run replaces the panel. Combine the items first with [Aggregate](/nodes/builtin/datatransformation/aggregate/) to show them all in one panel.
- **No panel appears.** The panel is drawn on the active tab. Make sure the page you want is the active tab when the node runs; browser settings pages and the extension store cannot show it.
- **The node fails outside the extension.** This node runs in the browser extension; install it or run the workflow from the extension.
