Draw a colored frame around elements on the active tab for a few seconds, with an optional label, to point something out.

## What it does

For each selector in **Elements**, Highlight Elements marks **every** matching element with a purple frame and a tinted overlay, and shows **Label** above it. It scrolls each element into view, one after the other, so you can follow along. The highlight is removed after **Duration** milliseconds (3,000 by default).

The incoming item is passed on unchanged. The node does not wait for the highlight to fade: the workflow continues right after the elements have been marked.

Nothing on the page is changed apart from the temporary highlight.

## When to use it

- Show the user which elements a workflow found, read or is about to change.
- Check what a selector matches while you build a workflow, before deleting or clicking.
- Point out a result on the page, such as the cheapest price in a list.

## Inputs and settings

<AwfParamTable rows={[{"name":"Elements","type":"List","required":true},{"name":"Label","type":"Text","default":"highlight","description":"Label shown on the highlight indicator."},{"name":"Duration","type":"Number","default":"3000","description":"How long to keep the highlight visible in milliseconds."}]} />
{/* AUTO:settings:end */}

- **Elements**: one entry per thing to highlight. In each **Target Element**, click the crosshair button and click the element on the page, or type a CSS selector.
- **Label**: short text such as `Best price`. Clear it to show the frame without a label.
- **Duration**: in milliseconds, for example `5000` for 5 seconds.

## Example workflow

1. Open a page with a pricing table and run the workflow from a [Hotkey](/nodes/builtin/trigger/hotkey/) trigger.
2. **Highlight Elements** with **Elements** = `.plan--recommended`, **Label** = `Our pick` and **Duration** = `5000`.
3. [Screenshot Page](/nodes/extension/screenshotpage/) with **Mode** = **Viewport** captures the page with the highlight visible.

## Common issues

- **Nothing is highlighted.** The selector matched nothing. Check it with **Ping**, or wait for the element first with [Wait For Element](/nodes/extension/ui/wait-for-element/).
- **The highlight disappears too fast.** Raise **Duration**. A value of `0` removes it after about 2 seconds.
- **Images and form fields get an outline but no label.** Elements that cannot hold other content (images, inputs) get an outline and glow instead of an overlay, without the label.
- **The node fails outside the extension.** This node runs in the browser extension; install it or run the workflow from the extension.
