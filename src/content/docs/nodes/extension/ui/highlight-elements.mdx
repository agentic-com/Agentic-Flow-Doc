Highlight selected elements in the opened page

## What it does

Visually highlights selected elements on the page with colored borders or overlays.

## When to use it

Use this node to draw attention to specific elements, guide users, or debug element selection.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Elements** | List |  | Yes |  |
| **Label** | Text | `highlight` | No | Label shown on the highlight indicator. |
| **Duration** | Number | 3000 | No | How long to keep the highlight visible in milliseconds. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Highlight Elements after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
