# Highlight Elements

Highlight selected elements in the opened page

## What it does

Highlight Elements belongs to the **In Page Action** palette group. Its canonical node id is `highlightElementsNode` and its source documentation link is `/nodes/extension/ui/highlight-elements/`.

## When to use it

Use Highlight Elements when the workflow needs to read from, write to, or interact with the currently open browser page.
