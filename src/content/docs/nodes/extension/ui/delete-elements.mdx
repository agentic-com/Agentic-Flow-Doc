Delete selected UI elements from the opened web page

## What it does

Removes selected DOM elements from the current page.

## When to use it

Use this node to clean up page content, remove distractions, or modify page layout for better readability.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **Elements** | List |  | Yes | List of DOM elements to delete from the opened web page. |
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Delete UI Elements after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
