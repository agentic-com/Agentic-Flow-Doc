Fill a form on the opened web page

## What it does

Automatically fills form fields on a web page with specified values.

## When to use it

Use this node to automate form submissions, data entry, or testing workflows.

## Inputs and settings

{/* AUTO:settings:start */}
This node has no settings.
{/* AUTO:settings:end */}

## Outputs

{/* AUTO:outputs:start */}
One output port.

Each output item has the fields `result` (list of entries).
{/* AUTO:outputs:end */}

## Dependencies and credentials

{/* AUTO:deps:start */}
None. This node needs no credential and has no slots for other nodes.
{/* AUTO:deps:end */}

## Example workflow

Run Form Fill after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
