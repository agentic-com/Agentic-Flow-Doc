Set attributes and styles on selected elements in the opened page

## What it does

Modifies HTML attributes and CSS styles of selected elements on the page.

## When to use it

Use this node to customize page appearance, modify element behavior, or apply dynamic styling.

## Inputs and settings

{/* AUTO:settings:start */}
| Setting | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| **DOM Selector** | Page element |  | Yes | The selector of the DOM element to interact with. |
| **Attributes** | List of entries |  | No |  |
| Attributes (each entry) › **Name** | Text |  | Yes |  |
| Attributes (each entry) › **Value** | Text |  | No |  |
| Attributes (each entry) › **Remove** | Toggle | Off | No |  |
| **Styles** | List of entries |  | No |  |

{/* AUTO:deps:start */}

{/* AUTO:deps:end */}

## Example workflow

Run Set Element Attribute Style after opening the target page, then pass its output to Edit Fields, an AI node, or an integration node.

## Troubleshooting

- Check that required settings are present before running the node.
- If the node uses browser page data, run it on the target tab after the page has loaded.
- If it calls an external service, verify credentials, permissions, and rate limits.
