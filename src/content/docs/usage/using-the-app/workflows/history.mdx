Workflow history helps you go back to an older version of a workflow.

## Understand workflow history

`Agentic WorkFlow` creates a new version when you:

- Save your workflow.
- Restore an old version. `Agentic WorkFlow` saves the latest version before restoring.

:::note[Workflow history and execution history]
Don't confuse workflow history with execution history.

Executions are workflow runs. With the executions list, you can see previous runs of the workflow.

Workflow history is previous versions of the workflow: for example, a version with a different node, or different parameters set.
:::

A run paused by [Wait For Approval](/nodes/builtin/flow/wait-for-approval/) appears in the executions list as a **waiting** run, and can be approved, rejected, or cancelled from there.

## View workflow history & restore

To view a workflow's history:

<Steps>
1. Open the workflow.
2. Select **Workflow history** <History class="inline-block m-0" />. `Agentic WorkFlow` opens a menu showing the saved workflow versions, and a canvas with a preview of the selected version.
3. Select the version you want to restore.
</Steps>
