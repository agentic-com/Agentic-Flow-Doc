---
title: Notes & "How this flow works"
description: "Add plain-language notes to workflow steps and read any flow as a numbered story — no code required."
---

A workflow can explain itself. Add a plain-language **note** to any step, and
Agentic WorkFlow shows it as a sticky note on the canvas and reads all the
notes back as a numbered story. This makes a flow someone shared with you
legible **the moment you open it** — you learn it by reading, not by studying.

---

## Add a note to a step

There are three ways to annotate a node — all open the same markdown editor:

1. **Hover** a node and click the **✎ Annotate** button.
2. **Right-click** a node and choose **Annotate this step** (or **Edit note** if
   it already has one).
3. Open the node's settings and edit the **Notes** field in the **Settings**
   tab.

Notes support **markdown**, so you can use bold, lists, and links to explain
what a step does and why.

> A note is meant for humans — say what the step accomplishes in plain words
> ("Grabs the product price from the page"), not how it's configured.

---

## See the notes on the canvas

Every step that has a note shows a **sticky-note callout** attached beneath it.
Steps without a note stay clean — there's no clutter for un-annotated nodes.
Click the ✎ on a callout to edit that note.

---

## Read the flow as a story

Click the **📖** button on the canvas toolbar to open **How this flow works**.
It lists every step in the order the flow runs and reads its note as a numbered,
plain-language story. A step with no note yet shows a gentle gap so you can see
what's still unexplained.

When you open a **template**, a **downloaded flow**, or any flow that already
has notes, the story panel **opens automatically** — so a flow someone sent you
reads like a walkthrough right away. You can reopen it any time with the 📖
button, including when you're only viewing a flow you can't edit.

---

## Let AI draft your notes

If you'd rather not start from a blank note, the assistant can draft one for you
in plain outcome-language — you stay in control and edit or approve what it
writes.

- **One step:** in the annotate dialog, click **✨ Draft with AI**. It reads the
  step and fills the editor with a suggested note; edit it, then **Save**.
- **The whole flow:** open **How this flow works** and click
  **✨ Draft missing notes**. A review window drafts a note for every step that
  doesn't have one yet, filling them in as it goes. For each one you can
  **Accept**, tweak the text first, or **Skip** — or **Accept all** at once.

Nothing is written to your flow until you accept it. The drafts describe what
each step accomplishes, not how it's configured, and your step settings (like
keys or tokens) are never sent along.

**Setting up AI:** drafting uses whichever AI provider you've configured for the
assistant (or a local model). If you haven't set one up yet, the ✨ buttons stay
disabled with a hint — add a provider in the assistant setup to enable them.
