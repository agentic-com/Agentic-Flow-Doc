AWFlow works in two ways:

- **Local workspace**: no account. Everything is saved in this browser, on this device. The sidebar shows *Local workspace · Saved on this device*.
- **Signed in**: you have an account. Each workflow and credential can be saved **in the cloud** (available wherever you sign in) or **locally** (this browser only).

The first time you open AWFlow without an account, you start in a local workspace. No login wall.

## What you get with each

| | Local workspace | Signed in |
| --- | --- | --- |
| Build and run workflows | Yes, no limits | Yes |
| Cloud storage across devices | No | Yes, within your [plan](/usage/using-the-app/settings/plan/) |
| Install from the Marketplace | No | Yes |
| Publish to the Marketplace | No | Yes (cloud workflows) |
| Request board voting | No | Yes |
| [Notifications](/usage/using-the-app/notifications/) | No | Yes |
| Profile and password | No | Yes |
| Chats, agents, memory, knowledge bases, AI providers | On this device | On this device |

Some things always stay on the device, whichever mode you use: chats, agents, memory, knowledge bases, AI providers, the data store, Safe mode and site permissions. See [Privacy & data](/usage/privacy-and-data/).

## Sign in from a local workspace

Use **Sign in** in the sidebar's user menu, in **Settings › General**, or on any screen that needs an account. See [Sign up and log in](/usage/using-the-app/account/sign-up-and-login/).

## Bring your local work to your account

The first time you sign in with local workflows or credentials, AWFlow asks **Move local items to your account?**

<Steps>

1. Tick the **Workflows** and **Credentials** you want in the cloud.

2. Click **Move selected to cloud**, or **Keep local** to leave everything where it is.

</Steps>

Anything you don't move stays on this device and keeps working. Later, move single items with **Move to cloud** / **Move to local** in the workflow or credential menu, or several at once from the [workflows list](/usage/using-the-app/workflows/manage-list/#bulk-actions).

<Aside>
If your local credentials are protected by a passphrase, unlock them first in **Settings › Preferences** to move them. See [Local secret vault](/usage/using-the-app/account/secret-vault/).
</Aside>

## Choose where new items go

Signed-in users set the default in **Settings › Preferences › Default storage location**. You can still pick each time you create a workflow or credential.
