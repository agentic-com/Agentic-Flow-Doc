The **Assistant Notch** is an optional floating button that the awflow browser extension can show on the web pages you visit. Clicking it opens a small panel with quick actions — the same actions available from the extension's right-click menu, plus a shortcut to run a matching workflow on the current page.

It is off by default, and only appears once you enable it.

## Enable or disable it

1. Go to **Settings → Preferences**.
2. Toggle **Assistant Notch** on (or off).

When enabled, the notch appears on each new web page you open. When disabled, it stops appearing.

The notch is injected by the browser extension, so it only shows on standard `http(s)` web pages — not on browser system pages (like `chrome://`), the extension gallery, or local file/PDF viewers.

## What's in the panel

Clicking the notch opens a panel with:

- **Run a workflow here** — any of your workflows that have a context-menu trigger applicable to the current page. Selecting one runs it against the current tab.
- **Get / Refresh Workflows** — refreshes the list of workflows the extension knows about.
- **Open in Side Panel** — opens awflow in the browser side panel.
- **Open in Full Tab** — opens awflow in a full browser tab.
- **Open chat** — opens the chat assistant for the current page.

These are the same actions you get from the extension's right-click (context) menu — the notch just puts them one click away without opening the menu.

## Notes

- The notch is separate from the chat launcher; when both are enabled they sit in different corners so they don't overlap.
- Because it runs inside the extension, the notch requires the awflow browser extension to be installed and active.
