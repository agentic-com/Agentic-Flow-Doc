# Chat with Aria

**Aria** is the assistant built into AWFlow. Open **Assistant** in the sidebar: the home screen is a chat. Ask anything — explain, write, summarise, translate, reason — and Aria answers as it types (streaming), even on small on-device models.

When you want something done again and again, say so ("every Monday…", "when this page changes…") or click **Build this as a workflow** under a reply. Aria then builds a workflow you can open in the canvas.

## The side panel

The panel on the left keeps everything one click away:

- **New chat** and **search** — search finds projects, chat titles, words inside your messages, and agents, all on this device.
- **Agents** — one row of avatars: click one to chat with that agent.
- **Pinned** — the projects and chats you pinned.
- **[Projects](/usage/using-the-app/chat-and-agents/projects/)** — each opens to its newest chats; *Show more* opens the project.
- **Recent** — chats that aren't in a project, team threads included.
- **Show all chats** — every conversation, with filters and bulk actions.

Use a chat's **⋯** menu to rename, pin, move it to a project or delete it — or drag it onto a project. In the narrow browser side panel, open the same list with the ☰ button.

## Models and privacy

The chat runs on the model you pick in the composer:

- **On-device models** (WebLLM, transformers.js, Chrome's built-in Gemini Nano) run entirely in your browser. Nothing you type leaves your device. Install them from [Local AI](/usage/using-the-app/local-models/).
- **Ollama models** on your computer appear automatically under **Ollama · this computer** when [Ollama](https://ollama.com) is running — every model you have pulled, no setup needed. They run on your machine, so nothing leaves it. Models without tool support are marked *Chat only*. To use an Ollama server on another address, add it once in **Settings › Providers** (kind *Ollama*, with its base URL): its models are then listed too.
- **Cloud providers** (OpenAI, Anthropic, Gemini, OpenRouter…) use your own API key from **Settings › Providers**.
- **Auto** uses your cloud providers first and falls back to an on-device model.

Each reply shows which model answered, whether it ran **on-device** or in the cloud, and its speed.

The first time you open Aria without a model — and no running Ollama, a short setup offers a recommended on-device model for your computer — or Chrome's Gemini Nano when it is available — and your cloud providers.

:::tip[Ollama not listed?]
Make sure Ollama is running (`ollama serve`, or the Ollama app) and has at least one chat model (`ollama pull llama3.1`). If you changed `OLLAMA_ORIGINS`, keep the browser extension allowed (`chrome-extension://*`). The list refreshes when you open a new chat.
:::

:::note
On-device answers are generated in a background page, so a chat keeps going while you switch tabs. Small models are fast and private but can make mistakes; double-check important answers.
:::

## Working with replies

Under each reply:

- **Copy** the answer.
- **Regenerate** for another answer; use **‹ ›** to switch between answers.
- **Branch** into a new chat from that point.
- Edit one of your messages and send it again — everything after it is answered again.
- **Stop** a reply while it is being written; what was written so far stays.

## Chat settings

The settings button in the chat header opens **Chat settings** for the current chat:

- **Model** for this chat.
- **Instructions for this chat** — extra guidance only this chat follows.
- **Creativity** — from *Precise* to *Creative*.
- **Use Aria's memory** — turn memory off for one chat.
- **Knowledge** — pin **Knowledge Base** collections (sidebar › Knowledge Base) the chat can draw on, and choose when to use them (always, when relevant, or only when you ask). A lock on a collection means it is **never sent to cloud models**.

A **context meter** shows how much of the model's context window the conversation uses; older messages are trimmed automatically when it is full.

## Page context, files and dictation

Use **+** in the composer to give Aria more to work with:

- **This tab** or **other open tabs** — Aria reads the page text.
- **Selection** — the text you selected on the page.
- **Files** — PDFs, text files and images. Long files are condensed **on-device** to fit the model, and the steps are shown under the reply ("Read report.pdf · condensed on-device").
- **Screenshot** of the current tab.

Click the **microphone** to dictate. Speech is transcribed by an on-device Whisper model; your voice never leaves the browser.

When Aria answers from your Knowledge Base, the sources appear as numbered chips under the reply.

## Memory

Aria remembers lasting preferences you share ("I prefer guesthouses over chain hotels") and your explicit requests ("remember that my budget is €600"). When it learns something, a small **Updated memory** notice appears with **Undo**.

Memories are stored **only on this device**. See and edit them per agent in the agent's **Memory** tab, or remove everything in **Settings › Privacy › Agent memory**.

## Talk to other agents

Type **@** to bring one of your [agents](/usage/using-the-app/chat-and-agents/agents/) into the chat for one answer ("@writer turn this into an email"), or a [team](/usage/using-the-app/chat-and-agents/teams/) to start a team thread ("@trip-crew 3 days in Rome"). Use the agent switcher in the chat header to chat with another agent.
