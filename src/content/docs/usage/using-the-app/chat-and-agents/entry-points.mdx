# Ways to open Aria

You don't have to open the app to ask Aria something. All of these use the same models and privacy as the [chat](/usage/using-the-app/chat-and-agents/chat/).

## Right-click

Right-click on any page:

- **Ask Aria about selection**, **Explain simply**, **Translate selection…** — on selected text.
- **Summarize page** — on the page.
- **Describe image** — on an image.
- **Send to a team…** — hand the page or selection to one of your [teams](/usage/using-the-app/chat-and-agents/teams/) as a new thread.
- **Add page to project…** — save the page (or selection) as a file in one of your [projects](/usage/using-the-app/chat-and-agents/projects/).

The answer appears in a small card on the page. Pick a **project** in the card to answer with its context. **Open in full chat** continues the conversation in the assistant.

## Keyboard shortcut

Press **Ctrl+Shift+K** (**⌘+Shift+K** on Mac, **Alt+Shift+K** in Firefox) for the quick-chat palette over the current page. Change the shortcut in your browser's extension shortcuts page.

## Address bar

Type **aw**, a space, then your question in the address bar:

- `aw what is a good name for a cat` — answers in the palette.
- `aw tab: summarize this` — about the current tab.
- `aw @trip-crew weekend in Porto` — opens the full assistant with an agent or team mention.
- `aw #lisbon what is still missing` — asks inside a project.

Recent chats appear as suggestions; pick one to reopen it.

## Notch

When the [Assistant Notch](/usage/using-the-app/assistant-notch/) is on, it offers a quick chat and **Page tools** (summarize, explain, translate) for the page you are on.

## Side panel

The [side panel](/usage/using-the-app/side-panel/) shows the same chat in a narrow layout, with the agent switcher at the top.
