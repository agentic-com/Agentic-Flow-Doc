## Why follow a learning path?

Following this path helps you move from first steps to confident builder in a structured way.  
You’ll understand key concepts, practice with real examples, and learn how to automate browser tasks — all without coding.

If you prefer a faster start, you can skip directly to the [Quick Setup Guide](/usage/getting-started/quick-starts/quick-intro/) or jump to [Create Your First Workflow](/learning/text-courses/beginner/first-workflow/).

---

## Step 1: Get familiar with the environment

### What to do

- [Install or activate the extension](/usage/getting-started/quick-starts/quick-intro/) in your browser.
- Open the Workflow Builder and explore: canvas, nodes, and connections.
- Run a built-in template to see how workflows behave.
- Observe how triggers start workflows and how each node executes.

### Why this matters

This step introduces you to how `Agentic WorkFlow` works inside your browser — no external servers, no setup complexity.  
Once you know the interface, you’ll feel confident building any workflow.

> Tip: Visit [Key Concepts](/usage/key-concepts/) anytime for concise explanations of workflows, nodes, and triggers.

---

## Step 2: Build your first workflow

### What to do

- Create a new workflow or clone one from the [Marketplace](/marketplace/).
- Add a Trigger node (for example: “Page Loaded” or “Button Clicked”).
- Add an action like Get Selected Text or Extract Links.
- Run the workflow and inspect the data flow between nodes.
- Modify parameters, rerun, and see how results change.

### Why this matters

This is your first hands-on experience. You’ll see how nodes pass data and how easy it is to create working automations.

> Learn more in [Create Your First Workflow](/learning/text-courses/beginner/first-workflow/).

---

## Step 3: Learn the core concepts

### Topics to cover

- What a node does and how it processes data
- The difference between triggers and actions
- How data flows between nodes (inputs and outputs)
- Using the execution log to debug a run
- Reusing workflows or sharing them via the [Marketplace](/marketplace/)
- Browser-specific automation with [Browser Nodes](/integration/extension/)
- Adding AI and reasoning with [Local AI Nodes](/usage/local-ai/)

### Why this matters

These are the building blocks of all workflows. Once you understand them, you can create flexible and reliable automations.

> For definitions and examples, see [Key Concepts](/usage/key-concepts/).

---

## Step 4: Build intermediate workflows

### What to try

- Automate a small real-world task:
  - Save highlighted text to a local file
  - Extract all links and summarize them with an AI node
  - Monitor a page for updates using “Wait for Element”
- Combine browser actions:
  - Scroll, extract, then fill a form automatically
- Add conditional logic:
  - “If page title contains X, then Y”
- Share your creations on the [Marketplace](/marketplace/)

### Why this matters

This step helps you transform simple ideas into practical automations — connecting data extraction, AI, and browser control together.

> Explore browser-specific actions in [Browser Nodes](/integration/extension/).

---

## Step 5: Master and share

### What to aim for

- Publish and share workflows on the [Workflow Marketplace](/marketplace/)
- Build reusable templates or sub-workflows
- Create advanced automations with [AI & Knowledge Base Workflows](/usage/local-ai/)
- Learn to handle errors and timeouts for stability
- Contribute to the community by sharing your best workflows

### Why this matters

You’re now designing intelligent, reliable workflows that others can reuse.  
You’re part of the growing `Agentic WorkFlow` ecosystem.

> Visit [Troubleshooting & Best Practices](/usage/troubleshooting/) to make your workflows more robust.

## Tips for beginners

- Start small — try extracting text or links first.
- Use the [Node Library](/usage/node-library/) to explore available nodes.
- Test step by step and inspect outputs.
- Save your progress often — everything stays local and private.
- Reuse workflows from the [Marketplace](/marketplace/) to learn faster.

---

With this path, you’ll move from basic understanding to creating intelligent browser automations.  
Each workflow you build brings new insight — and new possibilities.
