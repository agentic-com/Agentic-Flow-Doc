This guide is for the people who run the AWFlow service: moderators and administrators. If your account doesn't have an admin role, you won't see any of these screens.

## Who can open it

Only accounts with the **admin** or **superadmin** role can open admin screens. Anyone else who follows an admin link is sent back to the app. The server checks the role again on every request.

## Open the Admin panel

<Steps>

1. Click the panel switcher at the top of the sidebar. Admins see it in place of the plain logo.

2. Under **Panels**, pick **Admin**.

3. The sidebar now lists the admin screens. Click one to open it.

</Steps>

Switch back to **Studio** the same way. **Settings** and **Help** stay at the bottom of the sidebar in both panels. The command palette (<kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd>) also lists the **Users** and **Marketplace** admin screens.

## Tables work the same everywhere

Most admin screens share one table design:

- a **Filter...** search box and filter buttons, with **Reset** to clear them,
- **Customize Columns** to show or hide columns, and sortable column headers,
- **Rows per page** and page buttons at the bottom.

Each table remembers its sort and filters in your browser.
