Published: **September 8, 2026**

## Highlights

Version 0.6.0 is the largest release so far. It introduces an AI assistant that drafts workflows for you, a community marketplace with templates and safe sharing, a big expansion of app integrations built on modern OAuth, a browser-native node set that runs without extra permissions, and a trust layer that shows what a workflow touches and asks for consent before it runs. Under the hood, the cloud data layer moved to a new backend.

## AI Workflow Assistant

Describe the outcome you want and let the assistant draft a workflow on the canvas, then refine it by hand. It previews the result before you keep it, and runs on free in-browser models or a provider you connect.

## App Integrations

This release greatly expands the integration set: GitHub, Discord, Telegram, Linear, Todoist, Google Calendar, Microsoft 365 (Graph), HubSpot, Raindrop, Trello, Push Notifications (ntfy / Pushover), Baserow / NocoDB, Supabase, and Obsidian. A Custom API node connects to any service from its OpenAPI definition. Sign-in uses an auth-code + PKCE OAuth flow.

## Trust & Transparency

Every workflow now shows what it touches before it runs. Grant page and integration access per site, approve sensitive actions with per-run consent, and rely on a Safe / Trusted mode to control where automations can act. Shared workflows never carry secrets.

Relevant docs:

- [Permissions and security](/usage/troubleshooting/permissions-security/)
- [Action approval](/advanced-ai/concepts/action-approval/)

## Self-Explaining Workflows

Published workflows can carry narration — per-node notes, callouts, and a story panel that explains each step on open. The assistant can draft narration in a plain-outcome voice, and a Narrated badge marks flows that include it.

Relevant docs:

- [Narrated workflows](/usage/using-the-app/workflows/narration/)

## Cloud Data Layer Migration

The cloud data layer moved from SurrealDB to a new backend API. This is an internal change with no action required, but it underpins the marketplace, sharing, and account features in this release.
