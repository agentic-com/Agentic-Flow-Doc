## Highlights

Version 0.2.3 continues the development line after v0.2.2. It is best read as a maintenance release focused on continuing the early workflow builder iteration.

## Development Update

After updating, run important workflows manually and inspect node outputs before relying on automated triggers. This is especially important for workflows that combine browser actions, data mapping, and service calls.
