## Highlights

Version 0.2.4 continues the development line after v0.2.3. It is best read as a stability and iteration release rather than a major feature release.

## Development Update

This release keeps the application moving toward more reliable workflow authoring. When updating from earlier versions, retest workflows that depend on browser page state or complex data mappings.
