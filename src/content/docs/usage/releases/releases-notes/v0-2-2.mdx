## Highlights

Version 0.2.2 includes remote asset authentication work and a development update.

## Remote Asset Authentication

Remote asset manipulation now uses JWT-based authentication. This affects workflows or app behavior that depend on authenticated remote assets, making credential handling more explicit and aligned with token-based access.

Relevant docs:

- [Create credentials](/usage/using-the-app/credentials/create/)
- [Edit credentials](/usage/using-the-app/credentials/edit/)
- [Permissions and security](/usage/troubleshooting/permissions-security/)

This release also includes general development work. After updating, verify workflows that access protected services or assets and confirm credentials still behave as expected.
