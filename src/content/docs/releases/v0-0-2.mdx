## Notes

### Bug Corrections

This early release includes general bug corrections. If a workflow created on an earlier build behaves unexpectedly, test it step by step and inspect the output of each node.

Relevant docs:

- [Full and partial executions](/app/workflows/executions/run-from-the-canvas/)

### Design System Update

The app design moved toward the `shadcn-svelte` template system. This primarily affects the interface, not workflow logic, but it improves consistency across settings, panels, forms, and workflow controls.
