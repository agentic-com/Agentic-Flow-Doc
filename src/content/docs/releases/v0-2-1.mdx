## Highlights

Version 0.2.1 fixes user image display in settings and includes demo-related bug corrections.

## User Image Display In Settings

User images in settings display more reliably in this release. This is a user-interface fix and does not change workflow execution behavior.

Relevant docs:

- [Create credentials](/app/connections/create/)
- [Edit credentials](/app/connections/edit/)

## Demo Bug Corrections

Demo-related fixes make early examples and demonstrations more reliable. If you learned from an older demo, rerun the workflow and inspect each node output because browser state and data mappings may now be easier to validate.

Relevant docs:

- [Quick intro](/get-started/quick-intro/)
- [Long intro](/get-started/long-intro/)

This release also includes general development work toward the early workflow builder experience.
