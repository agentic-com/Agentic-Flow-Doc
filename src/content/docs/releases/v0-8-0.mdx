Published: **October 5, 2026**

## Highlights

Version 0.8.0 makes Aria chat-first. You can now talk to Aria from anywhere in
the browser, build your own agents with skills, rules and memory, group them
into teams, and organise work into projects. Around that, the release brings
on-device AI through TensorFlow.js and transformers.js, durable flow control
that survives a closed tab, a wave of new nodes, binary file handling, a
redesigned Executions view, a side panel where every screen works at narrow
widths, and the groundwork for Firefox support.

It also includes the fixes from a full product audit: the execution engine,
scheduler, extension security and performance all got targeted work.

The sections below group the changes by theme. Where a change affects how you
build or run workflows, the relevant docs are linked.

## Chat-first Aria, agents and teams

Aria moved from a workflow-drafting assistant to a chat you can open from
anywhere:

- **Chat core** with page context and knowledge, reachable from the
  right-click menu, the address bar (omnibox), a keyboard shortcut, and the
  notch quick chat.
- **Agents** with their own skills, rules, memory and activity log. Every
  built-in agent skill was checked and fixed so it actually works.
- **Live browser control** and **routines**, so an agent can act on the page
  you're on, with safety checks.
- **Teams of agents** that hand work to each other in a shared thread.
- **Projects** that group chats, files and agents, with a reorganised side
  panel and a redesigned project context panel.
- An **agent and team templates marketplace** to start from a ready-made
  agent.
- **Characters with living eyes** give each agent a recognisable face.
- Agent and team workspaces now fill the full height of the window, with
  pinned side rails and consistent tab headers.

## Building workflows with the assistant

The workflow builder inside the assistant is easier to follow and to trust:

- A **thinking timeline** shows each build stage as it happens.
- A **change plan** lists what will change before anything is applied, and
  the canvas **highlights** the changed nodes afterwards, with a streamed
  summary of the build.
- A real **read-only canvas preview** in the dock shows the draft workflow.
- Deterministic **structure fixups** and **schema-guided decoding** make
  drafts from local models more reliable.
- A **grouped model selector** (Auto / Cloud / On-device), a **Local/Cloud
  indicator**, and a nudge to go offline when an on-device model would do.
- **Ollama models are detected automatically** and appear in the model picker.
- The assistant no longer freezes the UI when it opens.

## Local AI and local models

On-device AI now covers far more than chat:

- **Local AI** runs TensorFlow.js and transformers.js models in a worker, with
  task nodes for text generation, summarising, translation, classification,
  question answering, image captioning, object detection and audio
  transcription.
- The **Local Models** page lets you see, install and delete in-browser
  models, browse the Hugging Face Hub with real model sizes, and filter by
  task or tool support. A **tool-capable** badge marks models that can call
  tools.
- **Prompt-based tool calling** lets WebLLM and Transformers Chat models run
  the Tools Agent, so agents can work fully on-device.
- The app checks your GPU **before** installing a WebLLM model it can't run.

## Durable flow control

Long-running workflows can now pause and resume safely:

- **Wait** of one minute or more survives closing the tab or the extension
  being unloaded (up to 30 days).
- **Poll Until** checks a URL until your conditions are met or a deadline
  passes.
- **Split in Batches** processes items in chunks, including durable
  checkpoints between batches.
- **Nested and batch suspend**: approvals and forms can pause inside loops and
  sub-workflows.
- When a run needs your response, you get a **top-bar badge, a sound, and a
  desktop notification**, and the approval or form card can appear **on the
  web page** you're on.
- **Loop** now allows up to 1,000 iterations.

## Building and running workflows

- A richer **`{{ }}` expression language**, and `$('label')` references now
  work for node labels that contain spaces.
- The **Code node** reads upstream data as `input` (including fan-in), and
  Python runs in an isolated worker per run.
- **Continue On Fail** per node, and per-node **retry** with a backoff
  strategy and retry-on-condition.
- A failed node now stops **only its own branch**, and a node with no output
  no longer stops the run.
- **Output schema contracts** validate what a node produces and show expected
  output previews.
- Workflows can declare a **minimum extension version**, and installing is
  blocked on older versions.
- The canvas **never loses an edit**: a save status, a leave guard, and
  Cmd+S / Cmd+Z.
- Node notes are hidden by default and revealed from a pin badge; the flow
  story opens only the first time.
- **Element Change** can watch a list of selectors picked from the page.

## Files and binary data

Workflows can now carry files. A `$binary` model with sources, sinks and an
output panel preview moves files between nodes; large files are stored locally
or in the cloud and expire automatically. Gmail can send attachments and Notion
can upload file and image blocks.

This release lays the groundwork for a Firefox version of the extension: a
Firefox build, a sidebar in place of Chrome's side panel, sign-in and
integration OAuth that work in Firefox, browser-specific copy, and a built-in
data-collection consent. The Chrome AI node explains that it only works in

## Privacy and security

- **Anonymous usage telemetry** (funnel events and error reports) with a new
  **Privacy** settings section where you can turn it off.
- The extension validates message senders, the fetch bridge re-checks
  redirects, and the injected notch and chat are hardened against the host
  page.
- Secrets in the local vault are always encrypted, and the storage encryption
  key is created only once (fixes a "Not authenticated" error after sign-in).
- If sign-in requires a password reset, the app now tells you so.

Relevant docs:

- [Permissions and security](/app/troubleshooting/permissions-security/)

## Reliability and performance

- **Engine fixes**: no more double runs or re-runs on resume, resumed runs no
  longer disappear, sub-workflow failures and cancels reach the parent,
  nested loops rewind correctly, and failures are attributed to the node that
  actually failed.
- **Scheduler fixes**: correct day-of-month and DST handling, and durable-wait
  alarms are kept when schedules sync.
- **Faster app**: heavy libraries (WebLLM, node SDKs) load only when needed,
  the chat and notch are injected on demand, the dashboard loads in parallel,
  the canvas uses a shared graph index, undo history is capped, and only the
  last 100 executions per workflow are kept locally.
