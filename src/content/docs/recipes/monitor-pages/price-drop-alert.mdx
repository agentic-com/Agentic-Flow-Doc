## Test it

<Steps>

1. Install the recipe, open **When the price changes**, and pick the price element on your product page with the crosshair. Set **URL Patterns** to that site.
2. Save and activate the workflow.
3. Keep the product page open. Element Change only watches pages that are open in the browser.
4. To try it without waiting for a sale, open the page's developer tools and edit the price text to a lower number. A **Price dropped!** notification appears.

</Steps>

## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Back in stock | Set **Fire when** to **Text matches** with **Match text** `In stock`, and drop the Regex, Data Store and IF steps. | Beginner |
| Check pages that aren't open | Use a [Schedule](/nodes/builtin/trigger/schedule/) trigger with [Get HTML from Link](/nodes/builtin/core/gethtmlfromlink/) and [HTML Extract](/nodes/builtin/datatransformation/html-extract/) to read the price. | Advanced |
| Log every price | Add [Google Sheets](/nodes/builtin/integration/google-sheets/) **Append** after Remember this price to chart the history. | Intermediate |

## Troubleshoot

- **It never fires.** The selector doesn't match the price, or the page isn't open. Re-pick the element with the crosshair and check **URL Patterns**.
- **The first change never alerts.** There's no stored price yet, so the comparison fails once. The second change works.
- **The number is wrong.** The element holds more than the price (such as "Was 99, now 79"). Pick a tighter element, or adjust the Regex **Pattern**.
