## Test it

<Steps>

1. Install the recipe and pick a model in **Local AI model** (it downloads once; see [Local models](/app/local-models/)).
2. Save and activate the workflow.
3. Type "hey can u send the report asap thx" in any text box, highlight it, right-click and choose **Agentic Workflow** › **Personal Workflows** › **Rewrite Professionally**.
4. Paste: you get something like "Hello, could you please send the report as soon as possible? Thank you."

</Steps>

## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Fix grammar only | Change **Prompt** to `Fix spelling and grammar. Keep my wording. Return only the text:`. | Beginner |
| Draft a reply | Select a message and prompt `Write a short, polite reply to this:`. | Beginner |
| Better writing, hosted model | Plug [OpenAI](/nodes/builtin/ai/aidependencies/llm/openai/) into the **Model** slot. Your text then goes to that provider. | Beginner |

## Troubleshoot

- **The rewrite adds "Here is the rewrite:".** Small models chat. Add `Do not add any introduction.` to the prompt, or pick a larger model.
- **Nothing to paste.** The model is still downloading on the first run. Wait for the run to finish (see the run log), then paste.
- **The menu entry is missing.** Activate the workflow, then right-click and choose **Get / Refresh Workflows**.
