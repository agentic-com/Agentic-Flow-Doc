## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Keep the exact text | Remove Information Extractor and map `selection` straight to the task content. No model needed. | Beginner |
| Add the page link | Add [Get Page Metadata](/nodes/extension/getpagemetadata/) and put its `url` in the task description. | Intermediate |
| Several tasks at once | Use an [Item List Output Parser](/nodes/builtin/ai/aidependencies/outputparser/itemlistoutputparser/) to split meeting notes into one task per action. | Advanced |

## Troubleshoot

- **The task title is empty.** The model returned nothing usable. Select a longer passage, or pick a larger model.
- **Todoist says the request is unauthorized.** Reconnect Todoist in the node's connection picker.
- **The menu entry is missing.** Turn the workflow On, then right-click and choose **Get / Refresh Workflows**.
