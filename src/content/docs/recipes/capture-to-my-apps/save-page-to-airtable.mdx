## Test it

<Steps>

1. Install the recipe. Open **Add a record to Airtable**, choose or create an Airtable connection, then pick the **Base** and **Table**. See [AirTable](/nodes/builtin/integration/airtable/). To import the file yourself, use **Add Workflow** › **Import**, choose the `.awf` and click **Create & open**. Then click **Make it mine** at the bottom of the canvas, tick the box and confirm, so you can edit it. To add the connection itself, see [Create a connection](/app/connections/create/).

   <StepShot shot="recipe-airtable-import" spot="create-open" n={1} />

   <StepShot shot="recipe-airtable-consent" spot="make-it-mine" n={1} />

   <StepShot shot="recipe-airtable-save-airtable" spot="credential" n={1} />

2. Make sure the table has a **Name** and a **URL** column (or rename the keys in the node to your columns).
3. Save and activate the workflow.

   <StepShot shot="recipe-airtable-canvas" spot="active" n={3} />

4. Right-click any page and choose **Agentic Workflow** › **Personal Workflows** › **Save Page to Airtable Reading List**.
5. Open the table in Airtable: a new row shows the page title and link.

</Steps>

## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Save to Notion instead | Replace the Airtable step with [Notion](/nodes/builtin/integration/notion/) and pick your database. | Beginner |
| Save to Google Sheets | Replace it with [Google Sheets](/nodes/builtin/integration/google-sheets/) **Append** and map title and URL to columns. | Beginner |
| Add an AI summary | Insert [Get All Text](/nodes/extension/getalltext/) and [Summarization](/nodes/builtin/ai/aiagents/summarizationchainnode/) before Airtable and map the summary to a column. | Intermediate |

## Troubleshoot

- **"Unknown field name".** A key in the record's fields doesn't match a column in your table. Column names are case-sensitive.
- **The run fails on Airtable with an authorization error.** The connection's token can't reach this base. Give it access to the base in Airtable, then check the connection in AWFlow.
- **The menu entry is missing.** Turn the workflow On, then right-click and choose **Get / Refresh Workflows**.
