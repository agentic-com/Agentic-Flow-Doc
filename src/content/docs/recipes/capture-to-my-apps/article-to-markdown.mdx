## Test it

<Steps>

1. Install the recipe and save it. No setup is needed. To import the file yourself, use **Add Workflow** › **Import**, choose the `.awf` and click **Create & open**. Then click **Make it mine** at the bottom of the canvas, tick the box and confirm, so you can edit it.

   <StepShot shot="recipe-markdown-import" spot="create-open" n={1} />

   <StepShot shot="recipe-markdown-consent" spot="make-it-mine" n={1} />

   <StepShot shot="recipe-markdown-canvas" spot="save" n={1} />

2. Open an article, right-click it and choose **Agentic Workflow** › **Personal Workflows** › **Capture Article as Markdown**.
3. Paste into a note: you get headings, paragraphs and links as Markdown.

</Steps>

## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Straight into Obsidian | Replace Clipboard Write with [Obsidian](/nodes/builtin/integration/obsidian/) to create a note. | Intermediate |
| Only the selection | Replace Get All HTML with [Get Selected Text](/nodes/extension/getselectedtext/) and skip the conversion. | Beginner |
| Add a title line | Add [Get Page Metadata](/nodes/extension/getpagemetadata/) and put `# title` and the URL above the Markdown in Clipboard Write's **Text**. | Intermediate |

## Troubleshoot

- **The Markdown is full of menus and ads.** Set **DOM Selector** on Get All HTML to the article container.
- **Nothing is pasted.** Clipboard Write writes on the page you ran it on. Run it from the right-click menu on the article rather than from the canvas.
- **Images are missing.** **Keep Images** is off by default in this recipe; turn it on in the Markdown step.
