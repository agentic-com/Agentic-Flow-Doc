A recipe is a complete workflow for one job, such as summarizing a page or saving data to a sheet, with the steps explained so you can adapt it.

Until step-by-step recipes are written up here, the quickest way to start from a working workflow is the Marketplace: install one, open it on the canvas, and change it to fit.
