## Test it

<Steps>

1. Install the recipe, open it on the canvas and pick a model in **Local AI model**. The first run downloads it once; installed models start right away. See [Local models](/app/local-models/).
2. Save and activate the workflow, then open a long article.
3. Right-click the article and choose **Agentic Workflow** › **Personal Workflows** › **Summarize This Page**. If it's missing, choose **Get / Refresh Workflows** first.
4. A **Page summary** panel opens in the corner of the article with a few bullet points.

</Steps>

## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Summarize only what you select | Replace **Get All Text** with [Get Selected Text](/nodes/extension/getselectedtext/) and a [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger set to **Selection**. | Beginner |
| Use a hosted model for long pages | Plug [OpenAI](/nodes/builtin/ai/aidependencies/llm/openai/) or [Ollama](/nodes/builtin/ai/aidependencies/llm/ollama/) into the **Model** slot instead of Web LLM. | Beginner |
| Keep a reading log | Connect [Notion](/nodes/builtin/integration/notion/) or [Google Sheets](/nodes/builtin/integration/google-sheets/) to the Summarize step's output as a second branch, to save each summary with the page's title and link. | Intermediate |

## Troubleshoot

- **The panel never appears.** Display Markdown shows on the active tab. Run it from the right-click menu on the article itself, so the article is the active tab.
- **The model doesn't load.** Web LLM needs WebGPU, which some browsers and graphics cards lack. Use [Transformers Chat](/nodes/builtin/ai/aidependencies/llm/transformerschat/) as the model instead.
- **The summary covers the menu and the cookie banner.** Set **DOM Selector** on Get All Text to the article's container.
