## Test it

<Steps>

1. Install the recipe and pick a model in **Local AI model** (it downloads once; see [Local models](/app/local-models/)).
2. Save and activate the workflow.
3. On any page, highlight a sentence, right-click it and choose **Agentic Workflow** › **Personal Workflows** › **Explain Like I'm 5**.
4. An **Explanation** panel opens with a plain-words version.

</Steps>

## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Translate instead | Replace Basic LLM Chain with [Translate](/nodes/builtin/ai/localai/translate/), which needs no chat model. | Beginner |
| Explain code | Change **Prompt** to `Explain what this code does, step by step:` and select a code block. | Beginner |
| Keep the answers | Branch [Notion](/nodes/builtin/integration/notion/) off Basic LLM Chain to save each term and its explanation. | Intermediate |

## Troubleshoot

- **The menu entry is missing.** Activate the workflow, then right-click and choose **Get / Refresh Workflows**. It only shows on selected text.
- **The explanation is cut short or vague.** Small models struggle with long selections. Select a shorter passage or pick a larger model.
- **Nothing happens for a while.** The first run downloads the model. Watch the progress in the run log on the canvas.
