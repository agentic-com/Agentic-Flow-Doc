## Test it

<Steps>

1. Install the recipe and save it. No setup is needed. To import the file yourself, use **Add Workflow** › **Import**, choose the `.awf` and click **Create & open**. Then click **Make it mine** at the bottom of the canvas, tick the box and confirm, so you can edit it.

   <StepShot shot="recipe-csv-import" spot="create-open" n={1} />

   <StepShot shot="recipe-csv-consent" spot="make-it-mine" n={1} />

   <StepShot shot="recipe-csv-canvas" spot="save" n={1} />

2. Open a page with a table, such as a Wikipedia list.
3. Right-click it and choose **Agentic Workflow** › **Personal Workflows** › **Page Table to CSV**.
4. Paste into a new spreadsheet: each column lands in its own cell.

</Steps>

## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Send rows to a sheet | Replace CSV and Clipboard Write with [Google Sheets](/nodes/builtin/integration/google-sheets/) **Append**. | Intermediate |
| Keep only some rows | Add [Filter](/nodes/builtin/flow/filter/) or [Sort](/nodes/builtin/datatransformation/sort/) between the table and the CSV. | Beginner |
| Lists instead of tables | Set Get Structured Data **Mode** to **list** for `ul` or `ol` lists. | Beginner |

## Troubleshoot

- **The wrong table is copied.** The page has several tables. Set **DOM Selector** to the one you want; the [data extraction guide](/app/troubleshooting/data-extraction/) shows how to find a selector.
- **Column names are the first data row.** The table has no header row. Turn off **Table first row is header**.
- **Nothing is copied.** Run it from the right-click menu on the page itself, not from the canvas.
