## Variations

| Variation | What to change | Level |
| --- | --- | --- |
| Scrape the page you're on | Replace Get HTML from Link with [Get All HTML](/nodes/extension/getallhtml/), which also works on pages you're signed in to. | Beginner |
| Keep only new items | Store the last titles with [Data Store](/nodes/builtin/core/datastore/) and use [Remove Duplicates](/nodes/builtin/datatransformation/removeduplicates/). | Advanced |
| Get a CSV | Add [CSV](/nodes/builtin/datatransformation/csv/) **Build** and [Clipboard Write](/nodes/extension/clipboardwrite/). | Beginner |

## Troubleshoot

- **The list is empty.** The site renders its list with JavaScript, so the fetched HTML has no items. Open the page and use [Get All HTML](/nodes/extension/getallhtml/) instead.
- **Links are relative (`/item?id=…`).** The site writes them that way. Prefix them with the site address in an [Edit Fields](/nodes/builtin/datatransformation/editfields/) step.
- **The fetch fails in the web app.** Some sites block requests from other origins; run it in the extension. See [browser compatibility](/app/troubleshooting/browser-compatibility/).
