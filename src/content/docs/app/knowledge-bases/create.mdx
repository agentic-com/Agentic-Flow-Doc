## Create a knowledge base

<Steps>

1. Open **Knowledge bases** in the sidebar and click **New knowledge base**.
2. Enter a **Name** and, optionally, **What's in it**. The description helps agents pick the right knowledge base.
3. Add sources right away (drop files, or use **Web page**, **Open tabs** or **Paste text**), or add them later.
4. Choose **Who can read it**: any model (**Cloud OK**) or this device only (**Device only**). See [Privacy](/app/knowledge-bases/privacy/).
5. Optionally open **Search engine** to see the embedding model it will use: by default *all-MiniLM-L6-v2*, on this device.
6. Click **Create and index**. The knowledge base opens and shows the progress.

</Steps>

<Callout type="tip" title="Check it worked">

The card shows **sources · chunks · size** and no longer says **Empty**. Open **Test search** and ask a question your documents answer: the passages come back. See [Test what gets found](/app/knowledge-bases/test-search/).

</Callout>

## Add sources

Open a knowledge base and click **Add sources** (or **Add sources** on its card). The dialog has four tabs:

| Tab | What it adds |
| --- | --- |
| **Files** | Drop or browse for files: PDF, TXT, Markdown, CSV, JSON and HTML. Text is extracted on this device. |
| **Web pages** | One URL per line. A bare domain gets `https://`. Duplicates and invalid entries are reported. |
| **Open tabs** | Extension only. Pick tabs, or **Select all** in a tab group. The text is read from the tab itself, so pages you are signed in to work too. |
| **Paste text** | A title and the text. |

The dialog header says which model indexes the sources, for example "Indexed on this device with MiniLM. Nothing is uploaded."

Each source gets its own row with a live status:

- *Reading* → *Embedding · 12 of 40 chunks* → **Added · 40 chunks**.
- **Already in this knowledge base and unchanged · skipped**, with **Re-index anyway**.
- An error in plain words, for example "No text found. It looks like a scanned image.", with **Try again**. A failed source never stops the others.

Under **Chunking** you choose how sources are split: **Automatic** (about 350 tokens per chunk), **Small** or **Large**, and whether to **Skip sources that haven't changed** (on by default).

You can close the dialog: indexing continues in the background, and the card and the knowledge base page show the progress. **Stop** cancels a job.

Adding a source that is already there **updates it in place** instead of adding a copy. If the new version is shorter, its leftover old passages are removed.

## The knowledge base page

Click a card to open it. The header shows sources, chunks, size, the model and the privacy badge, with **Test search**, **Add sources** and a menu (**Edit**, **Export**, **Delete**). The page has four tabs:

- **Sources**: every source with its type, title or link, number of chunks, when it was added and its status. Text indexed by a workflow shows as **From workflow …**; content added before sources were tracked is grouped under **Older content**. Click a source to open its chunks (number, page, size, with the overlap greyed), **Find in this source**, and **Re-index**, **Replace file…** and **Remove source**.
- **Test search**: see [Test what gets found](/app/knowledge-bases/test-search/).
- **Used by**: every agent, project, team, chat and workflow that uses it, with links.
- **Settings**: the **On this device only** switch and the **Search engine**. See [Re-embed or delete](/app/knowledge-bases/manage/).

In the side panel the page switches to one column, with **Add this tab** (extension) and **More sources**.
