**Settings › Assistant Notch** controls the floating bubble that the extension pins to the edge of web pages. It gives you quick actions (the same as the right-click menu) and the chat workflows available on the current page. Read [Assistant Notch](/app/assistant-notch/) for how to use it.

## Turn it on or off

Switch **Show the assistant bubble on web pages**.

## Customise it

When the bubble is on, you can change:

- **Resting form**: *Orb*, *Pill*, *Edge tab* or *Orb + badge*.
- **Accent**: one of five colours.
- **Size**: *S*, *M* or *L*.
- **Blocks**: which sections appear and in what order: *On this page*, *Pinned workflows*, *Quick actions* and *Page tools*. Drag the handle (or use **Move up** / **Move down**) and switch each one on or off. Blocks marked **Soon** aren't available yet.
- **Where it shows**: *All sites*. An allowlist option is coming.

Click **Save** to apply, or **Discard** to drop your changes.
