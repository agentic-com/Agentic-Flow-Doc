Workflow history helps you go back to an older version of a workflow.

## Understand workflow history

AWFlow keeps a new version of the workflow **each time you save it**. The first version is the one you created or imported.

:::note[Workflow history and execution history]
Don't confuse workflow history with execution history.

Executions are workflow runs. With the [executions list](/app/workflows/run-history/), you can see previous runs of the workflow.

Workflow history is previous versions of the workflow: for example, a version with a different node, or different parameters set.
:::

A run paused by [Wait For Approval](/nodes/builtin/flow/wait-for-approval/) appears in the executions list as a **waiting** run, and can be approved, rejected, or cancelled from there.

## View and restore a version

Open the workflow in the editor. Everything happens in the **Version history** popover at the top right:

To keep the version you picked, make it the current one: change something (move a step, for example), then click **Save**. Saving keeps a new version, so the newer ones stay in the list. To go back to the newest version instead, click the first version in the list, or reload the page.

The list is read when the editor opens: reload the page to see a version you have just saved.
