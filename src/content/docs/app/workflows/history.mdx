AWFlow keeps a new **version** of a workflow each time you save it, or when Aria applies a change, or when you restore an older version. **History** lists them so you can see what changed and go back.

:::note[History and Runs]
History is about **versions** of the workflow (a different step, other settings). The record of each time it ran is in [Runs](/app/workflows/run-history/).
:::

## Open History

In the editor, click the **History** button (the clock icon next to **Save**). A full-height sheet opens: *Every saved version of this workflow.*

Versions are grouped **Today**, **Yesterday** and **Earlier**. Each row shows:

- its name, or **Saved** (or **Aria: …** for a change Aria made, **Restored from …** for a restore);
- an icon for where it came from: a save, Aria, or a restore;
- the time, and what changed since the previous version, for example "+2 steps · 1 changed · 1 link";
- **Current** on the version the canvas is based on.

## See and compare a version

Click a row:

- **Preview** opens that version read-only.
- **Download .awf** saves that version as a file (passwords and keys are always left out; the file name carries the version's time).
- The actions show the **last run** of that version, with its status dot (for example *· last run Done*).
- **Compare with current** shows the old version with the differences ringed on the canvas, and the changes in plain words. Connection details are hidden.

## Restore a version

<Steps>

1. Click the version, then **Restore…**.
2. Confirm. The version is restored **as a new version**, labelled **Restored from …**, so the newer versions stay in the list.
3. The canvas shows it with **Restored — not saved yet**. Press **Save** to keep it.

</Steps>

## Name and keep a version

Click the star on a row, or **Name and keep**, and give the version a name ("Before the Slack change"). Named versions:

- stand out in the list;
- **survive clean-up**: they are never removed automatically (up to 20 per workflow).

**Unname** removes the name.

## How many versions are kept

- **On this device**: the last **50** versions of each workflow. Named, published and running versions (a paused run still needs its version) are always kept, as are the versions of the last 10 runs.
- **In your account (cloud)**: as many as your [plan](/app/settings/plan/) allows. Named versions and the versions paused runs need are always kept.

When a version is removed, the runs that used it keep their logs. Unsaved runs from the editor are kept as drafts and never show in History.
