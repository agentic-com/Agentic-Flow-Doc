You can run a workflow from the page you're on, using the browser's right-click menu. This is handy when you're browsing and want to use a workflow without opening AWFlow first. It needs the browser extension.

## Run a workflow

1. Open the web page you want the workflow to work on.
2. Right-click on the page.
3. Open the **Agentic Workflow** entry, then **Personal Workflows** (your own) or **Downloaded Workflows** (installed from the marketplace).
4. Click the workflow.

The workflow runs on that page. You can check what happened the same way as for any other run.

## Which workflows appear

The menu lists your **active** workflows that either:

- start with a [Context Menu](/nodes/builtin/trigger/contextmenu/) trigger. Its settings decide where the entry appears: for example only on links, only on selected text, or only on some sites; or
- have no automatic trigger, for example a workflow that starts with [When Started](/nodes/builtin/trigger/whenstarted/).

Workflows that start with another trigger (Schedule, Page Load, Hotkey…) don't appear, because they start on their own.

## If a workflow is missing

- Check that the workflow is **Active** (in the workflow list, or with the toggle in the canvas header) and saved.
- Check the Context Menu trigger's settings: the entry only appears where they allow it.
- Click **Get / Refresh Workflows** in the same right-click menu to reload the list.
- Browser pages (such as `chrome://` pages) and the extension gallery don't show extension menus.

## When to use it

- To run a workflow on the page you're reading, without switching to AWFlow.
- To act on a link, an image or selected text: add a Context Menu trigger limited to that kind of content.

To test a workflow step by step while building it, see [Run from the canvas](/app/workflows/executions/run-from-the-canvas/).
