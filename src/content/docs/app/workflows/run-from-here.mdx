When you fix a step in the middle of a workflow, you don't need to start again from the trigger. **Run from here** runs the step you pick **and the steps after it**, using what the earlier steps already produced.

## Start it

- **Run from here** in the step's menu, or in its right-click menu on the canvas.
- In the step's settings, the arrow next to **Run step** (**Run step ▾**) › **Run from here**.
- Select the step and press <Kbd mac="Cmd+Shift+Enter" windows="Ctrl+Shift+Enter" />.

The run bar reads, for example, *Running from Count open issues · step 2 of 3*.

## Where the earlier data comes from

Each step that leads into what runs uses, in this order:

1. its [kept result](/app/workflows/kept-results/), if it has one;
2. else its last result from this editor session;
3. else its data from the last saved run (when the workflow keeps step data, see [Workflow settings](/app/workflows/settings/#run-history)).

Those steps show a **Data from a past run** badge, and the **Last run** panel says which earlier results were used. A normal **Run** clears the badges.

If an earlier step has no result at all, AWFlow asks **Run from …?**: run that step first (recommended), or **Run from here anyway** (the step then receives no items).

## In Runs

A run started this way is recorded like a manual run, shown as **From a step · Count open issues** in [Runs](/app/workflows/run-history/).
