**In the app:** sidebar › **Your data** › **Memory**

**Memory** shows everything AWFlow remembers, in one place:

| What | Where it comes from |
| --- | --- |
| **Chats** | Your conversations with Aria, your agents and your teams: the Aria page, quick chats from the notch and the right-click card, team threads and chats in the canvas dock. |
| **Workflow conversations** | The chat history of workflows that use a [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) node, such as a chatbot built with a [Chat Trigger](/nodes/builtin/trigger/chat/). |
| **Facts** | Short things your assistant and agents learned about you ("Prefers short answers"), or that you added yourself. |

{/* SCREENSHOT: memory */}

1. **Storage strip.** What memory takes on this device, split into **Chats**, **Workflow** and **Facts**, with **Manage space →**.
2. **Import** and **Export all.** Move your memory as an `.awmem` file.
3. **Tabs.** **Conversations**, **Facts** and **Storage**.
4. **Search.** Looks in titles and in the messages themselves.

:::note[Chat memories is now Memory]
The page used to be called **Chat memories** and listed only workflow conversations. It now lists everything, and old links open it.
:::

## Use it everywhere

| Where | How memory works there |
| --- | --- |
| **Chat with Aria** | Every chat is kept here. Aria learns facts as you talk and uses the most relevant ones. See [Assistant memory](/app/chat-and-agents/memory/). |
| **An agent or a team** | Each agent has its own facts (builder › **Memory** tab), can read Aria's, and can share a fact with a team. |
| **A workflow** | A [Chat Memory](/nodes/builtin/ai/aidependencies/chatmemories/chatmemory/) node keeps a conversation across runs; it shows up here under **Workflows**. See [Memory and context](/concepts/ai/memory-context/). |

<Callout type="info" title="Your data" href="/app/memory/export-import/" linkLabel="Export a backup">

Memory is stored **only in this browser** and is never uploaded. Turn on [encryption](/app/memory/encryption/) to lock messages and facts with your passphrase. Clearing the browser's site data removes it, so export what you want to keep. It isn't limited by your plan: the only limit is the space your browser allows.

</Callout>
