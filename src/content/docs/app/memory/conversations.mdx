Open **Memory** and stay on the **Conversations** tab: every conversation of every kind, newest first.

## Filter and sort

- **Filter by kind** with the chips: **All**, **Aria chats**, **Quick chat**, **Teams**, **Workflows** and **Canvas dock**. Each chip shows its count; kinds you have none of are hidden.
- Under each title, a line says who the conversation belongs to: an agent and a project ("Writer · Trip to Lisbon"), a team, or a workflow and its key ("Workflow · Support bot · key inbox · shared").
- **Size** appears only for large conversations (a badge above **1 MB**). Sort by **Size** to find the biggest, or open [Free space](/app/memory/free-space/).
- **Recovered** marks an old workflow conversation that was saved but never shown before (written by the former Persistent Chat Memory node). The workflow keeps using it.

Each row's **⋯** menu has **Open**, **Export**, **Clear messages** and **Delete**. Select several rows to **Export** or **Delete** them together.

## Search inside conversations

The search box looks in **titles and in the messages themselves**. Matches are listed per conversation, with a snippet and your words highlighted. Click a match to open the conversation **at that message**, with **Load older messages** and **Load newer messages** around it.

Search uses a small word index kept on this device. After an update, older messages are indexed in the background and the results say **Indexing older messages…**. Tool results, reasoning and attachments aren't searched. With [encryption](/app/memory/encryption/) on, search looks at titles only.

## A conversation's page

Click a conversation to read it. Older messages load as you scroll up.

- **Summary**: when a long chat was summarised to fit the model, a notice says **18 earlier messages summarised · the agent sees this summary instead of them**. **View summary** shows it, the messages it covers, and *edited by you* if you changed it (see [Long chats](/app/chat-and-agents/chat/#long-chats-and-the-summary)).
- **Tool steps**: tools the agent used, in place. Click one for its arguments and stored result. A [slimmed](/app/memory/free-space/#slim-archive-and-delete) result shows only its one-line summary.
- **Interrupted replies**: a reply cut off when the tab closed is kept with what had been written, marked as interrupted.

The side panel shows **Used by** (the workflows that use this conversation), **What takes the space** (text, tool results, reasoning, unchosen regenerated answers, build snapshots, attachments, search index) and **Details** (created, last used, size, *On this device*).

The header has **Export**, **Slim**, **Clear messages** and **Delete**:

- **Clear messages** removes every message but keeps the conversation, so the workflows and chats that use it keep working and start fresh.
- **Delete** removes the conversation and its messages. It can't be undone: export it first to keep a copy.

## When a conversation is in use

If a workflow uses the conversation you're deleting, the dialog lists those workflows (with **Open** for each) and explains that they'll start with an empty memory on their next run. Choose **Clear messages only** to keep the conversation and drop its messages instead.
