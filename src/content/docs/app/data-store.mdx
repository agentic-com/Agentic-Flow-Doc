**In the app:** canvas › **Stored data** (one workflow), or **Settings › Preferences › Data store** (all workflows)

The [Data Store](/nodes/builtin/core/datastore/) node lets a workflow remember values between runs: a last-seen timestamp, a page cursor, a call count. This page is about seeing and clearing those values. To write and read them in a workflow, see the [Data Store node](/nodes/builtin/core/datastore/).

1. **Stored data** button on the canvas, shown when the workflow has a Data Store node.
2. **This workflow's values.** Each key with a preview of its value, **Copy** and **Delete**.
3. **Shared values.** A note when the workflow also uses values shared with all workflows.
4. **Clear all.** Make the next run behave like the workflow's first run.

## Use it everywhere

| Where | How |
| --- | --- |
| **A workflow** | The [Data Store](/nodes/builtin/core/datastore/) node sets, reads and increments values, scoped to **this workflow** or **shared with all workflows**. |
| **The canvas** | **Stored data** shows what this workflow kept; a Data Store node's settings link to it with **View stored values**. |
| **Settings** | **Settings › Preferences › Data store** lists every scope, with sizes and limits. |

<Callout type="info" title="Your data">

Values are kept **in this browser profile** only. The same workflow on another device keeps its own separate store, and clearing the extension's data removes them for good.

</Callout>

## On the canvas

Open a workflow that has a Data Store node and click **Stored data** in the canvas controls (or **View stored values** in the node's settings). The panel lists what this workflow's Data Store nodes remembered between runs, with **Copy** and **Delete** on each value and **Refresh** at the top. Before the first run it says *Nothing stored yet. Values appear here after a Data Store Set or Increment step runs.*

When the workflow also uses values **shared with all workflows**, a note says so; manage those in Settings.

## In Settings

Open **Settings › Preferences** and scroll to **Data store**. A summary shows how many values are stored, across how many scopes, and the total size, followed by the limits (each scope holds a fixed number of keys and total size). Values are grouped by **scope**:

- **Shared with all workflows**: the shared keyspace any of your workflows can read and overwrite. Listed first.
- **This workflow**: one group per workflow that has written values, named after it.

Each group shows its key count and size; inside, every key has a short preview of its value and its size. Values from a workflow you deleted stay visible under **`Deleted workflow (<id>)`**, so they can be found and cleared.

## Delete values

- **One value**: the delete (trash) control on its row.
- **A whole scope**: **Clear all** on the group's header (or in the canvas panel). The next run behaves like the workflow's first run.

Deletions take effect immediately and can't be undone.
