## Set it up

Use **Hugging Face Embeddings** in a workflow. The key is a saved credential.

<Steps>

1. **Create a key.** In your Hugging Face settings, open [Access Tokens](https://huggingface.co/settings/tokens) and click **Create new token**. Choose **Fine-grained** and tick **Make calls to Inference Providers**, or choose **Read**. Copy the token. It starts with `hf_`.
2. **Save it in AWFlow.** Open **Credentials** and click **Add Credential** (or **+ Add Credential** in the node's **Authentication** field). Pick **Simple Credential** and click **Continue**. Name it, for example *Hugging Face – personal*, set **Auth Type** to **JWT** and paste the key into **JWT**, exactly as copied. Choose the **Storage location** and click **Create Credential**.
3. **Pick it in the node.** In **Hugging Face Embeddings**, choose the credential in **Authentication** and type the **Model** id.

</Steps>

<Callout type="tip" title="Check it's connected">

Connect **Hugging Face Embeddings** to a [Local Knowledge](/nodes/builtin/ai/aidependencies/vectorstore/localknowledge/) node and index one short text with the [Indexer](/nodes/builtin/ai/aiagents/indexernode/): it finishes without an error.

</Callout>

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to Hugging Face Inference (huggingface.co). AWFlow's servers never relay the call.

</Callout>

## Common issues

- **A 401, "invalid API key" or "Incorrect API key" error.** The key was mistyped, revoked, or belongs to another account. Create a new key and update the credential (or the provider in **Settings › Providers**).
- **A 429 or "quota" error.** The account is out of credit or over its rate limit. Add credit or wait, then run again.
- **An embeddings node fails with 401 while a chat node with the same key works.** The credential is a **Bearer Token**. Embeddings nodes pass the value to the provider as it is, so use a **JWT** credential that holds only the key.
