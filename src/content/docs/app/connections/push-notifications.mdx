## Before you start

- The ntfy or Pushover app on your phone.
- The AWFlow browser extension. These steps run in the extension (the web app hands them to it).

## Used by

- [Push Notification](/nodes/builtin/integration/push-notification/)

## Pick a method

| Method | Use it when |
| --- | --- |
| **ntfy.sh public topic** <Badge variant="new" text="Recommended" /> | No account and no credential. Anyone who knows the topic name can read it, so pick a hard-to-guess one. |
| **ntfy with access control** | Your own ntfy server, or reserved topics. |
| **Pushover** | A paid, reliable push service with priorities and sounds. |

## Set it up

<Tabs syncKey="connect-push-notifications">
<TabItem label="ntfy.sh public topic (recommended)">

<Steps>

1. **Subscribe on your phone.** In the ntfy app, subscribe to a topic with a long, random name.
2. **In the node**, leave **Credential** empty and type the same **Topic**.

</Steps>

Click **Run step**: the notification arrives on your phone.

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to ntfy.sh or your ntfy server and `api.pushover.net`. AWFlow's servers never relay the call.

</Callout>

## Common issues

- **The ntfy notification never arrives.** The phone is subscribed to another topic or server. Check the exact **Topic** and **Server**.
- **"ntfy Error: 403 Forbidden" or 401.** The server needs an access token. Add a Bearer Token credential.
- **"Pushover needs a Basic Auth credential…".** The credential isn't Basic Auth, or a field is empty. The application token goes in **Username**, the user key in **Password**.
- **The run is blocked in the web app.** Push Notification runs through the browser extension. With the extension installed, the web app can use ntfy.sh and Pushover, but not your own ntfy server.
