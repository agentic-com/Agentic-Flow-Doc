## Before you start

- A Google account. AI Studio keys work without a Cloud project; Vertex AI keys need a Google Cloud project with billing.

## Used by

- [Chat Google](/nodes/builtin/ai/aidependencies/llm/google/)
- [Google Embeddings](/nodes/builtin/ai/aidependencies/embeddings/google/)
- [Aria and agents (Settings › Providers)](/app/settings/providers/)

## Pick a method

| Method | Use it when |
| --- | --- |
| **Aria & agents** <Badge variant="new" text="Recommended" /> | Chat with Aria or an agent on Google Gemini models. The key is kept in **Settings › Providers**. |
| **Workflow nodes** | Use **Chat Google**, **Google Embeddings** in a workflow. The key is a saved credential. |

## Set it up

<Tabs syncKey="connect-google-gemini">
<TabItem label="Aria & agents (recommended)">

<Steps>

1. **Create a key.** In Google AI Studio, open [Get API key](https://aistudio.google.com/app/apikey), click **Create API key** and copy it. For Vertex AI, create the key in the [Google Cloud Console](https://console.cloud.google.com/vertex-ai/studio/api-key/) instead.
2. Open **Settings › Providers** and click **+ Add provider**.
3. Pick **Google** as the **Provider**, give it a **Label** and paste the key into **API key**.
4. Type the **Model** id (a `gemini-…` id), then click **Add**.
5. Optionally click **Set as default**, so Aria and agents set to *Same as Aria* use it.

</Steps>

<Callout type="tip" title="Check it's connected">

Open a chat, pick the provider's model in the model menu and send *Hello*: the reply comes from Google Gemini. A wrong key shows a provider error in the chat right away.

</Callout>

</TabItem>
<TabItem label="Workflow nodes">

<Steps>

1. **Create a key.** In Google AI Studio, open [Get API key](https://aistudio.google.com/app/apikey), click **Create API key** and copy it. For Vertex AI, create the key in the [Google Cloud Console](https://console.cloud.google.com/vertex-ai/studio/api-key/) instead.
2. **Save it in AWFlow.** Open **Credentials** and click **Add Credential** (or **+ Add Credential** in the node's **Authentication** field). Pick **Simple Credential** and click **Continue**. Name it, for example *Google Gemini – personal*, set **Auth Type** to **JWT** and paste the key into **JWT**, exactly as copied. Choose the **Storage location** and click **Create Credential**.
3. **Pick it in the node.** In **Chat Google**, choose the credential in **Authentication** and type the **Model** id.

</Steps>

<Callout type="tip" title="Check it's connected">

Connect **Chat Google** to an AI node (for example a Basic LLM Chain with the prompt *Say hello*) and click **Test step** on the AI node: you get a reply.

</Callout>

</TabItem>
</Tabs>

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to generativelanguage.googleapis.com (AI Studio) and aiplatform.googleapis.com (Vertex AI). AWFlow's servers never relay the call.

Keys added in **Settings › Providers** are separate: they stay **on this device only**, encrypted, and are never synced to your account.

</Callout>

## Common issues

- **A 401, "invalid API key" or "Incorrect API key" error.** The key was mistyped, revoked, or belongs to another account. Create a new key and update the credential (or the provider in **Settings › Providers**).
- **A 429 or "quota" error.** The account is out of credit or over its rate limit. Add credit or wait, then run again.
- **An embeddings node fails with 401 while a chat node with the same key works.** The credential is a **Bearer Token**. Embeddings nodes pass the value to the provider as it is, so use a **JWT** credential that holds only the key.
- **"API key not valid" with a Vertex AI key.** In **Chat Google**, set **Platform Type** to `gcp`. Leave it empty or on `gai` for an AI Studio key.
