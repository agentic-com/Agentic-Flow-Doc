## Before you start

- A Cohere account. A trial key works, with low rate limits.

## Used by

- [Cohere Embeddings](/nodes/builtin/ai/aidependencies/embeddings/cohere/)

## Set it up

Use **Cohere Embeddings** in a workflow. The key is a saved credential.

<Steps>

1. **Create a key.** In the Cohere dashboard, open [API keys](https://dashboard.cohere.com/api-keys) and copy a trial or production key.
2. **Save it in AWFlow.** Open **Credentials** and click **Add Credential** (or **+ Add Credential** in the node's **Authentication** field), then fill the **New Credential** form. In the browser side panel the form comes in two steps: tap **Simple Credential** (or click **Continue**), then fill the rest.

<Callout type="tip" title="Check it's connected">

</Callout>

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to `api.cohere.ai`. AWFlow's servers never relay the call.

</Callout>

## Common issues

- **A 401, "invalid API key" or "Incorrect API key" error.** The key was mistyped, revoked, or belongs to another account. Create a new key and update the credential (or the provider in **Settings › Providers**).
- **A 429 or "quota" error.** The account is out of credit or over its rate limit. Add credit or wait, then run again.
- **An embeddings node fails with 401 while a chat node with the same key works.** The credential is a **Bearer Token**. Embeddings nodes pass the value to the provider as it is, so use a **JWT** credential that holds only the key.
