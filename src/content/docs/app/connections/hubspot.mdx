## Before you start

- A HubSpot account where you are a **Super Admin** (needed to create private apps).
- The AWFlow browser extension. These steps run in the extension (the web app hands them to it).

## Used by

- [HubSpot](/nodes/builtin/integration/hubspot/)

## Set it up

<Steps>

1. **Create a private app.** In HubSpot, open **Settings › Integrations › Private Apps** and click **Create a private app**.
2. **Pick scopes.** On the **Scopes** tab, add the scopes from the table below for the operations you use. Click **Create app**.
3. **Copy the access token** (it starts with `pat-`).
4. **Save it in AWFlow.** Open **Credentials** and click **Add Credential** (or **+ Add Credential** in a node's **Credential** field), then fill the **New Credential** form. In the browser side panel the form comes in two steps: tap **HubSpot** in the list, then fill the rest.

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to `api.hubapi.com`. AWFlow's servers never relay the call.

</Callout>

## Permissions each operation needs

| Operation | Scope |
| --- | --- |
| Contact · Search | `crm.objects.contacts.read` |
| Contact · Create or update, Update | `crm.objects.contacts.write` (and `.read`) |
| Company · Search | `crm.objects.companies.read` |
| Company · Create or update | `crm.objects.companies.write` (and `.read`) |
| Deal · List | `crm.objects.deals.read` |

## Common issues

- **"403 Forbidden — the private app token is missing a required scope".** Add the scope to the private app, then run again (the token stays the same).
- **"401 Unauthorized".** The token is wrong or was rotated. Copy the current one and update the credential.
- **The run is blocked in the web app.** HubSpot runs through the browser extension. Install the extension and allow HubSpot for this workflow when asked, or run the workflow from the extension. See [Extension-only integrations in the web app](/app/troubleshooting/extension-only-integrations-in-the-web-app/).
