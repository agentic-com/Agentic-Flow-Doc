## Before you start

- A Raindrop.io account.
- The AWFlow browser extension. These steps run in the extension (the web app hands them to it).

## Used by

- [Raindrop](/nodes/builtin/integration/raindrop/)

## Set it up

This is the only method. The token gives full access to your Raindrop account.

<Steps>

1. **Create an app.** On raindrop.io, open **Settings › Integrations** and, under **For Developers**, click **Create new app** (any name).
2. **Create the token.** Open the app, click **Create test token** and copy it.
3. **Save it in AWFlow.** Open **Credentials** and click **Add Credential** (or **+ Add Credential** in a node's **Credential** field), then fill the **New Credential** form. In the browser side panel the form comes in two steps: tap **Raindrop** in the list, then fill the rest.

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to `api.raindrop.io`. AWFlow's servers never relay the call.

</Callout>

## Common issues

- **"401 Unauthorized".** The token is wrong or was deleted. Create a new test token and update the credential.
- **The run is blocked in the web app.** Raindrop runs through the browser extension. Install the extension and allow Raindrop for this workflow when asked, or run the workflow from the extension. See [Extension-only integrations in the web app](/app/troubleshooting/extension-only-integrations-in-the-web-app/).
