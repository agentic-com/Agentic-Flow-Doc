## Before you start

- The Obsidian desktop app, open while the workflow runs.
- The **Local REST API** community plugin.
- The AWFlow browser extension. These steps run in the extension (the web app hands them to it).

## Used by

- [Obsidian](/nodes/builtin/integration/obsidian/)

## Set it up

<Steps>

1. **Install the plugin.** In Obsidian, open **Settings › Community plugins**, browse for **Local REST API**, install it and enable it.
2. **Turn on the HTTP server.** In the plugin's settings, enable the non-encrypted (HTTP) server on port `27123`. The HTTPS port `27124` uses a self-signed certificate that the browser rejects.
3. **Copy the API key** from the plugin's settings.
4. **Save it in AWFlow.** Open **Connections** and click **Add connection** (or **Connect** in a step's **Connection** field), then fill the **New connection** form. In the browser side panel the form comes in two steps: tap **Obsidian** in the list, then fill the rest.

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#connections-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **On this device**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **In your account (cloud)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to your own computer (`http://127.0.0.1:27123` by default). AWFlow's servers never relay the call.

</Callout>

## Common issues

- **"Could not reach the Obsidian Local REST API at…".** Obsidian is closed, the plugin or its HTTP server is off, or **Server URL** doesn't match the port.
- **"401 … check the API key from the plugin settings".** The key was regenerated in the plugin. Copy it again.
- **The run is blocked in the web app.** Obsidian runs through the browser extension. Install the extension and allow Obsidian for this workflow when asked, or run the workflow from the extension. See [Extension-only integrations in the web app](/app/troubleshooting/extension-only-integrations-in-the-web-app/).
