## Before you start

- An Attio workspace where you are an admin.
- The AWFlow browser extension. These steps run in the extension (the web app hands them to it).

## Used by

- [Attio](/nodes/builtin/integration/attio/)

## Set it up

<Steps>

1. **Create the token.** In Attio, open **Workspace settings › Developers**, create an integration and copy its **access token**. Give it read and write access to records and notes.
2. **Save it in AWFlow.** Open **Credentials** and click **Add Credential** (or **+ Add Credential** in a node's **Credential** field). Under **Integration App / Service** pick **Attio** and click **Continue**. Name it, for example *Attio – CRM*: **Auth Type** is already set to **Bearer Token**. Then paste the token into **Bearer Token**, choose the **Storage location** and click **Create Credential**.

</Steps>

<Callout type="tip" title="Check it's connected">

Run **Person › Search** with an email you know: the record comes back.

</Callout>

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to `api.attio.com`. AWFlow's servers never relay the call.

</Callout>

## Common issues

- **"401 Unauthorized — the API key is missing or invalid".** The token is wrong or was revoked. Create a new one and update the credential.
- **"403 Forbidden".** The token lacks read or write access to records or notes. Change its scopes in Attio.
- **The run is blocked in the web app.** Attio runs through the browser extension. Install the extension and allow Attio for this workflow when asked, or run the workflow from the extension. See [Extension-only integrations in the web app](/app/troubleshooting/extension-only-integrations-in-the-web-app/).
