## Before you start

- A Pipedrive account.
- The AWFlow browser extension. These steps run in the extension (the web app hands them to it).

## Used by

- [Pipedrive](/nodes/builtin/integration/pipedrive/)

## Set it up

This is the only method. The token can do anything your Pipedrive user can.

<Steps>

1. **Copy the token.** In Pipedrive, open **Settings › Personal preferences › API** and copy **Your personal API token**.
2. **Save it in AWFlow.** Open **Connections** and click **Add connection** (or **Connect** in a step's **Connection** field), then fill the **New connection** form. In the browser side panel the form comes in two steps: tap **Pipedrive** in the list, then fill the rest.

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#connections-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to `api.pipedrive.com`. AWFlow's servers never relay the call.

</Callout>

## Common issues

- **"401 … the API token is missing or invalid".** Copy the token again. Regenerating it makes the old one stop working.
- **The run is blocked in the web app.** Pipedrive runs through the browser extension. Install the extension and allow Pipedrive for this workflow when asked, or run the workflow from the extension. See [Extension-only integrations in the web app](/app/troubleshooting/extension-only-integrations-in-the-web-app/).
