## Before you start

- A Todoist account.
- The AWFlow browser extension. These steps run in the extension (the web app hands them to it).

## Used by

- [Todoist](/nodes/builtin/integration/todoist/)

## Set it up

<Steps>

1. **Copy the token.** In Todoist, open **Settings › Integrations › Developer** and copy the **API token**.
2. **Save it in AWFlow.** Open **Credentials** and click **Add Credential** (or **+ Add Credential** in a node's **Credential** field). Under **Integration App / Service** pick **Todoist** and click **Continue**. Name it, for example *Todoist – personal*: **Auth Type** is already set to **Bearer Token**. Then paste the token into **Bearer Token**, choose the **Storage location** and click **Create Credential**.

</Steps>

<Callout type="tip" title="Check it's connected">

Run **Project › List** in a **Todoist** node: your projects come back with their IDs.

</Callout>

## Where your token lives

<Callout type="credential" title="Where your token lives" href="/app/privacy-and-data/#credentials-and-secrets" linkLabel="Privacy & your data">

The credential is stored where you choose when you create it:

- **Local (this browser only)**: encrypted in this browser. The encryption key is kept on the same device, so turn on the [local secret vault](/app/account/secret-vault/) to lock it with a passphrase only you know.
- **Cloud (synced to your account)**: sent over an encrypted connection and stored encrypted on AWFlow's server, so it works on your other devices.

When a step runs, your browser sends it only to `api.todoist.com`. AWFlow's servers never relay the call.

</Callout>

## Common issues

- **"401 Unauthorized" or "403 Forbidden".** The token is wrong or was replaced. Copy the current one and update the credential.
- **The token leaked.** Issue a new token on the same page; the old one stops working.
- **The run is blocked in the web app.** Todoist runs through the browser extension. Install the extension and allow Todoist for this workflow when asked, or run the workflow from the extension. See [Extension-only integrations in the web app](/app/troubleshooting/extension-only-integrations-in-the-web-app/).
