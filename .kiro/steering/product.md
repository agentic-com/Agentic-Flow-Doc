# Product Overview

**Agentic Flow** is a framework for building AI-powered workflows that runs inside your browser. This is the documentation site for the project.

## Key Features
- Browser-based AI workflow builder
- Integration with various services and APIs
- Advanced AI capabilities using LangChain
- Visual workflow editor with nodes and connections
- Built-in and community-contributed integrations

## Documentation Structure
The documentation is organized into four main sections:
- **Usage**: Getting started guides, key concepts, and app usage
- **Integrations**: Built-in nodes, applications, and extensions
- **Advanced AI**: LangChain integration, evaluations, and AI examples
- **Learning**: Examples, video courses, and tutorials

## Target Audience
Developers and users building AI-powered automation workflows, ranging from beginners to advanced users working with LangChain and complex AI integrations.
