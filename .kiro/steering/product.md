# Product Context & Guidelines

**`Agentic Workflow Studio`** is a browser-based framework for building AI-powered workflows. This documentation site serves developers and users creating automation workflows with visual node-based editors.

## Core Product Concepts

### Workflow Architecture

- **Nodes**: Individual processing units (AI agents, data transformers, triggers, flow control)
- **Connections**: Data flow between nodes with typed inputs/outputs
- **Executions**: Workflow runs with manual, partial, or production modes
- **Lambda Workflows**: Reusable sub-workflows for modular design

### Node Categories

- **AI Agents**: LLM chains, RAG, Q&A, tool-based agents
- **Core**: HTTP requests, web scraping, code execution
- **Data Transformation**: Date/time, field editing, file operations
- **Flow Control**: Conditionals, filters, merging, error handling
- **Triggers**: Workflow initiation points

## Content Guidelines

### Documentation Tone

- Technical but accessible to both beginners and advanced users
- Focus on practical implementation over theoretical concepts
- Include working examples and code snippets
- Emphasize browser-based, no-installation benefits

### Node Documentation Standards

- Start with clear purpose statement
- Include parameter descriptions with types
- Provide practical examples with real use cases
- Show input/output data structures
- Link to related nodes and concepts

### AI Content Considerations

- LangChain integration is a key differentiator
- Emphasize evaluation and testing capabilities
- Show progression from basic to advanced AI workflows
- Include memory, tools, and agent patterns

## User Journey Mapping

1. **Getting Started**: Quick intro → Learning path → First workflow
2. **Building**: Node selection → Configuration → Testing → Publishing
3. **Advanced**: AI integration → Custom tools → Evaluation → Optimization

## Content Organization Principles

- Progressive disclosure: Simple → Complex
- Task-oriented structure over feature-oriented
- Cross-reference related concepts
- Maintain consistency in terminology and examples
